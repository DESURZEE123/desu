# 需求背景

目前尽调评审系统中租赁物信息分散在各项目详情页内，客户经理需在项目维度逐一录入租赁物，无法在项目外独立维护。同时，发票识别、验真、设备信息整理、勘察照片归档等环节分散在不同载体中流转，存在录入效率低、字段遗漏、附件错配等问题，一租赁物多发票、多附件场景下人工处理成本高。

为提升租赁物管理效率，在尽调评审系统中新增独立的【租赁物管理】节点，支持租赁物集中登记、发票识别回填、批量导入导出、与项目的关联管理。租赁物可在项目外独立维护，后续在项目报单时关联使用，减少重复录入，并为运营核验和付款审核提供统一的租赁物资料视图。

### 页面说明

1. 在左侧导航栏【租赁物查询】节点下方新增一级菜单【租赁物管理】，点击进入租赁物管理页，进入该页面时展示全部租赁物数据；
2. 进入租赁物管理页，页面上部导航栏出现"租赁物管理"页签；
3. 页面自上而下依次为：筛选条件区、功能操作按钮区、租赁物数据列表、分页区域；
4. 默认每页10条，列表分页支持选择10、20、50、100条数据一页，单次有效；
5. 已打开页签进行切换时不刷新页面。

1. 点击【全部展开】按钮，列表中所有租赁物展开详情视图，操作栏按钮由【详情】切换为【收起】；详情视图一行展示5个字段；

#### 租赁物发票识别并验真

参考<cite doc-id="LwvAwGKz5iGLDJk2U0Nc1IoQnvh" file-type="wiki" title="【小企业尽调评审系统】租赁物发票识别" type="doc"></cite>

修改处已标黄，同步修改租赁物信息模块现有租赁物发票识别按钮

该按钮新增验真功能详见4.3

1. 点击【租赁物发票识别】按钮，弹出发票识别窗口；
2. 上传方式：支持拖拽文件至上传区域，或点击上传区域选择本地文件；
3. 支持文件类型：单个 PDF、PNG、JPG ；
4. 上传文件后，弹窗内表格新增一行数据，识别状态为"待识别"，文档类型默认为"租赁物发票"；
5. 点击【租赁物发票识别并验真】按钮，对已上传文件执行发票识别与验真，识别状态依次变为"识别中"→“识别成功”、"识别失败”、；若无文件或全部文件已删除，【识别】按钮置灰；

## 新增现场勘察功能

### 业务流程

1. **尽调系统录入租赁物**：用户在尽调系统的租赁物管理节点新增或编辑租赁物信息，当录入的租赁物**净值（元）>10万**时，调用[消息推送接口](http://172.16.251.167:8090/pages/viewpage.action?pageId=47612413)接口向掌乐租推送租赁物勘察任务通知；
2. **掌乐租端运营收到勘察任务提醒**：运营人员在掌乐租App中收到新的勘察任务通知，勘察任务列表页展示待处理的勘察任务；
3. **运营点击进入勘察任务详细页**：掌乐租调用新增的租赁物信息接口查询租赁物关键字段（租赁物名称、数量、型号、净值）展示在勘察任务详细页上方，下方提供拍照入口；
4. **运营现场拍摄照片**：运营人员前往租赁物所在地，通过拍照功能分别拍摄设备外观照片和铭牌照片；
5. **提交勘察**：运营人员确认照片拍摄完成后，点击【提交勘察】按钮，该勘察任务状态由"待勘察"变更为"已提交"；
6. **尽调系统回读勘察附件**：尽调系统在刷新租赁物管理或项目审批页的租赁物信息模块时，调用掌乐租的租赁物管理接口，获取并展示勘察附件并同步更新到附件中，文件类型为租赁物勘察图片；
7. **尽调系统查看勘察附件**：用户在租赁物列表的"勘察附件"列点击附件图标，弹出图片查看弹窗，支持上一张/下一张翻页浏览。

| **序号** | **字段** | **类型** | **格式** | **是否必输** | **备注** |
|-|-|-|-|-|-|
| 1 | emplyeeId | String | 字符串 | 是 | 员工工号 |
| 2 | leasedAssetName | String | 字符串 | 否 | 租赁物名称 |
| 3 | uploadStartDate | Date | 日期 | 否 | 上传起始时间 |
| 4 | uploadEndDate | Datw | 日期 | 否 | 上传结束时间 |
| 5 | uploadBy | String | 字符串 | 否 | 上传人姓名 |
| 6 | dept | String | 字符串 | 否 | 部门 |
| 7 | currentPage | String | 字符串 | 否 | 当前页，默认第1页 |
| 8 | pageSize | String | 字符串 | 否 | 每页条数，默认每页10条，不要设置过多 |

反参

| **序号** | **字段** | **类型** | **格式** | **备注** |
|-|-|-|-|-|
| 1 | leasedAssetName | String | 字符串 | 租赁物名称 |
| 2 | number | number | 数字 | 数量 |
| 3 | uploadDate | Date | 日期 | 上传日期 |
| 4 | uploadBy | String | 字符串 | 上传人姓名 |
