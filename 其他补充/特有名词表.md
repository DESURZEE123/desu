# 特有名词表

## 整理名词（待并入正式章节）

> 下列解释以融资租赁行业通用口径为主；标注「待确认」的为系统/公司内部叫法，需对照字段定义或产品同事核对。

### 0. 合作/风险类（列表草稿）


| 名词                   | 一句话解释                                      | 备注                                      |
| -------------------- | ------------------------------------------ | --------------------------------------- |
| **承租人拜访记录**          | 客户经理/尽调人员上门或远程拜访承租人的留痕（时间、对象、结论等）          | 尽调过程材料；具体字段结构待确认                        |
| **累积跟踪**             | 对客户历史合作、敞口或风险变化做持续累计与跟踪的记录/视图               | **待确认**：跟踪对象是敞口、逾期还是拜访，需对照系统            |
| **承租人为非关联方的对外担保**    | 承租人给「非关联方」提供的担保余额（或笔数），属于或有负债               | 用来看承租人自身对外担保压力，≠本公司担保敞口                 |
| **总回款**              | 历史上已收回的款项合计（租金/本金等，口径看系统定义）                 | 易与「合同金额」「剩余本金」混淆；是否含提前结清待确认              |
| **顺利风险敞口**           | 疑为某类「当前仍存续、正常履约」业务上的风险敞口                     | **待确认**：也可能是「存量」口误/别称，需对照字段名              |
| **预测风险敞口 / 设备原值**    | 按设备原值或测算规则预估的风险敞口（审批前/投放前常用）                | 常与「存量风险敞口」对照：一个预测、一个实际；设备原值是否等于敞口基数待确认 |
| **承租人累积风险敞口**        | 该客户作为承租人，所有相关业务风险敞口的累计值                    | 接近文档中的「存量风险敞口」；是否含已结清、是否扣保证金待确认         |


### 1. 实施方案 · 规则报价

> **直租 / 回租会不会影响下面字段？**  
> **一般会。** 直租偏「购设备→出租」，投放与货价、首付、厂商贴息更常见；回租偏「存量设备融资」，名义货价、评估值、翻单相关字段更敏感。同一套报价字段名可能共用，但必填项、默认值、校验规则常按业务类型分支——**具体以系统配置为准（待确认）**。


| 名词                      | 一句话解释                                         | 备注 / 易混点                                      |
| ----------------------- | --------------------------------------------- | --------------------------------------------- |
| **规则报价**                | 按系统预设还款算法自动算出各期租金/本金利息的报价方式                    | 对偶概念是「不规则报价」（手工排期）                              |
| **投放金额**                | 本公司实际投放/融出的金额（这笔业务「放出去」多少钱）                   | ≈融资额；通常 ≠ 设备全款（可能扣首付、保证金等）                     |
| **投放日期**                | 资金实际投放（或起息）的日期                                | 影响起租、计息起算日                                    |
| **起租调整**                | 对起租日/首期起算做的人工或规则调整                             | **待确认**：是改日期、改首期金额，还是宽限期类调整                   |
| **付费标识**                | 标识租金是「先付」还是「后付」（或类似付费时点标签）                     | 先付：期初付；后付：期末付，现金流与 IRR 都会变                    |
| **调息**                  | 合同利率随基准（如 LPR）变动而调整的机制/开关                      | 有调息 vs 固定利率；调息规则（频率、幅度）待确认                    |
| **等额租金**                | 每期租金总额相同，本金+利息结构随期变化                           | 类似房贷等额本息                                      |
| **等额本金**                | 每期偿还本金相同，利息按剩余本金递减，前期总还款更高                     | 类似房贷等额本金                                      |
| **指定租金**                | 业务人员指定每期（或某些期）租金金额，系统反算本金/利息                   | 灵活排期，仍属「规则」算法的一种输入                             |
| **指定本金**                | 业务人员指定每期本金，系统据此算利息与租金                         | 与指定租金对称                                       |
| **分段报价**                | 租期内分多段，各段利率或算法可以不同                            | 如前 12 期一种算法、后 24 期另一种                         |
| **平息法**                 | 用「总利息 = 本金 × 年利率 × 年数」再均摊的简化计息方式                | 名义利率看起来低，实际负担常高于 IRR 口径；≠ 等额租金                |
| **保证金**                 | 客户押在公司的一笔钱，违约可扣，正常到期通常退还或抵扣尾款                  | 已见正式表「一、业务与角色」                                |
| **保证金金额**               | `(投放金额 - 首付款金额) × 保证金比例`                      | 公式来自你的草稿；系统是否严格按此算待确认                         |
| **保证金比例**               | 产品/审批给定的保证金占「投放−首付」的比例                         | **一般不是算出来的**，而是产品政策或审批结果；不同业务线可不同             |
| **保证金是否计入投放金额？**        | **通常不计入。** 投放金额是融出本金；保证金是增信押金，另记账              | 实务上可能「投放时从应付客户款中扣留保证金」，客户实收变少，但会计/报价上仍常分列；以系统为准 |
| **名义货价**                | 租期结束象征性留购价（如 100 / 1000 元），用于所有权转移              | 直租更常见；回租场景含义可能不同，待确认                          |
| **贴息金额**                | 厂商/经销商/财政等代承租人补贴的利息部分                         | 草稿公式：`(投放金额 - 首付款) × 贴息比例`                    |
| **贴息比例**                | 贴息占「投放−首付」的比例                                  | 多由厂商政策或活动给出，不是客户自填随意数                         |
| **计划收取日期**              | 计划向客户收取某笔款项（租金/保证金/名义货价等）的日期                   | 与实际回款日对比可看逾期                                   |


### 2. 实施方案 · 不规则报价


| 名词             | 一句话解释                            | 备注                         |
| -------------- | -------------------------------- | -------------------------- |
| **不规则报价**      | 不套标准算法，按自定义各期租金/日期排出还款表           | 适合特殊约定、不规则现金流              |
| **租金总额**       | 整个租期内应付租金合计                      | 不规则报价下常作为结果或校验项展示          |
| **综合收益率**      | 计入手续费等后的更全面年化收益                  | 已见正式表；通常 ≥ IRR             |
| **内部收益率（IRR）** | 按租金等现金流折现算出的真实年化收益率              | 已见正式表；≠ 合同名义利率             |
| **租金分配 IRP**   | 把每期租金拆成利息/本金（等）成分的分配结果或规则         | **待确认**：IRP 在系统中的全称与字段含义   |
| **银票收益率**      | 用银行承兑汇票等方式结算时，折算后的实际收益率            | 银票有贴息/期限成本，收益率常低于纯现金口径     |
| **保险计算基准金额**   | 计算租赁物保险费时所依据的保额基数                | 常取设备价款/投放额/评估值之一，以产品规则为准   |
| **优先受偿权数额**    | 抵押/质押等安排下，本公司可主张优先受偿的金额上限         | 风控/法务口径；与「风险敞口」「担保余额」相关但不等同 |


### 3. 经营数据分析


| 名词         | 一句话解释                         | 备注                            |
| ---------- | ----------------------------- | ----------------------------- |
| **银行流水**   | 企业银行账户的收支明细，用来核经营真实性与回款能力     | 尽调常见材料；关注对手方、稳定性、大额异常         |
| **银行承兑**   | 银行承兑汇票（银票）相关数据：收票、开票、贴现等      | 与「银票收益率」同一业务语境；可反映供应链结算习惯     |
| **纳税申报采购** | 纳税申报里体现的采购/进项相关数据（验证真实经营与设备/原料采购） | **待确认**：字段是进项税额、采购额还是发票清单维度 |







## 一、业务与角色


| 名词             | 一句话解释                            | 备注                   |
| -------------- | -------------------------------- | -------------------- |
| **融资租赁**       | 金融租赁公司帮客户买设备，客户分期付租金，租期到了设备通常归客户 | ≠ 银行贷款（贷款是直接给钱）      |
| **承租人**        | 租设备、付租金的一方，相当于「借钱的人」             | 合作历史核心查询对象           |
| **出租人**        | 买设备、收租金的一方                       | 本文档中固定为江苏金融租赁        |
| **担保人 / 担保方**  | 承租人还不上钱时，替其偿还的企业或个人              | 合作历史也要查其历史记录         |
| **关联企业 / 关联方** | 与承租人有股权、控制等「亲戚关系」的公司             | 风险可能传导到承租人           |
| **集团关联方**      | 同一集团下的公司                         | CRM 相关方类型之一          |
| **实控人关联方**     | 同一实际控制人控制的公司                     | CRM 相关方类型之一          |
| **其他关联方**      | 其他有关系的公司/手动新增客户                  | stakeHolderType=99 等 |
| **实际控制人（实控人）** | 不一定是法人代表，但实际上说了算的老板              | 知识图谱与合作历史会穿透查询       |
| **法定代表人**      | 营业执照上登记的法人代表                     | 可能与实控人不是同一人          |
| **增信措施**       | 担保、抵押、保证金等，用来降低业务风险的额外保障         | 该模块下也有合作历史，需同步更新     |
| **保证金**        | 客户先押在公司的一笔钱，违约时可抵扣损失             | 进入风险敞口计算公式           |
| **租赁物**        | 融资租赁合同标的设备/资产                    | 如扫地车、印刷机等            |

## 二、收益与金额指标


| 名词             | 一句话解释                      | 容易混淆     |
| -------------- | -------------------------- | -------- |
| **合同金额**       | 这笔业务最初的总金额（约等于买设备花了多少钱）    | ≠ 剩余本金   |
| **剩余本金**       | 客户目前还欠公司多少本金没还             | ≠ 合同金额   |
| **IRR（内部收益率）** | 按租金现金流算出的真实年化收益率           | ≠ 合同名义利率 |
| **综合收益率**      | 在 IRR 基础上可能再计入手续费等的更全面年化收益 | 通常 ≥ IRR |
| **利率**         | 合同上写的名义利率                  | 不等于实际收益率 |
| **存量风险敞口**     | 客户作为承租人，未结清业务上公司可能损失的金额    | 承租人身份    |
| **担保项目累计风险敞口** | 客户作为担保人，为他人担保项目上的风险敞口合计    | 担保人身份    |

## 三、逾期与信用风险


| 名词             | 一句话解释                   | 风险含义               |
| -------------- | ----------------------- | ------------------ |
| **逾期**         | 到了应付日，客户没付或没付够          | 核心信用信号             |
| **当前逾期金额**     | 现在仍欠着未付的逾期租金            | **高风险**            |
| **当前逾期天数**     | 最近一笔逾期已拖了多少天            | 衡量严重程度             |
| **当前逾期期数**     | 当前仍处于逾期状态的期数            | 「需关注」判定条件之一        |
| **历史最大逾期天数**   | 历史上最严重一次逾期拖了多少天         | 历史信用               |
| **历史逾期期数**     | 历史上总共逾期过几次/几期           | 逾期频率               |
| **征信**         | 人行征信中心记录的借贷信用档案         | 覆盖**所有金融机构**，不只本公司 |
| **合作历史**       | 客户在**本公司**的历史业务往来       | 内部数据，范围窄于征信        |
| **五级分类**       | 资产风险等级：正常、关注、次级、可疑、损失   | 后三类为不良             |
| **五级分类非正常账户数** | 征信中被归为「关注」及以下的账户个数      | 越大外部风险越高           |
| **司法涉诉**       | 客户涉及诉讼、执行等司法信息          | 知识图谱抽屉中展示          |
| **失信被执行人**     | 俗称「老赖」，有履行能力却拒不履行生效判决   | 高风险信号              |
| **限制高消费（限高）**  | 对失信人采取的惩戒（限制坐飞机、高铁一等座等） | 常与失信配套出现           |
| **需关注**        | 系统自动打出的风险标记（黄底 + 红字加粗）  | 命中逾期/征信/司法等规则时触发   |

## 四、业务类型与产品线


| 名词       | 一句话解释                     | 在合作历史中的差异点       |
| -------- | ------------------------- | ---------------- |
| **直租**   | 公司从厂商买新设备再租给客户            | 标准融资租赁           |
| **回租**   | 客户把已有设备「卖」给公司再租回，本质是融资    | 大单回租多「翻单」相关字段    |
| **翻单**   | 旧业务快到期时再做一笔新业务接续，类似「借新还旧」 | 回租场景需重点关注        |
| **授信**   | 预先批一个最高可做额度，额度内可快速做业务     | 环卫授信页少「经营情况」等字段  |
| **非授信**  | 没有预先额度，每笔单独审批             | 更灵活但更慢           |
| **零售**   | 金额较小、较标准化的业务              | 如环卫零售直租/授信       |
| **大单**   | 金额较大、审批更严的项目              | 如大单回租、大单通用       |
| **小企业**  | 面向小微企业的业务线                | 查承租人+关联企业+担保人    |
| **厂商租赁** | 与设备厂商合作获客，厂商可能担保/回购       | 查询范围同小企业         |
| **印包**   | 印刷包装行业业务线简称               | 只查承租人+担保人，不查关联企业 |
| **环卫**   | 环卫行业业务线                   | 查询主体更全，含经营情况等字段  |
| **经营情况** | 环卫特有：自营 / 挂靠 / 合作         | 可筛选；授信项目无此字段     |
| **闪光租**  | 文档中提及的数据/业务相关系统或接口体系      | 合作历史数据来源之一       |

## 五、流程与系统


| 名词                        | 一句话解释                                      | 备注                             |
| ------------------------- | ------------------------------------------ | ------------------------------ |
| **尽调（尽职调查）**              | 审批前摸清客户经营、财务、信用等真实情况                       | 合作历史属于尽调环节的参考信息                |
| **风控**                    | 分析调查结果，判断风险大小与可否承做                         | 与尽调、审批相邻但职责不同                  |
| **审批**                    | 各级决策人决定做不做、做多少                             | 合作历史供审批人参考                     |
| **尽调评审系统**                | 承载尽调与项目审批详情的系统                             | 合作历史模块所在系统                     |
| **项目审批详情页**               | 单个项目的审批信息总览页面                              | 合作历史为其中模块/页签                   |
| **信息完善性校验**               | 提交前检查必填信息是否齐全                              | 「合作历史说明」有数据时必填并参与校验            |
| **合作历史说明**                | 风控对历史合作情况的文字说明（最多 2000 字）                  | 有数据则必填，无数据则不展示                 |
| **CRM**                   | 客户关系管理系统（Customer Relationship Management） | 提供客户资料、关联方、权限等                 |
| **数据平台**                  | 对外提供合作历史等数据服务的平台                           | 更新/查询接口所在                      |
| **知识图谱 / 关系图谱**           | 用节点和连线展示客户两层内关联关系的可视化模块                    | 企业蓝、自然人橙、当前客户红                 |
| **一度关系**                  | 与承租人直接关联的主体                                | 节点过多时优先只保留一度                   |
| **两层关系**                  | 关联方的关联方                                    | 图谱默认展示范围                       |
| **查询状态（queryStatusEnum）** | 合作历史异步查询的状态码                               | 0成功 / 1失败 / 2查询中 / 3无数据 / 4未查询 |
| **轮询**                    | 更新发起后每隔一段时间再查结果（文档为 5 秒）                   | 因接口非实时返回                       |

## 六、易混对照（速查）


| 对比组                  | 怎么区分                       |
| -------------------- | -------------------------- |
| 承租人 vs 出租人 vs 担保人    | 付钱用设备的人 / 本公司 / 兜底还款的人     |
| 合同金额 vs 剩余本金         | 最初总额 vs 现在还欠多少             |
| 当前逾期 vs 历史逾期         | 现在还欠着（更高危）vs 以前逾期过已还清      |
| IRR vs 综合收益率 vs 利率   | 租金真实收益 / 含额外收入的收益 / 合同名义利率 |
| 存量风险敞口 vs 担保项目累计风险敞口 | 自己租的敞口 vs 帮别人担保的敞口         |
| 直租 vs 回租             | 买新设备租给客户 vs 用客户已有设备融资      |
| 授信 vs 非授信            | 先批额度再做 vs 每笔单独批            |
| 合作历史 vs 征信           | 只看本公司往来 vs 看全金融机构信用        |
| 失信被执行人 vs 限高         | 「老赖」身份 vs 对其采取的消费限制措施      |
| 尽调 vs 风控 vs 审批       | 查清事实 / 评估风险 / 拍板决策         |
