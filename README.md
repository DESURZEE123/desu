# 王怡阳 · 个人作品站

React + Vite 4 + TypeScript + Tailwind CSS 前端项目。根据视口宽度自动切换桌面端 / 移动端两套布局。

## 开发

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
npm run preview
```

## 结构

- `src/components/Desktop` — 桌面端布局（≥768px）
- `src/components/Mobile` — 移动端布局（&lt;768px）
- `prd.html` — 原始静态原型（参考）
- `resume.html` — 原简历静态页备份
