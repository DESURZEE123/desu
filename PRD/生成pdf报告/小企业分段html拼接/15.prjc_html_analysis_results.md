# AI分析结果 · HTML 直出

> 所属：小企业分段 HTML 拼接（`小企业分段html拼接`）  
> 模块索引：**15**  
> 上游：用户传入的尽调项目全量参数  
> 样式规范：`prjc_html_style.md`  
> **本 Skill 直接输出模块 HTML 片段（含顶栏与内容），不输出文档壳与 `<style>`。**

## 一、Skill Role

本 Skill 从用户传入参数中提取 `analysisResults` 数组，按 `analysisType` 分组、映射中文展示名，将 `analysisConclusion` 的 **Markdown 转为 HTML**，并**直接输出**符合 `prjc_html_style.md` 的模块 HTML 片段。

AI 在本层负责：字段提取、分组排序、空值规范化、Markdown→HTML、结构组装。  
**不做**业务分析、不改写 AI 结论语义；**不**输出文档壳、`<style>`；**不展示** `analysisDetail`。

> 当前 PDF **仅按小企业（`prjc-slb`）**输出；本模块字段结构固定。若入参无 `analysisResults` 或为空数组，整模块不输出。

## 二、模块标识

| 字段 | 值 |
| ---- | -- |
| `moduleIndex` | `15` |
| `moduleKey` | `analysis_results` |
| `moduleName` | `AI分析结果` |

## 三、数据来源

| 来源路径 | 说明 |
| -------- | ---- |
| `analysisResults[]` | 模块主数据：AI 分析结果列表 |
| `analysisResults[].analysisType` | 分析类型（分组标题，如「项目司法分析」「项目流水分析」） |
| `analysisResults[].customerName` | 客户名称（司法分析按客户分行；流水分析可为空） |
| `analysisResults[].customerNo` | 客户编号（仅数据匹配，**不输出**） |
| `analysisResults[].analysisConclusion` | 分析结论（**Markdown 原文**，PDF 唯一展示内容） |
| `analysisResults[].analysisDetail` | 分析详情（**PDF 不展示**，不提取） |
| `analysisResults[].taskStatus` | 任务状态（默认不输出） |
| `analysisResults[].pkAnalysisResult` | 结果主键（不输出） |

## 四、生成流程

```text
1. 读取 analysisResults；若 null / 非数组 / 长度为 0 → 整模块不输出
2. 按 analysisType 分组（见第五节固定顺序）
3. 组内按入参数组原始顺序保留条目
4. 每个 analysisType 输出一个 report-analysis-list 块
5. 对 conclusion 做空值规范化；有 Markdown 则转 HTML 写入 .report-md
6. 输出带顶栏的 report-module HTML 片段 → 交由 00 拼接
```

## 五、输出规则 / 可见性

### 5.1 分组与展示顺序

| 顺序 | analysisType | blockKey | 说明 |
| :--: | ------------ | -------- | ---- |
| 1 | `项目流水分析` | `cashflow_analysis` | 项目级；通常无 `customerName` |
| 2 | `项目司法分析` | `judicial_analysis` | 按客户分行；有 `customerName` 时展示实体标题 |

- 仅输出入参中**实际出现**的 `analysisType`；未出现的类型不输出空分组
- 若出现上表未列出的 `analysisType`：按首次出现顺序追加在固定类型之后，`label` 取 `analysisType` 原文，`blockKey` 取 `analysis_type_{序号}`

### 5.2 其它规则

| 规则 | 说明 |
| ---- | ---- |
| 实体标题 | `customerName` 非空才输出蓝色方点 + 名称 |
| 结论区 | 始终有灰底卡片；Markdown 渲染进 `.report-md`，否则「—」 |
| 详情 | **禁止**输出 `analysisDetail`、「查看详情」链接 |
| 空列表 | 某分组 `items` 为空时输出 `report-table-empty`（文案 `暂无分析结果`）；正常分组不会为空 |

## 六、字段映射与展示顺序

每个 `analysisType` → **1 个** `report-analysis-list`：

| 字段 | 来源 | 说明 |
| ---- | ---- | ---- |
| 分组标题 | `analysisType` | `report-section-title__text` |
| `items[].customerName` | `customerName` | 有值才渲染实体标题 |
| `items[].conclusion` | `analysisConclusion` | Markdown → HTML |

### 6.1 空值规范化（conclusion）

| 原值 | 规范化结果 | HTML 表现 |
| ---- | ---------- | --------- |
| `null` / `undefined` / `""` | 空 | `.report-analysis-item__empty` 显示「—」 |
| `"{}"`（空 JSON 对象字符串） | 空 | 同上 |
| 仅空白字符 | 空 | 同上 |
| 其他字符串 | **原样**作 Markdown 源 | 转 HTML 后写入 `.report-md` |

### 6.2 Markdown → HTML

结论 Markdown 转为语义 HTML，包裹在 `<div class="report-md">`：

| Markdown | HTML |
| -------- | ---- |
| `#` ~ `######` | `h1` ~ `h6` |
| 段落 | `p` |
| `-` / `*` / `1.` 列表 | `ul` / `ol` + `li` |
| `**text**` / `__text__` | `strong` |
| `*text*` / `_text_` | `em` |
| `` `code` `` | `code` |
| 围栏代码块 | `pre` > `code` |
| `>` 引用 | `blockquote` |
| `---` | `hr` |
| GFM 表格 | `table` > `thead` / `tbody`（用 `.report-md table`，**不用** `report-table`） |
| 裸链接 | 转义为文本（PDF 不做外链） |

**安全：** 禁止内联 `style`/`script`/事件属性；对 HTML 特殊字符转义。

## 八、空值与格式化

| 规则 | 说明 |
| ---- | ---- |
| conclusion 空 | 仍保留 item，展示「—」 |
| customerName 空 | 不输出实体标题行 |
| Markdown | 在本层转为 HTML；不保留源码到文本节点 |
| `analysisDetail` | 永不输出 |

## 九、约束

1. 必须可识别 `moduleIndex: 15`（`data-module-key="analysis_results"`）
2. 仅输出本模块 HTML 片段
3. 禁止内联 `style`；禁止文档壳与 `<style>`
4. 空结论展示「—」
5. 完整报告由 `00.prjc_html_report` 调度拼接
6. `analysisResults` 缺失或空数组：整模块不输出
7. **禁止**输出 `analysisDetail` 与「查看详情」
