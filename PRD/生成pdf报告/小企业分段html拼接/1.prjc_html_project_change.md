# 项目变更信息 · HTML 直出

> 所属：小企业分段 HTML 拼接（`小企业分段html拼接`）  
> 模块索引：**1**  
> 上游：用户传入的尽调项目全量参数  
> 样式规范：`prjc_html_style.md`  
> **本 Skill 直接输出模块 HTML 片段（含顶栏与内容），不输出文档壳与 `<style>`。**

## 一、Skill Role

本 Skill 从用户传入参数中提取 `projectChange`，按**小企业（`prjc-slb`）**页面「项目变更信息」字段范围映射中文展示名，并**直接输出**符合 `prjc_html_style.md` 的模块 HTML 片段。

AI 在本层负责：字段提取、展示映射、空值规范化、金额/文本格式化、HTML 结构组装。  
**不做**业务分析、条件重算；**不**输出文档壳、`<html>`/`<body>`、`<style>`。

## 二、模块标识

| 字段 | 值 |
| ---- | -- |
| `moduleIndex` | `1` |
| `moduleKey` | `project_change` |
| `moduleName` | `项目变更信息` |

## 三、数据来源

| 来源路径 | 说明 |
| -------- | ---- |
| `projectChange` | 模块主数据对象 |
| `projectChange.changeReason` | 审批变更原因 |
| `projectChange.changeType` | 审批变更类型（仅 `审批变更` / `审批修改` 时本模块才输出） |

## 四、生成流程

```text
1. 若 projectChange 为 null / 缺失：整模块不输出（返回空 / 由 00 跳过）
2. 若 changeType 不是「审批变更」或「审批修改」（含空 / 其他枚举如「初次评审」）：整模块不输出
3. 按固定顺序组装内容：changeReason（longText）→ changeType（kv）
4. 空值 →「—」；文本 trim 后原样展示
5. 输出带顶栏的 report-module HTML 片段 → 交由 00 拼接
```

## 五、输出规则 / 可见性

对齐页面截图展示逻辑：**仅审批变更 / 审批修改场景展示本模块**。

| 场景 | 处理方式 |
| ---- | -------- |
| `projectChange` 缺失 / `null` | 整模块不输出 |
| `changeType` 非「审批变更」且非「审批修改」（含空 / `null` /「初次评审」等） | 整模块不输出 |
| 已输出时 `changeReason` 为空 | 该字段展示「—」 |
| 枚举 / 文案 | 直接展示接口返回的中文值，不做码值转换 |

**展示形态：**

- 模块顶栏标题为「项目变更信息」
- 模块体内**不再**套一层分组标题（无蓝色圆点 `report-section-title`）
- `changeReason`：标签在上、内容在下（`report-longtext`）
- `changeType`：键值对（`report-kv`）

## 六、字段映射与展示顺序

模块内内容按以下顺序输出：

| 顺序 | 逻辑块 | label | HTML 形态 | 接口字段 |
| :--: | ------ | ----- | --------- | -------- |
| 1 | `changeReason` | `审批变更原因` | `report-longtext` | `projectChange.changeReason` |
| 2 | `changeType` | `审批变更类型` | `report-kv` | `projectChange.changeType` |

### 6.1 审批变更原因

| 字段 | 取值 | 格式化 |
| ---- | ---- | ------ |
| 展示值 | `projectChange.changeReason` | `trim` 首尾空白后原样展示；空 → `—` |

### 6.2 审批变更类型

| 字段 | 取值 | 格式化 |
| ---- | ---- | ------ |
| 展示值 | `projectChange.changeType` | `trim` 首尾空白后原样展示；空 → `—` |

## 七、HTML 输出结构

### 7.1 模块壳

```html
<div class="report-module" data-module-key="project_change">
  <div class="report-module__header">项目变更信息</div>
  <div class="report-module__body">
    <!-- 无 report-section-title；直接输出字段 -->
  </div>
</div>
```

### 7.2 审批变更原因（longText）

```html
<div class="report-block report-longtext">
  <div class="report-longtext__label">审批变更原因：</div>
  <div class="report-longtext__value">补充租赁物型号信息。</div>
</div>
```

### 7.3 审批变更类型（kv）

```html
<div class="report-kv">
  <span class="report-kv__label">审批变更类型：</span>
  <span class="report-kv__value">审批修改</span>
</div>
```

### 7.4 完整示例

```html
<div class="report-module" data-module-key="project_change">
  <div class="report-module__header">项目变更信息</div>
  <div class="report-module__body">
    <div class="report-block report-longtext">
      <div class="report-longtext__label">审批变更原因：</div>
      <div class="report-longtext__value">补充租赁物型号信息。</div>
    </div>
    <div class="report-kv">
      <span class="report-kv__label">审批变更类型：</span>
      <span class="report-kv__value">审批修改</span>
    </div>
  </div>
</div>
```

## 八、空值与格式化

| 规则 | 说明 |
| ---- | ---- |
| 空值占位 | `null` / `""` / 缺失 → 展示值填 `—` |
| 枚举 | 直接展示接口返回的中文值，不做码值转换 |
| 文本 | 不截断、不改写，原样透传 |
| HTML 转义 | 对 `<`、`>`、`&`、`"` 等做必要转义后写入文本节点 |

## 九、约束

1. 必须可识别 `moduleIndex: 1`（调度与调试用；HTML 以 `data-module-key="project_change"` 标识）
2. 仅输出本模块 HTML 片段（含 `report-module` 顶栏与内容）
3. 禁止内联 `style`；禁止文档壳与 `<style>`
4. 空值统一为 `—`
5. 完整报告由 `00.prjc_html_report` 调度拼接；本 Skill 输出不得作为最终整份 HTML 交付物
6. `projectChange` 缺失，或 `changeType` 非「审批变更」/「审批修改」时：整模块不输出，由 00 跳过拼接
