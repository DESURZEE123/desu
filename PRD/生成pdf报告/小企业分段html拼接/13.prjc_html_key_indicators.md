# 重点指标 · HTML 直出

> 所属：小企业分段 HTML 拼接（`小企业分段html拼接`）  
> 模块索引：**13**  
> 上游：用户传入的尽调项目全量参数  
> 样式规范：`prjc_html_style.md`  
> **本 Skill 直接输出模块 HTML 片段（含顶栏与内容），不输出文档壳与 `<style>`。**

## 一、Skill Role

本 Skill 从用户传入参数中提取 `keyIndicators`，按**小企业（`prjc-slb`）**页面字段范围映射中文展示名，并**直接输出**符合 `prjc_html_style.md` 的模块 HTML 片段。

AI 在本层负责：字段提取、展示映射、`elementList` 动态项插入、财务指标表透视与 `mergeSame` rowspan、空值规范化。  
**不做**指标计算、税票接口调用；**不**输出文档壳、`<style>`。

页面为「顶部重点指标栅格（每行 3 列）+ 承租人近 3 年主要财务指标表」；PDF 按同一顺序全部展开。

## 二、模块标识

| 字段 | 值 |
| ---- | -- |
| `moduleIndex` | `13` |
| `moduleKey` | `key_indicators` |
| `moduleName` | `重点指标` |

## 三、数据来源

| 来源路径 | 说明 |
| -------- | ---- |
| `keyIndicators` | 模块主数据对象 |
| `keyIndicators.yoyRevenueGrowthRate` | 近一年收入同期增长率(%) |
| `keyIndicators.generalProvisionRatio` | 营授比(%) |
| `keyIndicators.elementList[]` | 承租人 / 担保人抵押类负债占比动态列表 |
| `keyIndicators.elementList[].equivalentName` | 指标中文名（已含主体名称与单位） |
| `keyIndicators.elementList[].equivalentValue` | 指标值 |
| `keyIndicators.lesseeAndGuarantorsMortgageLiabilityRatio` | 承租人及担保人抵押类负债占比(%) |
| `keyIndicators.dailyAverageBalanceToIncomeRatio` | 日均余额收入比(%) |
| `keyIndicators.externalGuaranteeToIncomeRatio` | 对外担保收入比(%) |
| `keyIndicators.cashCoverageRatio` | 现金覆盖比(%) |
| `keyIndicators.financialIndicatorList[]` | 承租人近 3 年主要财务指标 |
| `keyIndicators.financialIndicatorList[].year` | 年份键，如 `202312` |
| `keyIndicators.financialIndicatorList[].dataType` | 数据类型，如 `合并` / `单体` |
| `keyIndicators.haveData` | 财务指标表是否有数据；`false` 时财务表走空态 |
| `keyIndicators.fsDataSourceType` | 财报数据来源类型（**默认不输出**） |

> PDF **不输出**「税票数据引入」等页面操作按钮。

## 四、生成流程

```text
1. 若 keyIndicators 为 null / 缺失：整模块不输出
2. 组装顶部重点指标 group（columns: 3），含 elementList 动态项
3. 按 financialIndicatorList 生成年份列，按固定行序展开财务指标表
4. 空值规范化为「—」；数值原样透传（不追加 %）
5. 输出带顶栏的 report-module HTML 片段 → 交由 00 拼接
```

## 五、输出规则 / 可见性

| 规则 | 说明 |
| ---- | ---- |
| `elementList` | 有几条输出几条；空则跳过动态项，固定指标仍输出 |
| `haveData === false` 或财务列表空 | 仍输出顶部指标；财务表走 `report-table-empty` |
| `netProfitMargin` | **不提取、不输出** |
| 税票引入按钮 | **不输出** |
| 顶部 `keyMetrics` | **不传**蓝色圆点小节标题（无 `report-section-title`） |
| 评估项目列 | 连续相同值用 `rowspan`（mergeSame） |

## 六、字段映射与展示顺序

| 顺序 | blockKey | label | HTML |
| :--: | -------- | ----- | ---- |
| 1 | `keyMetrics` | （不传） | `report-group` · columns: 3 |
| 2 | `financialIndicatorList` | `承租人近3年主要财务指标` | `report-table` |

### 6.1 顶部重点指标（columns: 3）

**children 组装顺序：**

| 顺序 | label | 接口字段 |
| :--: | ----- | -------- |
| 1 | 近一年收入同期增长率(%) | `yoyRevenueGrowthRate` |
| 2 | 营授比(%) | `generalProvisionRatio` |
| 3… | `equivalentName` 原文 | `elementList[i].equivalentValue` |
| 后 1 | 承租人及担保人抵押类负债占比(%) | `lesseeAndGuarantorsMortgageLiabilityRatio` |
| 后 2 | 日均余额收入比(%) | `dailyAverageBalanceToIncomeRatio` |
| 后 3 | 对外担保收入比(%) | `externalGuaranteeToIncomeRatio` |
| 后 4 | 现金覆盖比(%) | `cashCoverageRatio` |

**动态项规则：**

- 插入位置：固定在「营授比」之后、「承租人及担保人抵押类负债占比」之前
- `label`：**完整透传** `equivalentName`，不改写、不截断
- 列表为空：顺序变为 增长率 → 营授比 → 承租人及担保人占比 → 日均余额收入比 → 对外担保收入比 → 现金覆盖比
- 栅格 class：`report-grid__cell--w-33`

### 6.2 承租人近3年主要财务指标

**showIndex：** `false`  
**emptyText：** `暂无财务指标数据`

#### 动态列

| 列顺序 | label | key | 说明 |
| :----: | ----- | --- | ---- |
| 1 | 评估项目 | `category` | mergeSame → rowspan |
| 2 | 财务指标 | `indicator` | 固定中文 |
| 3… | `{year} {dataType}` | `y_{year}` | 如 `202312 合并`；`dataType` 空则仅 `year` |

- 年份列按 `financialIndicatorList` **年份升序**
- 同一 `year` 多条：以后出现的为准

#### 固定行序

| 顺序 | 评估项目 | 财务指标 | 接口字段 |
| :--: | -------- | -------- | -------- |
| 1 | 盈利能力 | 销售毛利率(%) | `grossProfitMargin` |
| 2 | 盈利能力 | ROA 资产净利率(%) | `returnOnAssets` |
| 3 | 盈利能力 | ROE 净资产收益率(%) | `returnOnEquity` |
| 4 | 运营能力 | 存货周转率 | `inventoryTurnover` |
| 5 | 运营能力 | 应收账款周转率 | `accountsReceivableTurnover` |
| 6 | 运营能力 | 总资产周转率 | `totalAssetTurnover` |
| 7 | 偿债能力 | 资产负债率(%) | `debtToAssetRatio` |
| 8 | 偿债能力 | 速动比率 | `quickRatio` |
| 9 | 偿债能力 | 流动比率 | `currentRatio` |
| 10 | 偿债能力 | 借款依存度(%) | `loanDependence` |
| 11 | 偿债能力 | 现金流动负债比率(%) | `cashFlowToCurrentLiabilitiesRatio` |
| 12 | 偿债能力 | 销售现金比率(%) | `cashSalesRatio` |
| 13 | 偿债能力 | 清算价值比率(%) | `liquidationValueRatio` |
| 14 | 发展能力 | 营业增长率(%) [财报数据] | `operatingRevenueGrowthRateFinancial` |
| 15 | 发展能力 | 资本积累率(%) | `capitalAccumulationRate` |
| 16 | 发展能力 | 总资产增长率(%) | `totalAssetGrowthRate` |

> 评估项目文案用「运营能力」（对齐页面）。若后续入参加入 `operatingRevenueGrowthRateInvoice`，插在「营业增长率(%) [财报数据]」之前，归属发展能力。

**空表判定：** `haveData === false` 或列表空 → `report-table-empty`。  
有数据时始终输出 16 行（或含发票增长率时 17 行），缺年份字段填 `—`，不因某年全空删行。

**mergeSame：** 「盈利能力」连续 3 行 rowspan=3；「运营能力」3 行；「偿债能力」7 行；「发展能力」3 行（有发票行则 4）。

## 八、空值与格式化

| 规则 | 说明 |
| ---- | ---- |
| 空值占位 | `null` / `""` / 缺失 → `—` |
| 数值透传 | 原样展示（如 `0.0000`、`98.25`），**不**强制补小数位，**不**追加 `%` |
| `equivalentName` / `dataType` | 直接展示 |
| `fsDataSourceType` | 不输出 |
| HTML 转义 | 文本节点转义 |

## 九、约束

1. 必须可识别 `moduleIndex: 13`（`data-module-key="key_indicators"`）
2. 仅输出本模块 HTML 片段
3. 禁止内联 `style`；禁止文档壳与 `<style>`
4. 空值统一为 `—`
5. 完整报告由 `00.prjc_html_report` 调度拼接
6. `keyIndicators` 缺失：整模块不输出
7. 不计算、不改写指标；`elementList` 名称完整透传
8. 顶部指标**无**蓝色小节标题；财务表评估项目列做 rowspan 合并
