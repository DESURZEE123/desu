# 重点科目财务报表 · HTML 直出

> 所属：小企业分段 HTML 拼接（`小企业分段html拼接`）  
> 模块索引：**14**  
> 上游：用户传入的尽调项目全量参数  
> 样式规范：`prjc_html_style.md`  
> **本 Skill 直接输出模块 HTML 片段（含顶栏与内容），不输出文档壳与 `<style>`。**

## 一、Skill Role

本 Skill 从用户传入参数中提取 `financialStatementsOfKeyAccounts`，按**小企业（`prjc-slb`）**页面字段范围映射中文展示名，并**直接输出**符合 `prjc_html_style.md` 的模块 HTML 片段。

AI 在本层负责：字段提取、按期透视展开、行级样式（`rowLevel`）、金额格式化、主体标题栏与资产负债表/利润表 HTML 组装。  
**不做**税票 / 财报分析接口调用；**不**输出文档壳、`<style>`。

页面为「按主体展开的资产负债表 + 利润表 + 模块级财务说明」；PDF **全部展开**（无「财报分析」跳转、无上传主体财报等交互）。

## 二、模块标识

| 字段 | 值 |
| ---- | -- |
| `moduleIndex` | `14` |
| `moduleKey` | `key_account_financials` |
| `moduleName` | `重点科目财务报表` |

## 三、数据来源

| 来源路径 | 说明 |
| -------- | ---- |
| `financialStatementsOfKeyAccounts` | 模块主数据对象 |
| `financialStatementsOfKeyAccounts.financialStatementsOfKeyAccountList[]` | 各主体财报表 |
| `….sheetName` | 主体标题（如「承租人XXX重点科目财务报表」） |
| `….fsDataSourceType` | 数据来源（展示「数据来源：{值}」） |
| `….balanceSheet[]` | 资产负债表按期明细 |
| `….profitSheet[]` | 利润表按期明细 |
| `….balanceSheet[].period` / `….profitSheet[].period` | 期间列头，如 `202312` |
| `….balanceSheet[].dataType` / `….profitSheet[].dataType` | 单体 / 合并（列头红标） |
| `financialStatementsOfKeyAccounts.financialNotes` | 财务说明（模块级，全部主体表之后） |

**PDF 不提取 / 不输出：**

| 字段 / 能力 | 原因 |
| ----------- | ---- |
| `creditCode` / `customerNo` / `periodType` | 仅数据匹配 |
| `financialIndex[]` | 本页截图不展示（重点指标模块另有表） |
| 「财报分析」「上传主体财报」「税票授权财报引入」 | 页面交互 |

## 四、生成流程

```text
1. 若 financialStatementsOfKeyAccounts 为 null / 缺失：整模块不输出
2. 遍历 financialStatementsOfKeyAccountList（保持入参顺序）
3. 每个主体输出：主体标题栏 → 资产负债表 → 利润表
4. 全部主体结束后，若 financialNotes 有值：输出「财务说明」longText
5. 空值 →「—」；有值金额千分位保留 2 位；0.00 原样展示
6. 输出带顶栏的 report-module HTML 片段 → 交由 00 拼接
```

## 五、输出规则 / 可见性

| 规则 | 说明 |
| ---- | ---- |
| `balanceSheet` / `profitSheet` 空 | 仍输出对应表标题 + `report-table-empty`「暂无数据」 |
| 期间列 | 按数组顺序提取不重复 `period`；列头带 `dataType` 红标 |
| 资产负债 vs 利润期间 | 可不一致（各自独立透视） |
| `rowLevel` | `1` 一级合计粉底加粗；`2` 二级小计黄底加粗；`3` 明细缩进 |
| 财报分析按钮 | **不输出** |

## 六、字段映射与展示顺序

| 顺序 | blockKey | HTML | 说明 |

## 八、空值与格式化

| 规则 | 说明 |
| ---- | ---- |
| 空值占位 | `null` / `""` / 缺失 → `—` |
| 金额 | 千分位 + 2 位小数；含 `0.00` 与负数 |
| 期间 / dataType | 原样；dataType 渲染为红标 |
| `financialNotes` 空 | 不输出该块 |
| HTML 转义 | 文本节点转义 |

## 九、约束

1. 必须可识别 `moduleIndex: 14`（`data-module-key="key_account_financials"`）
2. 仅输出本模块 HTML 片段
3. 禁止内联 `style`；禁止文档壳与 `<style>`（行级背景用 class，不用 inline）
4. 空值统一为 `—`
5. 完整报告由 `00.prjc_html_report` 调度拼接
6. `financialStatementsOfKeyAccounts` 缺失：整模块不输出
7. 资产负债表 / 利润表行序必须严格按 §6.3 / §6.4，不得增删科目
8. 禁止输出财报分析 / 上传 / 税票引入等交互
