# 承租人基本信息 · HTML 直出

> 所属：小企业分段 HTML 拼接（`小企业分段html拼接`）  
> 模块索引：**8**  
> 上游：用户传入的尽调项目全量参数  
> 样式规范：`prjc_html_style.md`  
> **本 Skill 直接输出模块 HTML 片段（含顶栏与内容），不输出文档壳与 `<style>`。**

## 一、Skill Role

本 Skill 从用户传入参数中提取 `lesseeBaseInfo.companyPublicInfo`，按**小企业（`prjc-slb`）**页面字段范围映射中文展示名，并**直接输出**符合 `prjc_html_style.md` 的模块 HTML 片段。

AI 在本层负责：字段提取、展示映射、金额格式化、诉讼卡片过滤与 HTML 组装。  
**不**调用法人客户 / 司法涉诉接口；**不**输出文档壳与 `<style>`。

页面为「基本信息 + 行业许可证 + 主营业务 + 公司沿革 + 股权结构 + 实控人介绍 + 司法诉讼总览 + 司法诉讼说明」；PDF **按顺序全部展开**（无编辑按钮 / 更新司法涉诉数据等交互）。

> 若 `lesseeBaseInfo` 或 `companyPublicInfo` 为 null / 缺失，整模块不输出。

## 二、模块标识

| 字段 | 值 |
| ---- | -- |
| `moduleIndex` | `8` |
| `moduleKey` | `lessee_base_info` |
| `moduleName` | `承租人基本信息` |

## 四、生成流程

```text
1. 若 lesseeBaseInfo.companyPublicInfo 为 null / 缺失：整模块不输出
2. 输出「基本信息」sectionHeading（蓝竖条）
3. 输出「基本信息」group（4 列栅格，注册地址整行；无 label，避免与大区标题重复）
4. 输出「行业许可证」table（圆点小标题）
5. 输出「主营业务」「公司沿革」longText（有值时）
6. 输出「股权结构」table + 合计行
7. 输出「实控人及股东情况介绍」longText（有值时）
8. 输出「司法诉讼信息」sectionHeading
9. 输出诉讼卡片 litigationCards（无外层 label；caseNum=0 的标签不展示）
10. 输出「司法诉讼信息说明」longText（有值时）
11. 空值规范化为「—」；数值原样透传
12. 输出 report-module HTML 片段 → 交由 00 拼接
```

## 五、输出规则 / 可见性

- 各表 `null` / `[]`：仍输出对应 table 块，走空态文案
- 各说明类长文本为空：不输出该 longText 块
- 司法标签：`caseNum === 0` 或缺失时不输出该卡片
- 高风险标签（`caseTypeHighRiskList`）→ tone `highRisk`（红底卡片）
- 普通标签（`caseTypeCommonList`）→ tone `common`（蓝底卡片）
- 「更新司法涉诉数据」：PDF **不输出**

**标题层级：**

- 「基本信息」「司法诉讼信息」用 `report-section-heading`（蓝竖条）作大标题
- 其下原内容标题若与大标题同名则不再传 label（基本信息 group / 诉讼卡片区无圆点标题）
- 其余圆点小标题（行业许可证 / 股权结构 / 主营业务等）保持不变

### 6.1 基本信息（group · columns: 4 · 无 label）

数据来源：`companyPublicInfo.baseInfo`

| 顺序 | label | 接口字段 | 说明 |
| :--: | ----- | -------- | ---- |
| 1 | 企业名称 | `customerName` | |
| 2 | 统一社会信用代码 | `crdntlsCode` | |
| 3 | 法定代表人 | `legalRepresentativeCustomerName` | |
| 4 | 实际控制人 | `actControlsName` | |
| 5 | 成立时间 | `estblshDate` | |
| 6 | 注册资本(万元) | `rgstrdCapital` | 千分位格式化 |
| 7 | 行业小类 | `pkIndustrySortLittle.name` | 对象取 `name` |
| 8 | 从业人数 | `employeeNum` | |
| 9 | 注册地址 | `rgstrdAddress` | `fullWidth` → `--w-100` |

### 6.2 行业许可证（table）

| 顺序 | 列 label | key |
| :--: | -------- | --- |
| 1 | 证件名称 | `specCrdntlsName` |
| 2 | 编号 | `specCrdntlsCode` |
| 3 | 期限 | `expirationDate` |

- `showIndex`: `true`
- 空态：`暂无行业许可证数据`

### 6.3 主营业务 / 公司沿革（longText）

| 逻辑块 | label | 接口字段 |
| ------ | ----- | -------- |
| `mainBusiness` | `主营业务` | `baseInfo.mainBusiness` |
| `companyEvolution` | `公司沿革` | `baseInfo.companyEvolution` |

有值时输出，空 / null 不输出。

### 6.4 股权结构（table）

| 顺序 | 列 label | key |
| :--: | -------- | --- |
| 1 | 股东名称 | `shareholderName` |
| 2 | 出资额(万元) | `shareholderCapitalAmount` |
| 3 | 占比(%) | `holdStockRatio` |

- `showIndex`: `true`
- 空态：`暂无股权结构数据`
- **合计行：** 取自 `shareholderTotal`；股东名称列展示 `合计`

### 6.5 实控人及股东情况介绍（longText）

数据来源：`controllerIntroduction`；有值时输出。

### 6.6 司法诉讼信息（litigationCards）

数据来源：`judicialLitigationInfo`

| 属性 | 说明 |
| ---- | ---- |
| `updateTime` | 展示为「司法诉讼数据更新时间：{time}」（可置于卡片区上方右侧） |
| `cards[]` | 先 `caseTypeHighRiskList`，再 `caseTypeCommonList`；过滤 `caseNum <= 0` |
| `cards[].caseType` | 案件类型标签名 |
| `cards[].caseNum` | 案件数量（卡片右上角） |
| `cards[].tone` | `highRisk` / `common` |
| 空态 | `客户暂无司法诉讼数据` |

**tone 样式：**

| tone | 说明 |
| ---- | ---- |
| `highRisk` | 红渐变底；被执行人、强制清算与破产案件、限制高消费等 |
| `common` | 蓝渐变底；民事案件、执行案件等 |

布局：卡片左起自动换行，**宽度适中**（约 3 列量级），**不按一行卡片数均分拉满**；右上角数量、居中案件类型。

## 七、HTML 输出结构

### 7.3 行业许可证 / 股权结构（标准表）

```html
<div class="report-block report-table-block">
  <div class="report-section-title">
    <span class="report-section-title__dot"></span>
    <span class="report-section-title__text">行业许可证</span>
  </div>
  <table class="report-table">
    <thead>
      <tr>
        <th>序号</th>
        <th>证件名称</th>

        <th>期限</th>
      </tr>
    </thead>
    <tbody><!-- rows 或 empty --></tbody>

```

股权结构含合计行：

```html
<tr class="report-table__summary-row">
  <td class="report-table__cell--strong">合计</td>
  <td class="report-table__cell--strong">合计</td>
  <td class="report-table__cell--strong">{shareholderTotal.出资额}</td>
  <td class="report-table__cell--strong">{shareholderTotal.占比}</td>
</tr>
```

> 若 `showIndex=true`，合计行首列为「合计」（或按 `summary.index`），股东名称列也可为「合计」——以 `shareholderTotal` 字段映射为准，名称列展示「合计」。

### 7.4 主营业务等 longText（保留圆点标题语义：用 longText label）

```html
<div class="report-block report-longtext">
  <div class="report-longtext__label">主营业务：</div>
  <div class="report-longtext__value">高新纤维与功能性复合面料的研发、生产及一体化供应链服务…</div>
```

> 若需与页面圆点小标题视觉一致，可在 longText 外另加 `report-section-title`；默认以 `report-longtext__label` 作为小标题即可（与其它模块 longText 一致）。需要圆点时推荐：

```html
<div class="report-block">
  <div class="report-section-title">
    <span class="report-section-title__dot"></span>
    <span class="report-section-title__text">主营业务</span>
  </div>
  <div class="report-longtext">
    <div class="report-longtext__value">……</div>
  </div>
</div>
```

本模块「主营业务 / 公司沿革 / 实控人介绍 / 司法诉讼说明」**保留圆点小标题**，采用上式（圆点标题 + 仅 value 的 longText）。

## 八、空值与格式化

| 规则 | 说明 |
| ---- | ---- |
| 空值占位 | `null` / `""` / 缺失 → `—` |
| 注册资本等金额 | 千分位格式化 |
| 行业小类 | 对象取 `name` |
| 诉讼卡片 | `caseNum <= 0` 剔除，不展示 0 卡片 |
| 长文本 | 空则整块不输出（非填 `—`） |
| 表格空 | 仍输出标题 + `report-table-empty` |

## 九、约束

1. 必须可识别 `moduleIndex: 8`
2. 仅输出本模块 HTML 片段
3. 禁止内联 `style`；禁止文档壳与 `<style>`
4. 空值统一为 `—`（长文本空块跳过除外）
5. 完整报告由 `00.prjc_html_report` 调度拼接
6. 「基本信息」「司法诉讼信息」必须用蓝竖条 `report-section-heading`，禁止用空 group 圆点冒充
7. 不输出更新司法涉诉按钮、主键、内嵌合作历史等页面能力
8. `lesseeBaseInfo` / `companyPublicInfo` 缺失时整模块不输出
