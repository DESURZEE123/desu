# 项目概要 · HTML 直出

> 所属：小企业分段 HTML 拼接（`小企业分段html拼接`）  
> 模块索引：**2**  
> 上游：用户传入的尽调项目全量参数  
> 样式规范：`prjc_html_style.md`  
> **本 Skill 直接输出模块 HTML 片段（含顶栏与内容），不输出文档壳与 `<style>`。**

## 一、Skill Role

本 Skill 从用户传入参数中提取 `labelInfo`，按**小企业（`prjc-slb`）**页面字段范围映射中文展示名，并**直接输出**符合 `prjc_html_style.md` 的模块 HTML 片段。

AI 在本层负责：字段提取、展示映射、清单过滤、空值规范化、HTML 结构组装。  
**不做**标签条件计算、不调用外部接口；**不**输出文档壳与 `<style>`。

页面为「警示清单 / 负面清单双卡 + 突破说明」；PDF 按同一顺序全部展开输出（无链接弹窗、无悬浮省略交互）。

## 二、模块标识

| 字段 | 值 |
| ---- | -- |
| `moduleIndex` | `2` |
| `moduleKey` | `project_summary` |
| `moduleName` | `项目概要` |

## 三、数据来源

| 来源路径 | 说明 |
| -------- | ---- |
| `labelInfo` | 模块主数据对象 |
| `labelInfo.riskLabel[]` | 警示清单条目（字符串数组） |
| `labelInfo.negativeList[]` | 负面清单条目（字符串数组） |
| `labelInfo.labelDesc` | 突破负面清单/警示清单说明 |
| `labelInfo.queryTime` | 数据更新时间（**PDF 不输出**） |
| `labelInfo.highlightLabel[]` | 高亮标签（预留；**PDF 不输出**） |
| `labelInfo.status` | 查询状态（仅数据匹配，**不输出**） |
| `labelInfo.pkRecord` | 记录主键（仅数据匹配，**不输出**） |

> PDF **不输出**变更记录弹窗、标签链接下划线交互、重新计算按钮、顶栏数据更新时间等页面能力。

## 四、生成流程

```text
1. 若 labelInfo 为 null / 缺失：整模块不输出
2. 过滤 riskLabel / negativeList 中 null / "" / 仅空白条目
3. 若两清单过滤后皆空且无有效 labelDesc：整模块不输出
4. 组装 labelPanel 双卡（仅输出有数据的清单卡）
5. 若任一方清单有数据：组装突破说明 longText（空则「—」）
6. 输出 report-module HTML 片段 → 交由 00 拼接
```

## 五、输出规则 / 可见性

| 场景 | 处理方式 |
| ---- | -------- |
| `labelInfo` 缺失 | 整模块不输出 |
| `riskLabel` 为空 / `[]`（过滤后） | 不输出警示清单卡 |
| `negativeList` 为空 / `[]`（过滤后） | 不输出负面清单卡 |
| 两清单皆空且无 `labelDesc` | 整模块不输出 |
| `labelDesc` | 仅当 `riskLabel` 或 `negativeList` 至少一方有数据时输出 |
| `highlightLabel` | 不输出 |

**清单条目规则：**

- 按接口数组顺序原样透传文案，不改写、不截断
- 过滤 `null` / `""` / 仅空白条目；过滤后数组为空则视为该清单无数据
- 页面超长省略 + 悬浮完整展示：**PDF 全文展示**，不做省略号截断
- 仅一方有数据时：单卡仍按页面卡样式渲染（宽度对齐双卡布局）
- 两方皆空：不输出 labelPanel 区域

## 六、字段映射与展示顺序

| 顺序 | 逻辑块 | label | HTML 形态 | 说明 |
| :--: | ------ | ----- | --------- | ---- |
| 1 | `labelPanel` | （无外层 label） | `report-label-panel` | 警示 / 负面双卡；仅含非空清单 |
| 2 | `labelDesc` | `突破负面清单/警示清单说明` | `report-longtext` | 任一方清单有数据时 |

### 6.1 清单双卡（labelPanel）

| 字段 | 类型 | 说明 |
| ---- | ---- | ---- |
| 卡片顺序 | — | 固定：警示 → 负面 |
| 警示卡 | — | `blockKey=riskLabel`；卡头「警示清单」；tone=`warning` → `report-label-card--warning` |
| 负面卡 | — | `blockKey=negativeList`；卡头「负面清单」；tone=`negative` → `report-label-card--negative` |
| `items[]` | string[] | 清单条目，按入参顺序 |

### 6.2 突破说明（longText）

| 项 | 规则 |
| -- | ---- |
| 数据来源 | `labelInfo.labelDesc` |
| 输出条件 | 警示或负面至少一方有数据 |
| 空值 | 有清单但说明未填 → `—` |
| label | 固定「突破负面清单/警示清单说明」；**不渲染**页面必填红星 `*` |

## 八、空值与格式化

| 规则 | 说明 |
| ---- | ---- |
| 空值占位 | `null` / `""` / 仅空白 → 展示值填 `—`（清单 `items` 中空白条目直接剔除，不进入列表） |
| 清单文案 | 原样透传，保留全角符号（如 `＜`） |
| 说明文本 | `labelDesc` trim 首尾空白后输出 |
| 数组顺序 | 按接口返回顺序，不重排 |
| HTML 转义 | 清单条目与说明写入前做必要转义 |

## 九、约束

1. 必须可识别 `moduleIndex: 2`
2. 仅输出本模块 HTML 片段
3. 禁止内联 `style`；禁止文档壳与 `<style>`
4. 空值统一为 `—`（清单空白条目剔除，不填 `—`）
5. 完整报告由 `00.prjc_html_report` 调度拼接
6. 不输出 `queryTime` / `updateTime` / `status` / `pkRecord` / `highlightLabel` 及页面交互能力
7. 不做标签条件重算；以入参 `labelInfo` 已落库数据为准
8. 清单条目在 PDF 中**完整展示**；不做 hover 省略；页面变更记录链接按纯文本输出
