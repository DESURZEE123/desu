# 经营数据分析 · HTML 直出

> 所属：小企业分段 HTML 拼接（`小企业分段html拼接`）  
> 模块索引：**11**  
> 上游：用户传入的尽调项目全量参数  
> 样式规范：`prjc_html_style.md`  
> **本 Skill 直接输出模块 HTML 片段（含顶栏与内容），不输出文档壳与 `<style>`。**

## 一、Skill Role

本 Skill 从用户传入参数中提取 `revenueAnalysis`，按**小企业（`prjc-slb`）**页面字段范围映射中文展示名，并**直接输出**符合 `prjc_html_style.md` 的模块 HTML 片段。

AI 在本层负责：字段提取、展示映射、分组/透视、`roleTag` / `mergeSame` / 叠行宽表、营业收入分析与核验透视表、空值规范化。  
**不做**税票/流水接口调用、不筛选主体；**不**输出文档壳、`<style>`。

页面为「主体列表 + 资产规模 + 生产销售情况分析 + 收入分析 + 还款能力分析」；PDF **按顺序全部展开**。宽表（列数 > 8）输出为 `report-table--stacked`。

## 四、生成流程

```text
1. 若 revenueAnalysis 为 null / 缺失：整模块不输出
2. 输出主体列表 table
3. 输出「资产规模」sectionHeading + 厂房 / 设备 / 稼动率相关块
4. 输出「生产销售情况分析」sectionHeading + 主营产品 / 说明 / 下游客户块
5. 输出「收入分析」sectionHeading + 营业收入分析 / 核验 / 说明块
6. 输出「还款能力分析」sectionHeading + 基础信息 / 收支明细 / 指标 / 说明块
7. 空值规范化为「—」；数值原样透传（不追加 %）
8. 输出带顶栏的 report-module HTML 片段 → 交由 00 拼接
```

## 五、输出规则 / 可见性

| 规则 | 说明 |
| ---- | ---- |
| 各表 null / [] | 仍输出 table 块，走 emptyText |
| 说明类长文本空 | 不输出该 longText 块 |
| `factoryType` | `0`→自有、`1`→租用、`2`→无厂房；无法识别则原样或 `—` |
| `paymentMethod[]` | 多选用 `/` 拼接（如 `现金/银行承兑`） |
| 主体角色 | `customerRole[]` → `report-role-tag`（`cellType: roleTag`） |
| 分组表 | 主营产品 / 下游客户：每组末尾「合计」行；主体名称与角色 mergeSame |
| 营业收入分析 / 核验 | 动态时间列；底部汇总行首列跨 3 列 |
| 银行流水高亮 | 展示仍用 `bankStatement`；`bankStatementFromJz` 有值且不同 → `.report-table__cell--highlight` |

### 6.7 营业收入分析（透视）

**showIndex：** `false` · **emptyText：** `暂无营业收入分析数据`

#### 列定义

| 顺序 | 列 | 来源 | 说明 |
| :--: | -- | ---- | ---- |
| 1 | 主体名称 | `customerName` → `subjectName` | mergeSame（同一主体两行） |
| 2 | 主体角色 | `customerRole` | mergeSame + roleTag |
| 3 | 类型 | 固定文案 | `开票收入(万)` / `不开票收入(万)` |
| 4… | `{timeInterval}` | 动态列 | 列头取 `timeInterval` 原文；按 `serialNumber` 升序去重 |

#### 明细行

1. 按 `serialNumber` 升序提取不重复 `timeInterval`  
2. 按 `customerNo` 分组（保持首次出现顺序）；每组 **2** 行：

| type | 各动态列取值 |
| ---- | ------------ |
| `开票收入(万)` | `invoicingRevenue` |
| `不开票收入(万)` | `nonInvoicingRevenue` |

3. 同一主体 `subjectName` / `customerRole` rowspan=2  
4. 某主体某区间缺失 → `—`  
5. **不输出** `amountTotal` / `pkRevenueAnalysis` / `startYear` / `endYear`

#### 底部汇总行（`operatingIncomeAnalysisTotal[]`）

共 **3** 行；首列文案跨「主体名称 / 主体角色 / 类型」三列（`colspan="3"`）：

| 顺序 | 汇总 label | 各动态列字段 |
| :--: | ---------- | ------------ |
| 1 | `合计(万)` | `invoicingRevenue` |
| 2 | `关联交易(万)` | `relatedTransaction` |
| 3 | `剔除关联交易后合计(万)` | `excludeRelatedTransaction` |

- 匹配键：`timeInterval` ≡ 动态列  
- **禁止**用明细行自行加总替代后端合计对象

后续：`operatingIncomeDesc`（longText）；`verifiableRatio`（取 `incomeAnalysis.ratio`，有值时）。

| 顺序 | type | 字段 | 备注 |

**银行流水高亮：** 展示值始终 `bankStatement`；当 `bankStatementFromJz` 有值且 ≠ `bankStatement` 时，该单元格加 `report-table__cell--highlight`；**不**用 FromJz 替换展示值；FromJz **不单独成列**。

#### 底部汇总 3 行

| 顺序 | label | 月列字段 |
| :--: | ----- | -------- |
| 1 | `流水与承兑合计(万)(剔除关联交易)` | `totalFlow` |

## 八、空值与格式化

| 规则 | 说明 |
| ---- | ---- |
| 空值占位 | `null` / `""` / 缺失 → `—` |
| 数值 | 原样透传，**不**追加 `%` |
| 百分比 / 金额 | 按源字段原样；不强制补位 |
| 缺失月/年 | 格填 `—`，不参与合计/均值 |
| HTML 转义 | 文本节点转义 |

## 九、约束

1. 必须可识别 `moduleIndex: 11`（`data-module-key="revenue_analysis"`）
2. 仅输出本模块 HTML 片段
3. 禁止内联 `style`；禁止文档壳与 `<style>`
4. 空值统一为 `—`
5. 完整报告由 `00.prjc_html_report` 调度拼接
6. `revenueAnalysis` 缺失：整模块不输出
7. 大区标题必须用 `report-section-heading`；内容标题用圆点 `report-section-title`
8. 透视合计行必须以接口 Total 对象为准，禁止前端自行加总替代
9. 禁止输出筛选主体 / 信息完善 badge 等交互
