# 实施方案 · HTML 直出

> 所属：小企业分段 HTML 拼接（`小企业分段html拼接`）  
> 模块索引：**6**  
> 上游：用户传入的尽调项目全量参数  
> 样式规范：`prjc_html_style.md`  
> **本 Skill 直接输出模块 HTML 片段（含顶栏与内容），不输出文档壳与 `<style>`。**

## 一、Skill Role

本 Skill 从用户传入参数中提取 `embodiment`（及同构报价 / 增信子对象），按**小企业（`prjc-slb`）**页面字段范围映射中文展示名，并**直接输出**符合 `prjc_html_style.md` 的模块 HTML 片段。

AI 在本层负责：字段提取、多报价展开、展示映射、金额格式化、增信卡片 HTML 组装。  
**不做**业务分析、不计算风险敞口；**不**输出文档壳与 `<style>`。

页面为 Tab 的「租金计划表 / 保证金计划 / 其他收支计划」在 PDF 中**按顺序全部展开**输出（无 Tab 交互）。

## 二、模块标识

| 字段 | 值 |
| ---- | -- |
| `moduleIndex` | `6` |
| `moduleKey` | `implementation_plan` |
| `moduleName` | `实施方案` |

## 三、数据来源

| 来源路径 | 说明 |
| -------- | ---- |
| `embodiment` | 模块主数据对象 |
| `embodiment.riskExposure` | 预测风险敞口(元) |
| `embodiment.rate` | 预测风险敞口/设备原值(%) |
| `embodiment.lesseeAggregateRiskExposure` | 承租人累计风险敞口(元) |
| `embodiment.aggregateRiskExposure` | 承租人及关联方累计风险敞口(元) |
| `embodiment.advertisingInfoList[]` | 报价方案列表（投放信息 / 付款条件 / 各类计划） |
| `embodiment.advertisingInfoList[].paymentTermList` | 付款条件及笔数 |
| `embodiment.advertisingInfoList[].rentPlan` | 租金计划表（含汇总 + 明细） |
| `embodiment.advertisingInfoList[].depositPlan` | 保证金计划 |
| `embodiment.advertisingInfoList[].otherPlan` | 其他收支计划 |
| `commonCreditEnhancementMeasure.creditEnhancementMeasureList[]` | 按 `quotName` 匹配的增信措施（优先） |
| `embodiment.creditEnhancementMeasureInfo` | 实施方案内嵌增信措施（次选） |
| `creditEnhancementMeasure` | 顶层增信措施（兜底） |

> 多报价时，按 `advertisingInfoList` 接口返回顺序逐条输出；每条报价以其 `quotName` 作为 `sectionHeading`。

## 四、生成流程

```text
1. 从 embodiment 提取风险敞口汇总字段 → group（无标题）
2. 若 advertisingInfoList 为空：可输出 empty「暂无关联报价」；跳过报价子块
3. 遍历 advertisingInfoList：
   a. sectionHeading（quotName）
   b. 投放信息 group
   c. 付款条件 table
   d. 租金计划汇总 group + 明细 table
   e. 保证金计划 table
   f. 其他收支计划 table
   g. 增信措施 measureList
4. 输出 report-module HTML 片段 → 交由 00 拼接
```

## 五、输出规则 / 可见性

| 分组 / 字段 | 是否输出 |
| ----------- | :------: |
| 风险敞口汇总（4 项） | ✅ |
| 报价方案（`quotName` 大区标题） | ✅ |
| 投放信息（含贴息、银票收益率、是否调息） | ✅ |
| 付款条件及笔数 | ✅ |
| 租金计划表（汇总 + 明细） | ✅ |
| 保证金计划 | ✅ |
| 其他收支计划 | ✅ |
| 增信措施 | ✅ |
| 保险规则 / 保险 | — |
| 单瓦融资额 | — |
| 支付方式 / 备注（环卫专属） | — |

**空数据规则：**

- `advertisingInfoList` 为 `null` / `[]`：仍输出风险敞口汇总；不输出报价子块，可追加空态「暂无关联报价」
- 单表为空：该表走对应空态文案，其余块正常输出
- 增信措施列表为空：输出圆点标题 + `report-table-empty`，文案 `暂无增信措施`

**页面交互不输出：** 关联报价 / 取消关联 / 编辑 / 保存、知识图谱等

## 六、字段映射与展示顺序

| 顺序 | 逻辑块 | label | HTML 形态 |
| :--: | ------ | ----- | --------- |

### 6.1 风险敞口汇总（group · 无标题）

| 承租人及关联方累计风险敞口(元) | `aggregateRiskExposure` | 千分位 + 2 位小数 |

### 6.9 增信措施（measureList）

数据来源（按优先级）：

1. `commonCreditEnhancementMeasure.creditEnhancementMeasureList` 中 `quotName` 与当前报价一致的项 → 其内层 `creditEnhancementMeasureList`
2. `embodiment.creditEnhancementMeasureInfo.creditEnhancementMeasureList`
3. `creditEnhancementMeasure.creditEnhancementMeasureList`（若带 `quotName` 则按报价过滤）

#### 6.9.1 卡片主字段

| 字段 | key / 规则 | 格式化 |
| ---- | ---------- | ------ |
| 担保方式文案 | `guaranteeMethod` | 取对象 `desc`；已是字符串则原样 |
| 担保方式色调 | `guaranteeTone` | 见下表 → `report-measure-card__tag--{tone}` |
| 客户名称 | `customerName` | 原样 |
| 关系标签 | `relationship` | 原样；空则不渲染 |
| 证件类型 | `crdntlsType` | 原样 |
| 证件代码 | `documentCode` | 原样 |

**`guaranteeTone` 映射：**

| 担保方式 | code | tone | 标签 class 后缀 |
| -------- | :--: | ---- | --------------- |
| 保证担保 | 1 | `guarantee` | `--guarantee` |
| 抵押担保 | 3 | `mortgage` | `--mortgage` |
| 质押担保 | 5 | `pledge` | `--pledge` |
| 其他 / 未知 | — | `default` | `--default` |

> 有 `desc` 无 `code` 时按文案包含「保证 / 抵押 / 质押」匹配；均无法匹配则 `default`。

#### 6.9.2 抵押 / 质押属性行（attrs）

仅抵押担保 / 质押担保时输出：

| 列 label | key |
| -------- | --- |
| 抵押物类别 | `collateralType` |
| 抵质押物类型 | `mortgageAndPledgeType` |
| 抵质押物分类 | `mortgageAndPledgeClass` |

空 → `—`。保证担保不传 attrs。

#### 6.9.3 担保物明细（collateral）

仅当 `collateralList` 非空时输出；列：

| 列 label | key | 格式化 |
| -------- | --- | ------ |
| 担保物名称 | `assetsName` | 原样 |
| 所在地 | `locationVfbc` | 原样 |
| 车牌号/不动产面积 | `assetsNo1Vfbc` | 原样 |
| 机身号/不动产单元号 | `assetsNo` | 原样 |
| 租赁物唯一识别码/抵质押证书编号 | `assetsNo2Vfbc` | 原样 |
| 担保物估值(元) | `estimateValue` | 千分位 + 2 位小数 |
| 币种 | `currtype` | 原样 |
| 第三方质押债务人 | `debtor` | 原样 |
| 是否第一顺位 | `isFirstOrder` | 原样 |
| 评估方式 | `assessMode` | 原样 |
| 优先受偿权数额 | `compensationNumber` | 千分位 + 2 位小数（已是文案则原样） |
| 估值周期 | `valuationCycle` | 原样 |

- 子表标题：`担保物`；`showIndex: true`
- 列数 > 8 → 叠行；表头与单元格统一左对齐
- `collateralList` 为空：不输出担保物块

**PDF 不输出：** 知识图谱入口、编辑/删除、担保人详情弹层等。

## 八、空值与格式化

| 规则 | 说明 |

## 九、约束
