# 报告自动生成 PDF · 分段 HTML 拼接总控（prjc_html_report）

## 一、资源角色

本资源为 **总控**：接收用户直接传入的尽调项目全量参数（不走接口），判断模块范围，按 `moduleIndex` 升序调度各**模块 HTML Skill**，注入统一样式，汇总完整 HTML 后交 PDF 生成服务。

**本层只做流程编排、样式注入与文档壳包裹**，不做业务字段整理、分析或计算。各模块 Skill **直接输出 HTML 片段**。

### 分层职责

| 层级 | 资源 | 职责 |
| ---- | ---- | ---- |
| 总控 | `00.prjc_html_report`（本文） | 判断范围、按序调度、注入样式、包文档壳、汇总 → PDF |
| 样式 | `prjc_html_style` | 固定 CSS + displayType HTML 模板（**不**由模块重复输出） |
| 模块 | `N.prjc_html_*` | 从总入参取本模块数据，按样式模板输出 HTML 片段 |

---

## 二、操作流程

```text
1. 判断模块范围
   ├─ 模块明确：仅生成指定模块
   └─ 模块不明确：默认生成下表全部「可输出」模块（跳过知识图谱）

2. 按 moduleIndex 升序调度各模块 HTML Skill
   ├─ 有数据 / 可渲染 → 返回 HTML 片段（含 report-module）
   └─ 整模块应跳过 → 返回 null（不占位空壳，除非该模块 Skill 另有约定）

3. 注入 prjc_html_style.md 固定 <style> 一次（写入文档壳 <head>）

4. 包裹文档壳
   ├─ <title>：headInfo.projectName + 尽调调查报告 + yyyyMMddHHmm
   └─ <body> 内 <div class="report-root"> 拼接各模块片段

5. 完整 HTML 交 PDF 生成服务
```

### 步骤说明

1. **判断模块范围**
   - 模块明确：仅生成指定模块
   - 模块不明确：默认生成下表全部已配置且应输出的模块
   - 数据缺失：告知对应模块 Skill 以「—」占位，**不中断**；整模块无内容且约定 skip 时返回 null

2. **按序调度模块 Skill**  
   按 `moduleIndex` **升序**调用。各模块自行从总入参提取本模块字段，按 `prjc_html_style.md` 模板输出 HTML。  
   - 成功：返回一段 HTML（通常以 `report-module` 为根）  
   - 跳过：返回 `null`（汇总时忽略，不插入空模块）

3. **注入统一样式**  
   从 `prjc_html_style.md` 取出完整 `<style>…</style>`，在文档壳 `<head>` 中输出**一次**。  
   各模块 Skill **禁止**再输出 `<style>` 或文档壳。

4. **包裹文档壳并拼接**  
   - `<title>` 规则见第三节  
   - 各非 null 片段按 `moduleIndex` 升序放入 `<div class="report-root">`  
   - 交 PDF 生成服务

## 三、页面名称（`<title>`）规则

由「项目名称 + 固定文案 + 生成时间」拼接，作为 HTML 页面名称（浏览器 / PDF 文档标题）。

| 项 | 说明 |
| ---- | ---- |
| 数据路径 | `headInfo.projectName` |
| 时间 | 总控生成时刻，格式 `yyyyMMddHHmm`（示例：`202609081234`） |
| 有值 | `{headInfo.projectName}-尽调调查报告-{yyyyMMddHHmm}` |
| 示例 | `南通东屹高新纤维科技有限公司回租第(2)单-尽调调查报告-202609081234` |
| 缺失 / 空串 | `尽调调查报告-{yyyyMMddHHmm}` |

- **仅本总控**负责写入 `<title>`；各模块 Skill **不**各自拼标题

## 五、文档壳 HTML 示例

```html
<!DOCTYPE html>
<html lang="zh-CN">
<head>
  <meta charset="UTF-8" />
  <title>{headInfo.projectName}-尽调调查报告-{yyyyMMddHHmm}</title>
  <!-- 以下 <style> 从 prjc_html_style.md 原样注入一次 -->
  <style>
    /* … 见 prjc_html_style.md 固定样式表 … */
  </style>
</head>
<body>
  <div class="report-root">
    <!-- moduleIndex 升序；跳过 null；不含附件信息 -->
    <!-- 1.prjc_html_project_change 片段 -->
    <!-- 2.prjc_html_project_summary 片段 -->
    <!-- … -->
    <!-- 15.prjc_html_analysis_results 片段 -->
  </div>
</body>
</html>
```

模块片段示例（由模块 Skill 产出，总控只拼接）：

```html
<div class="report-module" data-module-key="project_summary">
  <div class="report-module__header">项目概要</div>
  <div class="report-module__body">
    <!-- 模块内容 -->
  </div>
</div>
```

## 六、核心原则

1. **只做编排与包裹**：本层不整理、不计算、不补充业务数据；不替代模块 Skill 写字段 HTML
2. **数据直传**：全链路基于用户传入参数，不调用业务接口
3. **小企业专用**：仅按小企业（`prjc-slb`）输出，不做其他尽调系统分支
4. **缺失不中断**：缺失字段由模块以「—」占位；缺模块数据可 skip（null），**不中断**整份报告
5. **样式只注入一次**：`<style>` 仅来自 `prjc_html_style.md`，由本总控写入 `<head>`
6. **模块不发壳 / 不发样式**：模块 Skill 不得输出 `<html>` / `<head>` / `<body>` / `<style>` / `<title>`
7. **直接出 HTML**：各模块 Skill 交付物即为 HTML 片段（可按 displayType 组织内部结构）
