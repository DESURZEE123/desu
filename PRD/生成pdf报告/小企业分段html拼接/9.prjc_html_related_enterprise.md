# 关联企业信息 · HTML 直出

> 所属：小企业分段 HTML 拼接（`小企业分段html拼接`）  
> 模块索引：**9**  
> 上游：用户传入的尽调项目全量参数  
> 样式规范：`prjc_html_style.md`  
> **本 Skill 直接输出模块 HTML 片段（含顶栏与内容），不输出文档壳与 `<style>`。**

## 一、Skill Role

本 Skill 从用户传入参数中提取 `associateCompany`，按**小企业（`prjc-slb`）**页面字段范围映射中文展示名，并**直接输出**符合 `prjc_html_style.md` 的模块 HTML 片段。

AI 在本层负责：字段提取、展示映射、空值规范化、金额格式化、概要卡片与详情卡片 HTML 组装。  
**不做** CRM / 司法涉诉接口调用；**不**输出文档壳、`<html>`/`<body>`、`<style>`。

页面为「关联企业概要卡片列表 + 各企业详情（基本信息 / 主营业务 / 股权结构 / 实控人介绍 / 司法诉讼）」；PDF **按概要列表顺序全部展开**（无折叠 / Tab）。

## 二、模块标识

| 字段 | 值 |
| ---- | -- |
| `moduleIndex` | `9` |
| `moduleKey` | `related_enterprise` |
| `moduleName` | `关联企业信息` |

## 三、数据来源

| 来源路径 | 说明 |
| -------- | ---- |
| `associateCompany` | 模块主数据对象 |
| `associateCompany.associatedCompanySynopsisList[]` | 关联企业概要列表（标签 + 名称 + 证件号） |
| `associateCompany.associatedCompanySynopsisList[].isGuarantor` | 是否担保人：`是`→担保人，否则→非担保人 |
| `associateCompany.associatedCompanySynopsisList[].customerName` | 客户名称 |
| `associateCompany.associatedCompanySynopsisList[].crdntlsCode` | 统一社会信用代码 |
| `associateCompany.associatedCompanyList[]` | 关联企业详情（结构与 `companyPublicInfo` 同构） |
| `associatedCompanyList[].baseInfo` | 基本信息 |
| `associatedCompanyList[].relationTypes[]` | 与承租人关系 |
| `associatedCompanyList[].otherDesc` | 其他关系说明 |
| `associatedCompanyList[].shareholderList[]` | 股权结构明细（股东名称 / 出资额 / 占比） |
| `associatedCompanyList[].shareholderTotal` | 股权结构合计行 |
| `associatedCompanyList[].controllerIntroduction` | 实控人及股东情况介绍 |
| `associatedCompanyList[].judicialLitigationInfo` | 司法诉讼总览 |
| `associatedCompanyList[].judicialLitigationInfo.caseTypeHighRiskList[]` | 高风险案件标签（`caseType` / `caseNum`） |
| `associatedCompanyList[].judicialLitigationInfo.caseTypeCommonList[]` | 普通案件标签（`caseType` / `caseNum`） |
| `associatedCompanyList[].judicialLitigationInfo.updateTime` | 司法诉讼数据更新时间 |
| `associatedCompanyList[].judicialLitigationInfo.judicialLitigationInfoDesc` | 司法诉讼信息说明 |

**PDF 不提取 / 不输出：**

| 字段 / 区块 | 原因 |
| ----------- | ---- |
| `pkCustomerStkhldr` / 各类主键 | 仅数据匹配 |
| `collaborationHistoryModel` | 合作历史由模块 2 独立输出 |
| `assetSize` / `financialAnalysisList` 等 | 页面截图范围外 |
| 仅存在于概要列表、无详情的企业 | 仅输出概要卡片，不输出详情区 |

## 四、生成流程

```text
1. 若 associateCompany 为 null / 缺失：整模块不输出
2. 概要列表与详情列表均为空：输出 empty「暂无关联企业」
3. 输出「关联企业概要」associateCompanySynopsis（按 synopsisList 顺序）
4. 按 synopsisList 顺序，匹配 associatedCompanyList（customerNo）输出详情卡片
5. 详情内：基本信息 → 主营业务 → 股权结构 → 实控人介绍 → 司法诉讼 → 司法诉讼说明
6. 空值规范化为「—」
7. 输出带顶栏的 report-module HTML 片段 → 交由 00 拼接
```

## 五、输出规则 / 可见性

| 场景 | 处理方式 |
| ---- | -------- |
| `associateCompany` 缺失 / `null` | 整模块不输出 |
| 概要与详情均为空 | 模块仍输出顶栏；体内 empty「暂无关联企业」 |
| `isGuarantor === '是'` | 概要卡片标签「担保人」、`report-associate-tag--guarantor` |
| 否则 | 概要卡片标签「非担保人」、`report-associate-tag--nonGuarantor` |
| 详情标题 | **不**输出担保人标签；仅企业名称 + 统一社会信用代码 |
| `relationTypes[]` | 多值用 `、` 拼接 |
| 司法标签 | 先高风险后普通；`caseNum <= 0` 不展示卡片 |
| 高风险 / 普通 | `report-litigation-card--highRisk` / `--common` |
| 无详情数据的概要企业 | 仅出现在概要列表 |
| 主营业务 / 实控人介绍 / 司法诉讼说明为空 | 不输出对应 longText 块 |

## 六、字段映射与展示顺序

| 顺序 | 逻辑块 | HTML 形态 | 说明 |
| :--: | ------ | --------- | ---- |
| 1 | `associatedCompanySynopsisList` | `report-associate-synopsis` | 概要卡片列表 |
| 2+ | `company_{customerNo}` | `report-associate-detail` | 每家有详情的企业一组 |

### 6.1 概要卡片字段

| 展示 | 接口字段 / 规则 |
| ---- | --------------- |
| 标签文案 | `isGuarantor === '是'` → `担保人`；否则 → `非担保人` |
| 标签 class | `guarantor` / `nonGuarantor` |
| 客户名称 | `customerName` |
| 证件号 | `crdntlsCode`（空 → `—`） |

### 6.2 详情内子块顺序

| 顺序 | blockKey | label | HTML 形态 |
| :--: | -------- | ----- | --------- |
| 1 | `baseInfo` | `基本信息` | `report-group` · columns: 4 |
| 2 | `mainBusiness` | `主营业务` | `report-longtext`（有值时） |
| 3 | `shareholderList` | `股权结构` | `report-table` |
| 4 | `controllerIntroduction` | `实控人及股东情况介绍` | `report-longtext`（有值时） |
| 5 | `judicialLitigationInfo` | `司法诉讼信息` | `report-litigation-section` |
| 6 | `judicialLitigationInfoDesc` | `司法诉讼信息说明` | `report-longtext`（有值时） |

### 6.3 基本信息字段（group · columns: 4）

| 顺序 | label | 接口字段 | 栅格 |
| :--: | ----- | -------- | ---- |
| 1 | 企业名称 | `baseInfo.customerName` | w-25 |
| 2 | 统一社会信用代码 | `baseInfo.crdntlsCode` | w-25 |
| 3 | 法定代表人 | `baseInfo.legalRepresentativeCustomerName` | w-25 |
| 4 | 实际控制人 | `baseInfo.actControlsName` | w-25 |
| 5 | 成立时间 | `baseInfo.estblshDate` | w-25 |
| 6 | 注册资本(万元) | `baseInfo.rgstrdCapital` | w-25；千分位 |
| 7 | 行业小类 | `baseInfo.pkIndustrySortLittle.name` | w-25 |
| 8 | 从业人数 | `baseInfo.employeeNum` | w-25 |
| 9 | 注册地址 | `baseInfo.rgstrdAddress` | **w-100** |
| 10 | 与承租人关系 | `relationTypes[]` 用 `、` 拼接 | w-25 |
| 11 | 其他关系说明 | `otherDesc` | **w-100** |

### 6.4 股权结构（table）

**showIndex：** `true`（合计行序号位展示「合计」）  
**emptyText：** `暂无股权结构数据`

| 顺序 | 列 label | 接口字段 | 说明 |
| :--: | -------- | -------- | ---- |
| 1 | 股东名称 | `shareholderName` | 明细行原样；合计行固定「合计」 |
| 2 | 出资额(万元) | `shareholderCapitalAmount` | 千分位；合计取 `shareholderTotal.shareholderCapitalAmount` |
| 3 | 占比(%) | `holdStockRatio` | 原样透传；合计取 `shareholderTotal.holdStockRatio` |

无 `shareholderTotal` 时不输出合计行。列表为空 → `report-table-empty`。

### 6.5 司法诉讼信息

| 属性 | 接口字段 | 说明 |
| ---- | -------- | ---- |
| 更新时间 | `updateTime` | 标题右侧「司法诉讼数据更新时间：{time}」 |
| 卡片 | 先 `caseTypeHighRiskList`，再 `caseTypeCommonList` | 过滤 `caseNum <= 0` |
| `caseType` / `caseNum` | 同名字段 | 居中文案 / 右上角数量 |
| tone | 来源列表 | highRisk / common |
| 空态 | — | `客户暂无司法诉讼数据` |

布局：卡片左起排布、自动换行；宽度适中（约 3 列量级），不按一行卡片数均分拉满。

## 八、空值与格式化

| 规则 | 说明 |
| ---- | ---- |
| 空值占位 | `null` / `""` / 仅空白 / 缺失 → `—` |
| 金额 | 注册资本、出资额：千分位（有小数则保留原小数位习惯；无则按入参） |
| 关系数组 | `relationTypes` 非空元素用 `、` 连接；全空 → `—` |
| 长文本空 | 不输出该 longText 块（不占「—」） |
| HTML 转义 | 对 `<`、`>`、`&`、`"` 做必要转义 |

## 九、约束

1. 必须可识别 `moduleIndex: 9`（HTML 以 `data-module-key="related_enterprise"` 标识）
2. 仅输出本模块 HTML 片段（含 `report-module` 顶栏与内容）
3. 禁止内联 `style`；禁止文档壳与 `<style>`
4. 空值统一为 `—`（长文本块为空则整块省略）
5. 完整报告由 `00.prjc_html_report` 调度拼接
6. `associateCompany` 缺失时：整模块不输出，由 00 跳过
7. 详情标题不输出担保人标签；担保人标签仅出现在概要卡片
