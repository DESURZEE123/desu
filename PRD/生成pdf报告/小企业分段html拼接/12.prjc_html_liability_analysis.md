# 刚性负债分析 · HTML 直出

> 所属：小企业分段 HTML 拼接（`小企业分段html拼接`）  
> 模块索引：**12**  
> 上游：用户传入的尽调项目全量参数  
> 样式规范：`prjc_html_style.md`  
> **本 Skill 直接输出模块 HTML 片段（含顶栏与内容），不输出文档壳与 `<style>`。**

## 一、Skill Role

本 Skill 从用户传入参数中提取 `liabilityAnalysis`，按**小企业（`prjc-slb`）**页面字段范围映射中文展示名，并**直接输出**符合 `prjc_html_style.md` 的模块 HTML 片段。

AI 在本层负责：字段提取、展示映射、金额/空值格式化、宽表叠行（`stackSpan` / `mergeSame` / `subKey`）、合计行组装。  
**不做**征信/中登接口调用、不筛选主体；**不**输出文档壳、`<style>`。

页面为「借款情况（企业借款 / 个人借款）+ 对外担保情况 + 负债说明」；PDF **按顺序全部展开**。宽表（列数 > 8）在本层输出为**单表叠行**（`report-table--stacked`），不拆表。

## 二、模块标识

| 字段 | 值 |
| ---- | -- |
| `moduleIndex` | `12` |
| `moduleKey` | `liability_analysis` |
| `moduleName` | `刚性负债分析` |

## 三、数据来源

| 来源路径 | 说明 |
| -------- | ---- |
| `liabilityAnalysis` | 模块主数据对象 |
| `liabilityAnalysis.loanSituation.companyLoanList[]` | 企业借款明细 |
| `liabilityAnalysis.loanSituation.companyLoanTotal` | 企业借款合计（借款金额 / 余额） |
| `liabilityAnalysis.loanSituation.personLoanList[]` | 个人借款明细 |
| `liabilityAnalysis.loanSituation.personLoanTotal` | 个人借款合计 |
| `liabilityAnalysis.externalGuaranteeSituationList[]` | 对外担保情况明细 |
| `liabilityAnalysis.amountTotal` | 对外担保余额合计 |
| `liabilityAnalysis.liabilityStatement` | 负债说明 |
| （可选）征信/中登更新时间字段 | 有值时输出为 `updateTime` kv |

**PDF 不提取 / 不输出：**

| 字段 | 原因 |
| ---- | ---- |
| `pkQueryRecord` / `queryStatusEnum` | 仅查询态匹配 |
| `loanBalance` | 页面主表不展示 |
| `associateLiabilityInfo` | 截图无对应块 |
| `personBorrowIndexList` / `companyBorrowIndexList` | 征信指标内部结构 |
| `loanSituation.personBorrowDetailList` | 个人借款明细子表；PDF 用 `personLoanList` |
| `customerNo` / 各类主键 | 仅数据匹配 |
| `isWhite` / `loanOrigTypeName` 等 | 主表不展示 |

## 四、生成流程

```text
1. 若 liabilityAnalysis 为 null / 缺失：整模块不输出
2. 有更新时间则输出 updateTime（kv）
3. 输出「借款情况」大区标题（sectionHeading）
4. 组装企业借款叠行表（含 summary）
5. 组装个人借款叠行表（含 summary）
6. 组装对外担保情况叠行表（含 summary）
7. 组装负债说明 longText（有值时）
8. 输出带顶栏的 report-module HTML 片段 → 交由 00 拼接
```

## 五、输出规则 / 可见性

| 规则 | 说明 |
| ---- | ---- |
| 各表 null / [] | 仍输出对应 table 块，走 `report-table-empty` |
| `liabilityStatement` 空 | 不输出负债说明块 |
| 筛选 / 更新按钮 | **不输出** |
| 五级分类 / 角色 | PDF **不做**彩色标签，仅中文文案 |
| 宽表 | 单表叠行，**禁止**按列数拆成多表 |
| `repeat == 是` | 合计以接口 `companyLoanTotal` 为准，不自行按 repeat 重算 |

## 六、字段映射与展示顺序

| 顺序 | blockKey | label | HTML |
| :--: | -------- | ----- | ---- |
| 1 | `updateTime` | `征信、中登数据更新时间` | `report-kv`（有值时） |
| 2 | `loanSituationTitle` | `借款情况` | `report-section-heading` |
| 3 | `companyLoanList` | `企业借款` | 叠行宽表 |
| 4 | `personLoanList` | `个人借款` | 叠行宽表 |
| 5 | `externalGuaranteeSituationList` | `对外担保情况` | 叠行宽表 |
| 6 | `liabilityStatement` | `负债说明` | `report-longtext`（有值时） |

> **注意：** `loanSituationTitle` 必须用蓝竖条 `report-section-heading`，**禁止**用空 group 冒充圆点标题。

### 6.1 企业借款（table · 叠行）

**showIndex：** `true`  
**emptyText：** `暂无企业借款数据`

| 顺序 | 列 label | key | 格式化 | 叠行列属性 |
| :--: | -------- | --- | ------ | ---------- |
| 1 | 借款主体 | `borrowingEntity` | 仅主体名称；日期走副行 | `stackSpan` + `mergeSame`；`subKey: queryTime` |
| 2 | 主体角色 | `principalRole` | 数组用 `、` 拼接；空 → `—` | `stackSpan` + `mergeSame` |
| 3 | 租赁借款余额合计(元) | `leaseLoanTotal` | 金额 | `stackSpan` + `mergeSame` |
| 4 | 非租赁借款余额合计(元) | `nonLeaseLoanTotal` | 金额 | `stackSpan` + `mergeSame` |
| 5 | 业务类型 | `businessType` | 原样 | 配对叠放 |
| 6 | 机构编码 | `institutionalCode` | 原样 | 配对叠放 |
| 7 | 授信机构 | `creditInstitutional` | 原样 | 配对叠放 |
| 8 | 借款金额(元) | `loanAmount` | 金额 | 配对叠放 |
| 9 | 余额(元) | `balance` | 金额 | 配对叠放 |
| 10 | 起始日期 | `startDate` | 原样 | 配对叠放 |
| 11 | 截止日期 | `deadline` | 原样 | 配对叠放 |
| 12 | 担保方式 | `guaranteeMethod` | 原样 | 配对叠放 |
| 13 | 抵押类型 | `mortgageType` | 原样 | 配对叠放 |
| 14 | 五级分类 | `fiveLevel` | 原样 | 配对叠放 |
| 15 | 当前逾期月份 | `curOverdueMonth` | 原样 | 配对叠放 |
| 16 | 数据来源 | `querySource` | 原样 | 配对叠放 |
| 17 | 是否与征信重复 | `repeat` | 原样；空 → `—` | 配对叠放（**不得**单独拆表） |

**借款主体展示：**

- `borrowingEntity` 只填主体名称（用于 mergeSame）
- `queryTime` trim 非空时渲染副行：`（征信查询日期: {queryTime}）` → `.report-table__entity-sub`
- 同一主体多行：主体/角色/租赁与非租赁合计单元格 `rowspan = 记录数 × 2`
- 序号列**不合并**，每条明细各自编号

**summary：**

| key | 取值 |
| --- | ---- |
| `index` | `合计` |
| `leaseLoanTotal` | 按 `borrowingEntity` **去重取首行**的 `leaseLoanTotal` 求和后金额格式化 |
| `nonLeaseLoanTotal` | 同上 |
| `loanAmount` | `companyLoanTotal.loanAmount` |
| `balance` | `companyLoanTotal.balance` |
| 其余列 | `—` |

### 6.2 个人借款（table · 叠行）

**emptyText：** `暂无个人借款数据`

| 顺序 | 列 label | key | 格式化 | 叠行 |
| :--: | -------- | --- | ------ | ---- |
| 1 | 借款主体 | `borrowingEntity` | 主体名 + `subKey: queryTime` | `stackSpan` + `mergeSame` |
| 2 | 业务大类 | `businessCategory` | 原样 | 配对 |
| 3 | 担保方式 | `guaranteeMethod` | 原样 | 配对 |
| 4 | 账户数量 | `accountNum` | 数字转字符串 | 配对 |
| 5 | 借款金额(元) | `loanAmount` | 金额 | 配对 |
| 6 | 余额(元) | `balance` | 金额 | 配对 |
| 7 | 累计逾期月数 | `overdueMonths` | 原样 | 配对 |
| 8 | 当前逾期账户数 | `overdueAccountNum` | 原样 | 配对 |
| 9 | 最长逾期月数 | `maxOverdueMonths` | 原样 | 配对 |
| 10 | 最大逾期金额(元) | `maxOverdueAmount` | 金额 | 配对 |
| 11 | 近一个月到期金额(元) | `balanceDue` | 金额 | 配对 |
| 12 | 近三个月被其他机构查询贷款审批及担保资格的次数 | `queryTimes` | 原样 | 配对 |
| 13 | 数据来源 | `querySource` | 原样 | 配对 |

**不输出：** `isBadAccount` / `maxCreditAmount` / `isWhite` / `principalRole` / `customerNo`

**summary：** `loanAmount` / `balance` / `maxOverdueAmount`（有则填）/ `balanceDue` ← `personLoanTotal`；其余 `—`。

### 6.3 对外担保情况（table · 叠行）

**emptyText：** `暂无对外担保数据`

| 顺序 | 列 label | key | 格式化 | 叠行 |
| :--: | -------- | --- | ------ | ---- |
| 1 | 担保主体 | `borrowingEntity` | + `subKey: queryTime` | `stackSpan` + `mergeSame` |
| 2 | 主体角色 | `principalRole` | `、` 拼接 | `stackSpan` + `mergeSame` |
| 3 | 被担保主体 | `guaranteedEntity` | 空串 → `—` | 配对 |
| 4 | 业务类型 | `businessType` | 原样 | 配对 |
| 5 | 余额(元) | `balance` | 金额 | 配对 |
| 6 | 起始日期 | `startDate` | 原样 | 配对 |
| 7 | 截止日期 | `deadline` | 原样 | 配对 |
| 8 | 五级分类 | `fiveLevel` | 原样 | 配对 |
| 9 | 当前逾期月数 | `curOverdueMonth` | 原样 | 配对 |
| 10 | 是否存在对应借款 | `loanExists` | 原样 | 配对 |
| 11 | 数据来源 | `querySource` | 原样 | 配对 |

**summary：** `balance` ← `amountTotal`；其余 `—`。

### 6.4 叠行布局算法（本层必须执行）

1. 将列分为：`stackSpan: true` 跨行固定列；其余按出现顺序**两两配对**为物理列
2. 末列落单：上行填该列、下行填「—」
3. `showIndex`：最左跨行固定列，每条记录编号，`rowspan="2"`，不与主体合并
4. 表头两行 class：`report-table__head-row--top` / `--bottom`；样式须一致
5. 数据上行/下行：`report-table__data-row--top` / `--bottom report-table__record-divider`
6. 合计行亦占 2 行

## 八、空值与格式化

| 规则 | 说明 |
| ---- | ---- |
| 空值占位 | `null` / `""` / 仅空白 / 缺失 → `—` |
| 金额 | 千分位 + 2 位小数（如 `4005800` → `4,005,800.00`） |
| 日期 / 枚举 / 文本 | 原样；`queryTime` 先 `trim` |
| 数组角色 | `principalRole` 非空元素用 `、` 连接；全空 → `—` |
| 五级分类色标 | PDF 不做，仅文案 |

## 九、约束

1. 必须可识别 `moduleIndex: 12`（`data-module-key="liability_analysis"`）
2. 仅输出本模块 HTML 片段
3. 禁止内联 `style`；禁止文档壳与 `<style>`
4. 空值统一为 `—`
5. 完整报告由 `00.prjc_html_report` 调度拼接
6. `liabilityAnalysis` 缺失：整模块不输出
7. 宽表完整列于**单个**叠行表；「是否与征信重复」不得拆表
8. `loanSituationTitle` 用 `report-section-heading`，禁止空 group 冒充
