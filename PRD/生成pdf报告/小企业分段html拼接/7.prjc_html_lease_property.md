# 租赁物信息 · HTML 直出

> 所属：小企业分段 HTML 拼接（`小企业分段html拼接`）  
> 模块索引：**7**  
> 上游：用户传入的尽调项目全量参数  
> 样式规范：`prjc_html_style.md`  
> **本 Skill 直接输出模块 HTML 片段（含顶栏与内容），不输出文档壳与 `<style>`。**

## 一、Skill Role

本 Skill 从用户传入参数中提取 `lshldModel`，按**小企业（`prjc-slb`）**页面字段范围与项目形态分支映射中文展示名，并**直接输出**符合 `prjc_html_style.md` 的模块 HTML 片段。

AI 在本层负责：形态判定（只读）、字段提取、展示映射、金额格式化、行内详情展开 HTML。  
**不**调用核心租赁物接口；**不**输出文档壳与 `<style>`。

页面为「顶部汇总指标 + 租赁物明细表（可展开行）+ 底部说明」；PDF **全部展开**：每条明细在汇总行下固定输出详情栅格（无全部展开 / 收起 / 导出 / 操作列）。

> 若 `lshldModel` 为 null / 缺失，整模块不输出。

| `lshldModel.breakPriceDesc` | 是否突破作价及说明 |

### 3.1 项目形态判定（取 `projectBaseInfo`）

| 项目形态 | 判定条件 |
| -------- | -------- |
| 直租 | `leaseMethod = 直租` |
| 直转回 | `leaseMethod = 回租` 且 `capitalUse ∈ {购置本次租赁物, 其他租赁物}` |
| 纯回租 | `leaseMethod = 回租` 且 `capitalUse = 补充流动资金` |

> 判定顺序：先看是否直租；否则再按资金用途区分直转回 / 纯回租。**只读**上述两字段做展示分支，不改写业务数据。

**PDF 不提取 / 不输出：**

| 字段 / 能力 | 原因 |
| ----------- | ---- |
| `pkRentThing` / `pkRentThingCore` / `providerCode` / `proCrdntlsCode` / `pkAccountCore` 等主键 | 仅数据匹配 |
| `initialDetail` / `checkInfo` / `riskInfo` | 详情弹窗其它分区；本页展开区未展示 |
| 「全部展开」「全部收起」「导出」「操作 / 收起」 | 页面交互；PDF 默认全部展开详情 |
| 顶栏纯回租专属字段 | 直租、直转回形态下不输出 |
| `supplierInfoList`（纯回租） | **仅直租 / 直转回**展示 |

## 四、生成流程

```text
1. 若 lshldModel 为 null / 缺失：整模块不输出
2. 读取 projectBaseInfo.leaseMethod / capitalUse，按 §3.1 判定项目形态
3. 输出顶部汇总 group（4 列）：始终含监控设备 2 字段；仅纯回租追加评估/净值/定价/折价/占比
4. 输出租赁物明细 table：每行 = 汇总列 + detail 详情栅格（PDF 全部展开）
5. 若形态为直租 / 直转回：输出「供应商信息」table；纯回租不输出
6. 输出权属说明、突破作价说明 longText（有值时）
7. 空值 →「—」；金额千分位 2 位；比例原样透传（不追加 %）
8. 输出 report-module HTML 片段 → 交由 00 拼接
```

## 五、输出规则 / 可见性

- `lshldInfoList` 为 `null` / `[]`：仍输出 table 块 + 空态文案
- `thingType`：取对象 `name`
- 明细表 **汇总列 + 行内详情字段集按项目形态分支**（§6.2.A vs §6.2.B）；不可混用
- 每条明细**必须**输出对应形态的 detail；无折叠交互
- 合计行：原值 ← `lshldPriceTotal`，净值 ← `netWorthTotal`；其余列 `—`；序号列文案 `合计`；合计行**无** detail
- 宽表（汇总列数 > 8）：叠行；详情栅格仍挂在该条记录下方
- 长文本为空：不输出该块
- **供应商信息表**：仅直租 / 直转回；列表空时仍输出空态；纯回租整表不输出

## 九、约束

1. 必须可识别 `moduleIndex: 7`
2. 仅输出本模块 HTML 片段
3. 禁止内联 `style`；禁止文档壳与 `<style>`
4. 空值统一为 `—`
5. 完整报告由 `00.prjc_html_report` 调度拼接
6. 项目形态按 §3.1 判定；顶栏评估/净值/定价/折价/占比**仅纯回租**
7. 直租、直转回顶栏仅保留监控设备相关 2 字段
8. 明细表字段集按形态分支，**不得**混用
9. 「供应商信息」表仅直租 / 直转回输出
10. 明细表合计行净值不受顶栏纯回租条件限制
11. PDF 默认全部展开行内详情，无折叠交互
