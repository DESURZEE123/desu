# 增信措施 · HTML 直出

> 所属：小企业分段 HTML 拼接（`小企业分段html拼接`）  
> 模块索引：**10**  
> 上游：用户传入的尽调项目全量参数  
> 样式规范：`prjc_html_style.md`  
> **本 Skill 直接输出模块 HTML 片段（含顶栏与内容），不输出文档壳与 `<style>`。**

## 一、Skill Role

本 Skill 从用户传入参数中提取 `creditEnhancementMeasure`，按**小企业（`prjc-slb`）**页面字段范围映射中文展示名，并**直接输出**符合 `prjc_html_style.md` 的模块 HTML 片段。

AI 在本层负责：字段提取、展示映射、担保方式色标、空值/金额格式化、measureList 与担保人/担保企业详情 HTML 组装。  
**不做**客户 / 司法接口调用；**不**输出文档壳、`<style>`。

页面为「担保措施卡片列表 + 担保人（自然人）详情 + 担保企业详情」；PDF **按顺序全部展开**（无「信息已完善」badge、无「管理增信措施」按钮、无折叠 / Tab）。

## 二、模块标识

| 字段 | 值 |
| ---- | -- |
| `moduleIndex` | `10` |
| `moduleKey` | `credit_enhancement` |
| `moduleName` | `增信措施` |

## 三、数据来源

| 来源路径 | 说明 |
| -------- | ---- |
| `creditEnhancementMeasure` | 模块主数据对象 |
| `creditEnhancementMeasure.creditEnhancementMeasureInfo.creditEnhancementMeasureList[]` | 担保措施列表 |
| `creditEnhancementMeasure.guaranteePersonList[]` | 担保自然人详情列表 |
| `creditEnhancementMeasure.guaranteeCompanyList[]` | 担保企业详情列表 |
| `guaranteeCompanyList[].companyPublicInfo` | 担保企业公示信息（与承租人 `companyPublicInfo` 同构） |

**与「实施方案」内嵌增信措施的关系：**

| 模块 | 数据 | 说明 |
| ---- | ---- | ---- |
| 实施方案（moduleIndex 6） | 报价维度增信措施摘要 | 按报价取数过滤 |
| **本模块（moduleIndex 10）** | **顶层 `creditEnhancementMeasure` 全量页** | **不以报价过滤**；另含担保人 / 担保企业详情 |

**PDF 不提取 / 不输出：**

| 字段 / 区块 | 原因 |
| ----------- | ---- |
| `pkCreditEnhancementMeasure` / `pkGuarantorInfo` / 各类主键 | 仅数据匹配 |
| `customerType[]` / `guaCustomerNo` | 页面卡片不展示 |
| `collaborationHistoryModel` | 合作历史由模块 2 独立输出 |
| `loan` / `productionAndSaleSituation` / `assetSize` / 财报等 | 小企业本页截图范围外 |
| 「信息已完善」badge、「管理增信措施」「更新司法涉诉数据」 | 页面交互 |
| 自然人 `age` / `sex` / `maritalStatus` / `guaranteeContInfoList` | 截图不展示 |
| 企业行业许可证 / 主营业务 / 公司沿革 | 与承租人模块区分，本页不输出 |

## 四、生成流程

```text
1. 若 creditEnhancementMeasure 为 null / 缺失：整模块不输出
2. 输出「增信措施」大区标题（sectionHeading）
3. 输出「担保措施」measureList（取 creditEnhancementMeasureInfo.creditEnhancementMeasureList）
4. 若 guaranteePersonList 非空：输出「担保人信息」大区标题，再按列表顺序输出各自然人详情
5. 若 guaranteeCompanyList 非空：按列表顺序输出各担保企业详情（标题含企业名）
6. 空值规范化为「—」；金额千分位
7. 输出带顶栏的 report-module HTML 片段 → 交由 00 拼接
```

## 五、输出规则 / 可见性

| 规则 | 说明 |
| ---- | ---- |
| `guaCustType` | `0`→企业；`1`→自然人（理解语义，**不单独成列**） |
| `guaranteeMethod` | 取对象 `desc`；已是字符串则原样 |
| `relationship` 空 | 不渲染绿色关系 tag |
| 抵押 / 质押 | 仅 `mortgage` / `pledge` 时输出 attrs；`collateralList` 非空时输出担保物表 |
| 保证担保 | 通常不传 attrs / collateral |
| 司法标签 | `caseNum <= 0` 不展示；先高风险后普通 |
| 长文本空 | 不输出该 longText 块 |
| 担保人 / 企业列表空 | 不输出对应详情区块（担保措施列表仍输出，可 empty） |

### 5.1 担保方式色标

| 担保方式 | code | tone | class |
| -------- | :--: | ---- | ----- |
| 保证担保 | 1 | `guarantee` | `report-measure-card__tag--guarantee` |
| 抵押担保 | 3 | `mortgage` | `report-measure-card__tag--mortgage` |
| 质押担保 | 5 | `pledge` | `report-measure-card__tag--pledge` |
| 其他 / 未知 | — | `default` | `report-measure-card__tag--default` |

> 有 `desc` 无 `code` 时按文案包含「保证 / 抵押 / 质押」匹配；均无法匹配则 `default`。

### 6.1 担保措施卡片字段

| 卡片字段 | 接口字段 / 规则 |
| -------- | --------------- |
| 担保方式文案 | `guaranteeMethod.desc` |

| 抵质押物分类 | `mortgageAndPledgeClass` |

#### 担保物表（`collateralList` 非空）

**showIndex：** `true`；**全部列左对齐**；列数 > 8 走叠行表。

| 列 label | key | 格式化 |
| -------- | --- | ------ |
| 担保物名称 | `assetsName` | 原样 |
| 所在地 | `locationVfbc` | 原样 |
| 车牌号/不动产面积 | `assetsNo1Vfbc` | 原样 |
| 机身号/不动产单元号 | `assetsNo` | 原样 |
| 租赁物唯一识别码/抵质押证书编号 | `assetsNo2Vfbc` | 原样 |
| 担保物估值(元) | `estimateValue` | 千分位 + 2 位小数 |
| 币种 | `currtype` | 原样 |
| 第三方质押债务人 | `debtor` | 原样 |
| 是否第一顺位 | `isFirstOrder` | 原样 |
| 评估方式 | `assessMode` | 原样 |

| 顺序 | label | HTML |

## 八、空值与格式化

| 规则 | 说明 |
| ---- | ---- |
| 空值占位 | `null` / `""` / 缺失 → `—` |
| 金额 | 千分位 + 2 位小数（估值、优先受偿权数额、注册资本等） |
| 关系空 | 不渲染 `.report-measure-card__rel` |
| 长文本空 | 整块省略 |
| HTML 转义 | 文本节点转义 |

## 九、约束

1. 必须可识别 `moduleIndex: 10`（`data-module-key="credit_enhancement"`）
2. 仅输出本模块 HTML 片段
3. 禁止内联 `style`；禁止文档壳与 `<style>`
4. 空值统一为 `—`
5. 完整报告由 `00.prjc_html_report` 调度拼接
6. `creditEnhancementMeasure` 缺失：整模块不输出
7. 本模块担保措施**不以报价过滤**（与模块 6 区分）
8. 禁止输出交互 badge / 管理按钮 / 更新司法按钮
