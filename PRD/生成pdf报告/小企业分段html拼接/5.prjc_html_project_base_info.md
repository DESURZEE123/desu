# 项目基本信息 · HTML 直出

> 所属：小企业分段 HTML 拼接（`小企业分段html拼接`）  
> 模块索引：**5**  
> 上游：用户传入的尽调项目全量参数  
> 样式规范：`prjc_html_style.md`  
> **本 Skill 直接输出模块 HTML 片段（含顶栏与内容），不输出文档壳与 `<style>`。**

## 一、Skill Role

本 Skill 从用户传入参数中提取 `projectBaseInfo` 及相关子对象，按**小企业（`prjc-slb`）**页面字段范围映射中文展示名，并**直接输出**符合 `prjc_html_style.md` 的模块 HTML 片段。

AI 在本层负责：字段提取、条件字段可见性、展示映射、金额格式化、HTML 结构组装。  
**不做**业务分析；**不**输出文档壳与 `<style>`。

## 二、模块标识

| 字段 | 值 |
| ---- | -- |
| `moduleIndex` | `5` |
| `moduleKey` | `project_base_info` |
| `moduleName` | `项目基本信息` |

## 三、数据来源

| 来源路径 | 说明 |
| -------- | ---- |
| `projectBaseInfo` | 模块主数据对象 |
| `projectBaseInfo.projectType` | 项目类型（决定是否输出「对应老合同」） |
| `projectBaseInfo.oldContInfoList[]` | 对应老合同列表（老客租专用） |
| `projectBaseInfo.oldContInfoList[].oldContName` | 老合同名称（展示用） |
| `projectBaseInfo.oldContInfoList[].oldContId` | 老合同主键（仅匹配，**不输出**） |
| `projectBaseInfo.settleBeLeaseContList` | 起租前结清合同 |
| `projectBaseInfo.environmentAndSocialRisk` | 环境与社会风险评估 |
| `projectBaseInfo.siteSituationList` | 现场尽调情况列表 |
| `projectBaseInfo.companyBaseInfo` | 项目基本情况 |

## 四、生成流程

```text
1. 从 projectBaseInfo 提取字段
2. 组装首屏 group（无组标题）：固定字段按序输出；若 projectType = 「老客租项目」则在「项目类型」后插入「对应老合同」
3. 组装环境评估 table
4. 组装现场尽调 table
5. 组装项目基本情况 longText
6. 输出 report-module HTML 片段 → 交由 00 拼接
```

## 五、输出规则 / 可见性

**固定内容块：**

| 逻辑块 | label | HTML 形态 |
| ------ | ----- | --------- |
| `projectBaseInfo` | （不传 / 空，无组标题） | `report-grid`（4 列） |
| `environmentAndSocialRisk` | `环境与社会风险评估` | 圆点标题 + table |
| `siteSituationList` | `现场尽调情况` | 圆点标题 + table |
| `companyBaseInfo` | `项目基本情况` | `report-longtext` |

**条件展示：**

- **`对应老合同`（必填条件字段）**
  - **何时输出**：仅当 `projectBaseInfo.projectType = 老客租项目`
  - **插入位置**：紧接「项目类型」之后、「业务信息来源」之前
  - **取值**：`oldContInfoList[].oldContName`，按接口顺序；多个用中文分号 `；` 拼接
  - **空列表 / null**：仍输出该字段，值为 `—`
  - **何时不输出**：`projectType` 非「老客租项目」时，**整字段不出现**（即使 `oldContInfoList` 有值也不输出）
- `合同收益IRR(银票)`：实施方案存在银票投放且 `referenceYield.contIrrBanknote` 有值时，在参考收益率相关字段中展示（若入参携带）
- `SOFR类型` / `margin`：业务部门 = 航运金融事业部时展示（若入参携带）

**不输出：** 报价信息、参考收益率（通用大单专属）、项目备案情况、现场考察情况（`siteSituation`）、手续情况、尽调情况说明、业务信息来源列表、`oldContId`

## 六、字段映射与展示顺序

| 顺序 | 逻辑块 | label | 说明 |
| :--: | ------ | ----- | ---- |
| 1 | `projectBaseInfo` | （无） | group columns:4 |
| 2 | `environmentAndSocialRisk` | `环境与社会风险评估` | table |
| 3 | `siteSituationList` | `现场尽调情况` | table |
| 4 | `companyBaseInfo` | `项目基本情况` | longText |

### 6.1 首屏字段（group · columns: 4 · 无组标题）

顶栏「项目基本信息」下直接铺栅格，**不对齐**「● 项目基本信息」。

| 顺序 | label | 接口字段 | 形态 | 格式化 |
| :--: | ----- | -------- | ---- | ------ |
| 1 | 客户名称 | `customerName` | kv | 原样 |
| 2 | 项目金额(元) | `projectAmount` | kv | 千分位 + 2 位小数 |
| 3 | 项目类型 | `projectType` | kv | 原样 |
| 3a | 对应老合同 | `oldContInfoList` | kv | **条件字段**，见 §6.1.1 |
| 4 | 业务信息来源 | `projectSource` | kv | 原样 |
| 5 | 租赁方式 | `leaseMethod` | kv | 原样 |
| 6 | 资金用途 | `capitalUse` | kv | 原样 |
| 7 | 售后回租(新设备)原因 | `leasebackReason` | kv | 原样 |
| 8 | 售后回租(新设备)原因说明 | `leasebackExplain` | longText · fullWidth | 原样 |
| 9 | 投保情况 | `insuranceSituation` | kv | 原样 |
| 10 | 项目经理 | `managerName` | kv | 仅姓名，不传工号 |
| 11 | 项目协办人 | `custHelpName` | kv | 仅姓名，不传工号 |
| 12 | 起租前结清合同 | `settleBeLeaseContList` | kv | 取合同名称，多个用 `；` 分隔；空 → `—` |
| 13 | 租赁物保险 | `leaseInsurance` | longText · fullWidth | 原样 |

#### 6.1.1 对应老合同（条件）

当且仅当 **`projectBaseInfo.projectType = 老客租项目`** 时输出。

| 项 | 规则 |
| -- | ---- |
| 条件 | `projectType === "老客租项目"` 才组装；否则**跳过**，不占位 |
| 取值路径 | `projectBaseInfo.oldContInfoList[].oldContName` |
| 多值拼接 | 按数组顺序取 `oldContName`，用 `；` 连接 |
| 空值 | 老客租且列表为空 → `—`（字段仍输出） |

### 6.2 环境与社会风险评估（table）

数据来源：`projectBaseInfo.environmentAndSocialRisk`（扁平对象 → 指标/结果两列）

| 列 label | key | 说明 |
| -------- | --- | ---- |
| 指标 | `indicator` | 固定中文文案 |
| 结果 | `result` | 取对应接口字段原值 |

- `showIndex`: `false`
- 空态：`暂无评估信息`

**行序与字段映射：**

| 顺序 | 指标（`indicator`） | 接口字段 → `result` |
| :--: | ------------------- | ------------------- |
| 1 | 拟承租人经营活动是否涉及业务排除清单 | `exclusionBusinessResult` |
| 2 | 所属行业是否为国家产业政策、行业准入政策限制的行业 | `policyRestrictResult` |
| 3 | 是否取得主管部门颁发的特定行业的许可经营证明 | `operateLicenseResult` |
| 4 | 是否存在国家或省级主管部门认定的重大环境、安全生产违法违规行为 | `offenceResult` |
| 5 | 租赁物是否存在环境和社会风险隐患（易燃易爆物、危险化学品、有毒有害物等） | `hiddenRiskResult` |
| 6 | 评估结论（高、中、低） | `assessResult` |

### 6.3 现场尽调情况（table）

| 列 label | key | 格式化 |
| -------- | --- | ------ |
| 尽调人员 | `workerList` | `workerList[]` 取 `userName`，多人用 `、` 拼接 |
| 尽调日期 | `signDate` | 原样 |
| 地点 | `address` | 原样 |
| 主要内容 | `context` | 原样 |

- `showIndex`: `true`
- 空态：`暂无现场尽调记录`

### 6.4 项目基本情况（longText）

数据来源：`projectBaseInfo.companyBaseInfo`

## 八、空值与格式化

| 规则 | 说明 |
| ---- | ---- |
| 空值占位 | `null` / `""` / 缺失 → 展示值填 `—` |
| 金额 | 千分位 + 保留 2 位小数，如 `10,000.00` |
| 百分比 | 保留 4 位小数 + `%`，如 `8.5155%`（若本模块出现） |
| 枚举 | 直接展示接口返回的中文值，不做码值转换 |
| 人员姓名 | 项目经理 / 项目协办人仅姓名，不传工号 |

## 九、约束

1. 必须可识别 `moduleIndex: 5`
2. 仅输出本模块 HTML 片段
3. 禁止内联 `style`；禁止文档壳与 `<style>`
4. 空值统一为 `—`
5. 完整报告由 `00.prjc_html_report` 调度拼接
6. `对应老合同`：仅 `projectType = 老客租项目` 时输出；非老客租不得输出；`oldContId` 不输出
