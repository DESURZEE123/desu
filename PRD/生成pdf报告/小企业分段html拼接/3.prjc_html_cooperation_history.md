# 合作历史 · HTML 直出

> 所属：小企业分段 HTML 拼接（`小企业分段html拼接`）  
> 模块索引：**3**  
> 上游：用户传入的尽调项目全量参数  
> 样式规范：`prjc_html_style.md`  
> **本 Skill 直接输出模块 HTML 片段（含顶栏与内容），不输出文档壳与 `<style>`。**

## 一、Skill Role

本 Skill 从用户传入参数中提取 `commonCollaborationHistoryModel`（及同构子对象），按**小企业（`prjc-slb`）**页面字段范围映射中文展示名，并**直接输出**符合 `prjc_html_style.md` 的模块 HTML 片段。

AI 在本层负责：字段提取、展示映射、金额格式化、宽表叠行 HTML 组装。  
**不做**业务分析、筛选主体计算、知识图谱渲染；**不**输出文档壳与 `<style>`。

## 二、模块标识

| 字段 | 值 |
| ---- | -- |
| `moduleIndex` | `3` |
| `moduleKey` | `cooperation_history` |
| `moduleName` | `合作历史` |

## 三、数据来源

| 来源路径 | 说明 |
| -------- | ---- |
| `commonCollaborationHistoryModel` | 模块主数据对象（项目级合作历史） |
| `commonCollaborationHistoryModel.leaseCollaborationHistoryList` | 作为承租人情况列表 |
| `commonCollaborationHistoryModel.leaseAmountTotal` | 作为承租人情况 · 合计：`contCashPledge`（合同金额）/ `riskExposure`（剩余本金）/ `curOverdueAmount`（当前逾期金额） |
| `commonCollaborationHistoryModel.guarantorCollaborationHistories` | 作为担保人情况列表 |
| `commonCollaborationHistoryModel.guarantorAmountTotal` | 作为担保人情况 · 合计：`contCashPledge`（合同金额）/ `riskExposure`（剩余本金）/ `curOverdueAmount`（当前逾期金额） |
| `commonCollaborationHistoryModel.cooperateHistoryDesc` | 合作历史说明 |

> 承租人 / 担保人模块内嵌的 `collaborationHistoryModel` **不**作为本模块主数据源；PDF「合作历史」大模块仅取项目级 `commonCollaborationHistoryModel`。

## 四、生成流程

```text
1. 从 commonCollaborationHistoryModel 提取字段
2. 组装承租人情况表（含合计行 / 空态）
3. 组装担保人情况表（含合计行 / 空态）
4. 两表任一有数据时追加合作历史说明 longText
5. 列数 > 8 → 按叠行宽表规则输出（见 §7.3）
6. 输出 report-module HTML 片段 → 交由 00 拼接
```

## 五、输出规则 / 可见性

**固定内容块：**

| 逻辑块 | label | HTML 形态 |
| ------ | ----- | --------- |
| `leaseCollaborationHistoryList` | `承租人、关联方、担保人作为承租人情况` | 圆点标题 + table（叠行） |
| `guarantorCollaborationHistories` | `承租人、关联方、担保人作为担保人情况` | 圆点标题 + table（叠行） |
| `cooperateHistoryDesc` | `合作历史说明` | `report-longtext`（有合作历史数据时） |

**展示规则：**

- `合作历史说明`：两表任一有数据时输出；两表皆空时不输出
- `知识图谱`：交互可视化，**PDF 不输出**
- `筛选主体` / `更新合作历史`：页面操作，**PDF 不输出**（使用入参中已落库的全量列表）

**空数据规则：**

- 两表皆空（`null` / `[]`）：仍输出两个 table 块，空态文案均为 `所有客户均无合作历史数据`；不输出「合作历史说明」
- 单表为空：该表走空态文案 `暂无合作历史数据`，另一表正常输出；有数据时仍可输出说明
- 空表：不渲染 `<table>`，改为 `report-table-empty`

## 六、字段映射与展示顺序

| 顺序 | 逻辑块 | label | 说明 |
| :--: | ------ | ----- | ---- |
| 1 | `leaseCollaborationHistoryList` | `承租人、关联方、担保人作为承租人情况` | 完整列；`showIndex=true` |
| 2 | `guarantorCollaborationHistories` | `承租人、关联方、担保人作为担保人情况` | 完整列；`showIndex=true` |
| 3 | `cooperateHistoryDesc` | `合作历史说明` | 条件输出 |

> 每个 table **完整列**输出（合同 + 收益与逾期字段合并为一张表）。列数超过 8 时走叠行展示，**不**拆表。

### 6.1 作为承租人情况

数据来源：`commonCollaborationHistoryModel.leaseCollaborationHistoryList`

| 列 label | key | 格式化 |
| -------- | --- | ------ |
| 客户名称 | `customerName` | 原样 |
| 客户角色 | `customerRole` | 原样（已为中文则直接展示） |
| 租赁方式(实际) | `leaseMethodFact` | 原样 |
| 合同名称 | `contName` | 原样 |
| 内部收益率(%) | `irr` | 数值原样；已带 `%` 则不再追加 |
| 综合收益率(%) | `cmprhnsvIrr` | 同上 |
| 合同金额(元) | `contCashPledge` | 千分位 + 2 位小数 |
| 剩余本金(元) | `corpusBalancePledge` | 千分位 + 2 位小数 |
| 当前逾期金额(元) | `curOverdueAmount` | 千分位 + 2 位小数 |
| 合同起租日 | `leaseBeginDate` | 原样 |
| 合同到期日 | `contEndDate` | 原样 |
| 当前逾期天数 | `curOverdueDays` | 原样 |
| 历史最大逾期天数 | `historyOverdueDays` | 原样 |
| 历史逾期期数 | `historyOverdueTimes` | 原样 |

**合计行 summary：** 仅取 `leaseAmountTotal` 下表三个字段，**禁止**从 rows 求和或取同名其他字段。

| summary 列 | 取值路径 | 说明 |
| ---------- | -------- | ---- |
| 序号列 | 固定文案 `合计` | — |
| `contCashPledge`（合同金额） | `leaseAmountTotal.contCashPledge` | 千分位 + 2 位小数 |
| `corpusBalancePledge`（剩余本金） | `leaseAmountTotal.riskExposure` | 合计里字段名为 `riskExposure`，写入「剩余本金」列；禁止用 rows 的 `corpusBalancePledge` 顶替 |
| `curOverdueAmount`（当前逾期金额） | `leaseAmountTotal.curOverdueAmount` | 千分位 + 2 位小数 |
| 其余未列出的列 | — | `—` |

- 空态：`暂无合作历史数据`；两表皆空时 `所有客户均无合作历史数据`

## 八、空值与格式化

| 规则 | 说明 |
| ---- | ---- |
| 空值占位 | `null` / `""` / 缺失 → 展示值填 `—` |
| 金额 | 千分位 + 保留 2 位小数，如 `10,000.00` |
| 收益率 | 接口已为百分比文案则原样；纯数字可按业务约定补 `%`，不做额外精度改写 |
| 枚举 | 直接展示接口返回的中文值，不做码值转换 |
| 列表顺序 | 按接口返回顺序输出，不重排 |
| 合计 | `contCashPledge`←`*.contCashPledge`，`corpusBalancePledge`←`*.riskExposure`，`curOverdueAmount`←`*.curOverdueAmount`；字段缺失则该格填 `—`；**禁止**按 rows 求和 |

## 九、约束

1. 必须可识别 `moduleIndex: 3`
2. 仅输出本模块 HTML 片段
3. 禁止内联 `style`；禁止文档壳与 `<style>`
4. 空值统一为 `—`
5. 完整报告由 `00.prjc_html_report` 调度拼接
6. 不输出知识图谱、筛选主体、更新按钮等页面交互能力
7. 宽表不拆块；14～15 列完整输出于单个叠行表
8. 两表合计三金额列不得改用其他字段或自行汇总
