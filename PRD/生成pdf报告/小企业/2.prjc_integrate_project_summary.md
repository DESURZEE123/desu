# 项目概要 · 功能整合

> L1 · `moduleIndex: 2` · 上游：尽调全量入参 · 下游：`prjc_style_render`  
> 仅输出结构化 JSON（无 HTML）；完整报告须经 L0（`prjc_integrate_report`）调度。

**职责：** 从入参提取 `labelInfo`，按小企业（`prjc-slb`）映射警示 / 负面双卡 + 突破说明，并标注 `displayType`。不做标签条件重算、不调外部接口、不做 HTML 渲染。PDF 按页面顺序全文展开（无链接弹窗、无悬浮省略）。

---

## 一、模块标识

| 字段 | 值 |
| ---- | -- |
| `moduleIndex` | `2` |
| `moduleKey` | `project_summary` |
| `moduleName` | `项目概要` |

---

## 二、数据来源

| 路径 | 说明 |
| ---- | ---- |
| `labelInfo` | 模块主对象 |
| `labelInfo.riskLabel[]` | 警示清单条目 |
| `labelInfo.negativeList[]` | 负面清单条目 |
| `labelInfo.labelDesc` | 突破负面清单/警示清单说明 |

**PDF 不输出：** `queryTime` / `updateTime` / `highlightLabel` / `status` / `pkRecord`；以及变更记录弹窗、标签链接交互、重新计算按钮、顶栏更新时间等页面能力。

---

## 三、整模块门禁（校验）

先按 §四规范化清单，再判定；不通过 → **整模块不输出**（L0 跳过），不中断其它模块：

| # | 条件 | 结果 |
| -: | ---- | ---- |
| 1 | `labelInfo` 缺失 / `null` | 不输出 |
| 2 | 规范化后 `riskLabel`、`negativeList` **均无数据** | 不输出 |

说明：

- 「有数据」= 过滤空白后数组非空  
- 至少一方清单有数据 / `labelDesc` 有值 → 通过门禁

---

## 四、清单规范化与条目校验

对 `riskLabel` / `negativeList` 分别处理：

| 规则 | 说明 |
| ---- | ---- |
| 空白剔除 | 过滤 `null` / `""` / 仅空白；过滤后为空 → 该清单无数据 |
| 顺序 | 按接口数组顺序，L1 **不重排** |
| 文案 | 原样透传，不改写、不截断；保留全角符号（如 `＜`） |
| PDF 展示 | **全文展示**，不做省略号 / hover |

---

## 五、展示与格式化（校验）

门禁通过后，按固定顺序组装 blocks（可缺省个别 block，但相对顺序不变）。模块顶栏：「项目概要」。

| 顺序 | blockKey | label | displayType | 输出条件 | 格式化校验 |
| :--: | -------- | ----- | ----------- | -------- | ---------- |
| 1 | `labelPanel` | （不传） | `labelPanel` | 至少一方清单有数据 | 见下表 |
| 2 | `labelDesc` | `突破负面清单/警示清单说明` | `longText` | 至少一方清单有数据时**必出** | `trim` 后原样；空 → `—`；不渲染页面必填红星 `*` |

### `labelPanel` 结构校验

| 字段 | 校验 |
| ---- | ---- |
| `panels[]` | 仅含**有数据**的清单；顺序固定：警示 → 负面；两方皆空则不输出本 block |
| `panels[].blockKey` | `riskLabel` / `negativeList` |
| `panels[].label` | 固定：`警示清单` / `负面清单` |
| `panels[].tone` | 固定：`warning`（橙）/ `negative`（红） |
| `panels[].items[]` | 规范化后的字符串数组，按入参顺序 |

- 仅一方有数据：`panels.length === 1`；L2 单卡仍按卡样式渲染（宽度对齐双卡）
- `highlightLabel`：**不输出**（待业务定义后再扩展）

其它：不做标签条件重算（以入参落库为准）；不修改 / 不补充业务数据；输出不得含 HTML；必须带 `moduleIndex: 2`。

**L2 协作（`labelPanel`）：** 外层 `report-label-panel`；单卡 `report-label-card--warning` / `--negative`；卡头 `report-label-card__title`；列表 `ul.report-label-card__list > li`。链接型标签文案按纯文本输出。
