# 项目基本信息 · 功能整合

> L1 · `moduleIndex: 5` · 上游：尽调全量入参 · 下游：`prjc_style_render`  
> 仅输出结构化 JSON（无 HTML）；完整报告须经 L0（`prjc_integrate_report`）调度。

**职责：** 从入参提取 `projectBaseInfo` 及相关子对象，按小企业（`prjc-slb`）字段映射并标注 `displayType`。不做业务分析或 HTML 渲染。

---

## 一、模块标识

| 字段 | 值 |
| ---- | -- |
| `moduleIndex` | `5` |
| `moduleKey` | `project_base_info` |
| `moduleName` | `项目基本信息` |

---

## 二、数据来源

| 路径 | 说明 |
| ---- | ---- |
| `projectBaseInfo` | 模块主对象 |
| `projectBaseInfo.projectType` | 项目类型（决定是否输出「对应老合同」） |
| `projectBaseInfo.oldContInfoList[]` | 对应老合同列表（老客租专用） |
| `projectBaseInfo.oldContInfoList[].oldContName` | 老合同名称（展示用） |
| `projectBaseInfo.oldContInfoList[].oldContId` | 老合同主键（仅匹配，**不输出**） |
| `projectBaseInfo.settleBeLeaseContList` | 起租前结清合同 |
| `projectBaseInfo.environmentAndSocialRisk` | 环境与社会风险评估 |
| `projectBaseInfo.siteSituationList` | 现场尽调情况列表 |
| `projectBaseInfo.companyBaseInfo` | 项目基本情况 |

**PDF 不输出：** 报价信息、参考收益率（通用大单专属）、项目备案情况、现场考察情况（`siteSituation`）、手续情况、尽调情况说明、业务信息来源列表、`oldContId`

---

## 三、条件字段门禁（校验）

本模块**始终输出**（四块齐全）；条件字段按下表判定：

| # | 条件字段 | 条件 | 结果 |
| -: | -------- | ---- | ---- |
| 1 | `对应老合同`（`oldContInfoList`） | `projectType = 老客租项目` | 输出；插在「项目类型」后、「业务信息来源」前 |
| ↳ | | `projectType` 非「老客租项目」（如「区域线」） | **整字段不出现**（即使 `oldContInfoList` 有值也不出） |
| ↳ | | 老客租且列表 `null` / `[]` / 无名称 | 仍输出字段，值 `—` |
| 2 | `合同收益IRR(银票)` | 实施方案存在银票投放且 `referenceYield.contIrrBanknote` 有值（若入参携带） | 在参考收益率相关字段中展示 |
| 3 | `SOFR类型` / `margin` | 业务部门 = 航运金融事业部（若入参携带） | 展示 |

**对应老合同取值：** `oldContInfoList[].oldContName`，按接口顺序，多个用 `；` 拼接。  
**对照：** 老客租样例 `projectType=老客租项目` 展示合同名；区域线样例 `projectType=区域线` 不展示本字段。

## 四、展示与格式化（校验）

模块顶栏：「项目基本信息」。blocks 顺序固定，不可调换。

| 顺序 | blockKey | label | displayType |
| :--: | -------- | ----- | ----------- |
| 1 | `projectBaseInfo` | （不传 / 空，无组标题） | `group` |
| 2 | `environmentAndSocialRisk` | `环境与社会风险评估` | `table` |
| 3 | `siteSituationList` | `现场尽调情况` | `table` |
| 4 | `companyBaseInfo` | `项目基本情况` | `longText` |

### 通用格式化

| 规则 | 说明 |
| ---- | ---- |
| 空值 | `null` / `""` / 缺失 → `—`（输出中不出现 `null` / 空串） |
| 金额 | 千分位 + 2 位小数（如 `10,000.00`） |
| 百分比 | 保留 4 位小数 + `%`（如 `8.5155%`） |
| 枚举 | 接口中文原样，不做码值转换 |
| 人员 | `managerName` / `custHelpName` 仅姓名，不传工号 |

其它：不修改 / 不计算 / 不补充业务数据；输出不得含 HTML；必须带 `moduleIndex: 5`。

### 4.1 首屏 group（`columns: 4` · 无组标题）

> 不传 `label`（或传空）。L2 有 `label` 才渲染 `report-section-title`，故顶栏下直接铺栅格，不对齐「● 项目基本信息」。  
> `siteSituationList` / `companyBaseInfo` 为独立 block，不放入本 group。

| 顺序 | label | 接口字段 | displayType | 格式化 |
| :--: | ----- | -------- | ----------- | ------ |
| 1 | 客户名称 | `customerName` | `direct` | 原样 |
| 2 | 项目金额(元) | `projectAmount` | `direct` | 金额 |
| 3 | 项目类型 | `projectType` | `direct` | 原样 |
| 3a | 对应老合同 | `oldContInfoList` | `direct` | **条件字段**，见 §三 #1；仅老客租时输出，插在本行位置 |
| 4 | 业务信息来源 | `projectSource` | `direct` | 原样 |
| 5 | 租赁方式 | `leaseMethod` | `direct` | 原样 |
| 6 | 资金用途 | `capitalUse` | `direct` | 原样 |
| 7 | 售后回租(新设备)原因 | `leasebackReason` | `direct` | 原样 |
| 8 | 售后回租(新设备)原因说明 | `leasebackExplain` | `longText` | 原样；`fullWidth: true` |
| 9 | 投保情况 | `insuranceSituation` | `direct` | 原样 |
| 10 | 项目经理 | `managerName` | `direct` | 仅姓名 |
| 11 | 项目协办人 | `custHelpName` | `direct` | 仅姓名 |
| 12 | 起租前结清合同 | `settleBeLeaseContList` | `direct` | 取合同名称，多个用 `；` 分隔；空 → `—` |
| 13 | 租赁物保险 | `leaseInsurance` | `longText` | 原样；`fullWidth: true` |

**对应老合同 child 结构：** `blockKey: oldContInfoList` · `label: 对应老合同` · `displayType: direct` · `value` 为拼接后的 `oldContName`（或 `—`）。

### 4.2 环境与社会风险评估（table）

数据源：`projectBaseInfo.environmentAndSocialRisk`（扁平对象 → 固定 **6 行**「指标 / 结果」表）。

| 列 label | key | 说明 |
| -------- | --- | ---- |
| 指标 | `indicator` | 固定中文文案（见下行序） |
| 结果 | `result` | 取对应接口字段原值 |

- `showIndex`: `false`
- `emptyText`: `暂无评估信息`

| 顺序 | 指标（`indicator`） | 接口字段 → `result` |
| :--: | ------------------- | ------------------- |
| 1 | 拟承租人经营活动是否涉及业务排除清单 | `exclusionBusinessResult` |
| 2 | 所属行业是否为国家产业政策、行业准入政策限制的行业 | `policyRestrictResult` |
| 3 | 是否取得主管部门颁发的特定行业的许可经营证明 | `operateLicenseResult` |
| 4 | 是否存在国家或省级主管部门认定的重大环境、安全生产违法违规行为 | `offenceResult` |
| 5 | 租赁物是否存在环境和社会风险隐患（易燃易爆物、危险化学品、有毒有害物等） | `hiddenRiskResult` |
| 6 | 评估结论（高、中、低） | `assessResult` |

### 4.3 现场尽调情况（table）

数据源：`projectBaseInfo.siteSituationList`  
`showIndex: true` · `emptyText: 暂无现场尽调记录`

| 列 label | key | 格式化 |
| -------- | --- | ------ |
| 尽调人员 | `workerList` | `workerList[]` 取 `userName`，多人用 `、` 拼接 |
| 尽调日期 | `signDate` | 原样 |
| 地点 | `address` | 原样 |
| 主要内容 | `context` | 原样 |

### 4.4 项目基本情况（longText）

数据源：`projectBaseInfo.companyBaseInfo` → `blockKey: companyBaseInfo` · `label: 项目基本情况` · `displayType: longText`；空 → `—`。
