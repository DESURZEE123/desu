# 关联企业信息 · 功能整合

> L1 · `moduleIndex: 9` · 上游：尽调全量入参 · 下游：`prjc_style_render`  
> 仅输出结构化 JSON（无 HTML）；完整报告须经 L0（`prjc_integrate_report`）调度。

**职责：** 从入参提取 `associateCompany`，按小企业（`prjc-slb`）映射概要卡片 + 各企业详情（基本信息 / 主营业务 / 股权 / 实控人 / 司法诉讼），并标注 `displayType`。不调 CRM / 司法接口、不做 HTML 渲染。PDF 按概要列表顺序全部展开（无折叠 / Tab）。

---

## 一、模块标识

| 字段 | 值 |
| ---- | -- |
| `moduleIndex` | `9` |
| `moduleKey` | `related_enterprise` |
| `moduleName` | `关联企业信息` |

---

## 二、数据来源

| 路径 | 说明 |
| ---- | ---- |
| `associateCompany` | 模块主对象 |
| `.associatedCompanySynopsisList[]` | 概要列表（标签 + 名称 + 证件号） |
| `.associatedCompanySynopsisList[].isGuarantor` | `是`→担保人，否则→非担保人 |
| `.associatedCompanySynopsisList[].customerName` / `crdntlsCode` | 客户名称 / 统一社会信用代码 |
| `.associatedCompanyList[]` | 详情列表（结构与 `companyPublicInfo` 同构） |
| `.associatedCompanyList[].baseInfo` | 基本信息 |
| `.associatedCompanyList[].relationTypes[]` / `otherDesc` | 与承租人关系 / 其他关系说明 |
| `.associatedCompanyList[].shareholderList[]` / `shareholderTotal` | 股权明细 + 合计 |
| `.associatedCompanyList[].controllerIntroduction` | 实控人及股东情况介绍 |
| `.associatedCompanyList[].judicialLitigationInfo` | 司法诉讼（含高低风险列表 / `updateTime` / 说明） |

**PDF 不输出：** 主键；内嵌 `collaborationHistoryModel`；`assetSize` / `financialAnalysisList` 等截图外字段；仅有概要无详情的企业不输出详情区。

---

## 三、整模块与 block 门禁（校验）

| # | 条件 | 结果 |
| -: | ---- | ---- |
| 1 | `associateCompany` 缺失 / `null` | **整模块不输出**（L0 跳过） |
| 2 | 概要列表与详情列表均为空 | 输出 empty「暂无关联企业」 |
| 3 | 仅有概要、无匹配详情 | 仅出概要卡片；**不**出详情 block |
| 4 | 详情匹配 | 按 `synopsisList` 顺序，以 `customerNo` 匹配 `associatedCompanyList` |

## 四、展示与格式化（校验）

模块顶栏：「关联企业信息」。

| 顺序 | blockKey | displayType | 条件 |
| :--: | -------- | ----------- | ---- |
| 1 | `associatedCompanySynopsisList` | `associateCompanySynopsis` | 概要卡片列表 |
| 2+ | `company_{customerNo}` | `associateCompanyDetail` | 每家有详情的企业一组 |

### `associateCompanyDetail` 内 childBlocks 顺序

| 顺序 | blockKey | label | displayType | 条件 |
| :--: | -------- | ----- | ----------- | ---- |
| 1 | `baseInfo` | `基本信息` | `group` | 必出 |
| 2 | `mainBusiness` | `主营业务` | `longText` | 有值时 |
| 3 | `shareholderList` | `股权结构` | `table` | 必出 |
| 4 | `controllerIntroduction` | `实控人及股东情况介绍` | `longText` | 有值时 |
| 5 | `judicialLitigationInfo` | `司法诉讼信息` | `litigationCards` | 必出 |
| 6 | `judicialLitigationInfoDesc` | `司法诉讼信息说明` | `longText` | 有值时 |

### 通用格式化

| 规则 | 说明 |
| ---- | ---- |
| 空值 | `null` / `""` / 缺失 → `—` |
| 金额 | 千分位 |
| `relationTypes[]` | 多值用 `、` 拼接 |
| 列表顺序 | 按 `synopsisList` / 接口顺序，L1 **不重排** |
| 详情标题 | **仅**企业名称 + 统一社会信用代码；**不**输出 `guarantorTag` / `guarantorTone` |

### 4.1 概要卡片 `associateCompanySynopsis`

**仅概要卡片**输出担保人标签：

| 条件 | `guarantorTag` | `guarantorTone` |
| ---- | -------------- | --------------- |
| `isGuarantor === '是'` | `担保人` | `guarantor`（蓝平行四边形） |
| 否则 | `非担保人` | `nonGuarantor`（黄平行四边形） |

每项含：`guarantorTag` / `guarantorTone` / `customerName` / `crdntlsCode`。

### 4.2 基本信息 `baseInfo`（group · columns: 4）

| 顺序 | label | 接口字段 | 备注 |
| :--: | ----- | -------- | ---- |
| 1 | 企业名称 | `baseInfo.customerName` | |
| 2 | 统一社会信用代码 | `baseInfo.crdntlsCode` | |
| 3 | 法定代表人 | `baseInfo.legalRepresentativeCustomerName` | |
| 4 | 实际控制人 | `baseInfo.actControlsName` | |
| 5 | 成立时间 | `baseInfo.estblshDate` | |
| 6 | 注册资本(万元) | `baseInfo.rgstrdCapital` | 千分位 |
| 7 | 行业小类 | `baseInfo.pkIndustrySortLittle.name` | |
| 8 | 从业人数 | `baseInfo.employeeNum` | |
| 9 | 注册地址 | `baseInfo.rgstrdAddress` | `fullWidth: true` |
| 10 | 与承租人关系 | `relationTypes[]` | `、` 拼接 |
| 11 | 其他关系说明 | `otherDesc` | `fullWidth: true` |

### 4.3 股权结构 `shareholderList`

**showIndex：** `true`；**emptyText：** `暂无股权结构数据`。  
数据源：`shareholderList[]` + 同级 `shareholderTotal`。

| 列 label | key | 格式化 |
| -------- | --- | ------ |
| 股东名称 | `shareholderName` | 明细原样；合计行固定 `合计` |
| 出资额(万元) | `shareholderCapitalAmount` | 千分位；合计取 `shareholderTotal.shareholderCapitalAmount` |
| 占比(%) | `holdStockRatio` | 原样；合计取 `shareholderTotal.holdStockRatio` |

**合计行：** 取自 `shareholderTotal`；无 `shareholderTotal` → **不**输出合计行。列表空 / null → empty「暂无股权结构数据」。

### 4.4 司法诉讼 `litigationCards`

规则同承租人基本信息模块（§4.5）。数据源：`associatedCompanyList[].judicialLitigationInfo`。

| 属性 | 校验 |
| ---- | ---- |
| `updateTime` | 标题右侧「司法诉讼数据更新时间：{time}」 |
| `cards[]` | 先高风险后普通；过滤 `caseNum <= 0` |
| `cards[].tone` | `highRisk`（红）/ `common`（蓝） |
| `emptyText` | `客户暂无司法诉讼数据` |

**说明 longText：** `judicialLitigationInfoDesc` 有值时输出；空 / null 不输出。

**L2：** 卡片左起换行，宽约 3 列，不均分拉满；布局与承租人 / 增信措施一致。

其它：不修改 / 不补充业务数据；输出不得含 HTML；必须带 `moduleIndex: 9`。
