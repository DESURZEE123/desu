# 承租人基本信息 · 功能整合

> L1 · `moduleIndex: 8` · 上游：尽调全量入参 · 下游：`prjc_style_render`  
> 仅输出结构化 JSON（无 HTML）；完整报告须经 L0（`prjc_integrate_report`）调度。

**职责：** 从入参提取 `lesseeBaseInfo.companyPublicInfo`，按小企业（`prjc-slb`）映射基本信息 / 许可证 / 沿革 / 股权 / 实控人 / 司法诉讼，并标注 `displayType`。不调法人客户 / 司法接口、不做 HTML 渲染。PDF 按序全文展开（无编辑 / 更新司法按钮）。

---

## 一、模块标识

| 字段 | 值 |
| ---- | -- |
| `moduleIndex` | `8` |
| `moduleKey` | `lessee_base_info` |
| `moduleName` | `承租人基本信息` |

---

## 二、数据来源

| 路径 | 说明 |
| ---- | ---- |
| `lesseeBaseInfo.companyPublicInfo` | 模块主对象 |
| `.baseInfo` | 基本信息；含 `mainBusiness` / `companyEvolution` |
| `.industryLicenseList[]` | 行业许可证 |
| `.shareholderList[]` / `.shareholderTotal` | 股权结构明细 + 合计 |
| `.controllerIntroduction` | 实控人及股东情况介绍 |
| `.judicialLitigationInfo` | 司法诉讼总览 |
| `.judicialLitigationInfo.caseTypeHighRiskList[]` | 高风险案件标签 |
| `.judicialLitigationInfo.caseTypeCommonList[]` | 普通案件标签 |
| `.judicialLitigationInfo.judicialLitigationInfoDesc` | 司法诉讼信息说明 |
| `.judicialLitigationInfo.updateTime` | 司法诉讼数据更新时间 |

**PDF 不输出：** 主键；`customerNo` / `customerType[]`；`personActControlList` / `serviceInformAdress`；`assetSize` / `financialAnalysisList` / `loan`；内嵌 `collaborationHistoryModel`（由合作历史模块输出）；「更新司法涉诉数据」按钮。

---

## 三、整模块门禁（校验）

| # | 条件 | 结果 |
| -: | ---- | ---- |
| 1 | `lesseeBaseInfo` 或 `companyPublicInfo` 缺失 / `null` | **整模块不输出**（L0 跳过） |

通过后按 §四固定顺序组装；表空仍出 `emptyText`；说明类 longText 空则不输出该 block。

---

## 四、展示与格式化（校验）

模块顶栏：「承租人基本信息」。

| 顺序 | blockKey | label | displayType | 条件 |
| :--: | -------- | ----- | ----------- | ---- |
| 1 | `baseInfoTitle` | `基本信息` | `sectionHeading` | 必出（蓝竖条大区） |
| 2 | `baseInfo` | （不传） | `group` columns: 4 | 必出；避免与大区标题重复 |
| 3 | `industryLicenseList` | `行业许可证` | `table` | 必出（圆点小标题） |
| 4 | `mainBusiness` | `主营业务` | `longText` | 有值时 |
| 5 | `companyEvolution` | `公司沿革` | `longText` | 有值时 |
| 6 | `shareholderList` | `股权结构` | `table` | 必出；含合计行 |
| 7 | `controllerIntroduction` | `实控人及股东情况介绍` | `longText` | 有值时 |
| 8 | `judicialLitigationTitle` | `司法诉讼信息` | `sectionHeading` | 必出（蓝竖条大区） |
| 9 | `judicialLitigationInfo` | （不传） | `litigationCards` | 必出；含 `updateTime` |
| 10 | `judicialLitigationInfoDesc` | `司法诉讼信息说明` | `longText` | 有值时 |

> **标题层级：** 「基本信息」「司法诉讼信息」用 `sectionHeading`；同名内容块**不传** `label`。其余圆点小标题保留。

### 通用格式化

| 规则 | 说明 |
| ---- | ---- |
| 空值 | `null` / `""` / 缺失 → `—`（输出中不出现 `null` / 空串） |
| 金额（注册资本等） | 千分位 |
| 对象名 | `pkIndustrySortLittle` 取 `.name` |
| 列表顺序 | 按接口顺序，L1 **不重排** |
| `showIndex` | 许可证表 / 股权表均为 `true` |

### 4.1 基本信息 `baseInfo`

数据源：`companyPublicInfo.baseInfo`。注册地址整行。

| 顺序 | label | 接口字段 | 备注 |
| :--: | ----- | -------- | ---- |
| 1 | 企业名称 | `customerName` | |
| 2 | 统一社会信用代码 | `crdntlsCode` | |
| 3 | 法定代表人 | `legalRepresentativeCustomerName` | |
| 4 | 实际控制人 | `actControlsName` | |
| 5 | 成立时间 | `estblshDate` | |
| 6 | 注册资本(万元) | `rgstrdCapital` | 千分位 |
| 7 | 行业小类 | `pkIndustrySortLittle.name` | |
| 8 | 从业人数 | `employeeNum` | |
| 9 | 注册地址 | `rgstrdAddress` | `fullWidth: true` |

### 4.2 行业许可证 `industryLicenseList`

**emptyText：** `暂无行业许可证数据`。

| 列 label | key |
| -------- | --- |
| 证件名称 | `specCrdntlsName` |
| 编号 | `specCrdntlsCode` |
| 期限 | `expirationDate` |

### 4.3 主营业务 / 公司沿革

| blockKey | label | 取值 |
| -------- | ----- | ---- |
| `mainBusiness` | `主营业务` | `baseInfo.mainBusiness` |
| `companyEvolution` | `公司沿革` | `baseInfo.companyEvolution` |

空 / null → 不输出该 block。

### 4.4 股权结构 `shareholderList`

**emptyText：** `暂无股权结构数据`。数据源：`shareholderList[]` + `shareholderTotal`。

| 列 label | key |
| -------- | --- |
| 股东名称 | `shareholderName` |
| 出资额(万元) | `shareholderCapitalAmount` |
| 占比(%) | `holdStockRatio` |

**合计行 `summary`：** 取自 `shareholderTotal`；`shareholderName` 列固定 `合计`。

### 4.5 司法诉讼 `litigationCards`

数据源：`judicialLitigationInfo`。**不传 label**（大区由 `judicialLitigationTitle` 承担）。

| 属性 | 校验 |
| ---- | ---- |
| `updateTime` | 原样；展示「司法诉讼数据更新时间：{time}」 |
| `cards[]` | 先 `caseTypeHighRiskList`，再 `caseTypeCommonList` |
| 过滤 | `caseNum === 0` / 缺失 → **不输出**该卡片 |
| `cards[].caseType` | 案件类型标签名 |
| `cards[].caseNum` | 案件数量（右上角） |
| `cards[].tone` | 高风险 → `highRisk`（红）；普通 → `common`（蓝） |
| `emptyText` | `客户暂无司法诉讼数据` |

**L2：** 卡片左起自动换行，宽度约 3 列量级，**不**按行均分拉满；`highRisk` 红渐变 / `common` 蓝渐变。

其它：不修改 / 不补充业务数据；输出不得含 HTML；必须带 `moduleIndex: 8`。
