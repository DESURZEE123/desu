# 合作历史 · 功能整合

> L1 · `moduleIndex: 3` · 上游：尽调全量入参 · 下游：`prjc_style_render`  
> 仅输出结构化 JSON（无 HTML）；完整报告须经 L0（`prjc_integrate_report`）调度。

**职责：** 从入参提取项目级 `commonCollaborationHistoryModel`，按小企业（`prjc-slb`）映射并标注 `displayType`。不做业务分析、主体筛选计算、知识图谱或 HTML 渲染。

---

## 一、模块标识

| 字段 | 值 |
| ---- | -- |
| `moduleIndex` | `3` |
| `moduleKey` | `cooperation_history` |
| `moduleName` | `合作历史` |

---

## 二、数据来源

| 路径 | 说明 |
| ---- | ---- |
| `commonCollaborationHistoryModel` | 项目级合作历史（本模块**唯一**主数据源） |
| `.leaseCollaborationHistoryList` | 作为承租人情况列表 |
| `.leaseAmountTotal` | 承租人合计：`contCashPledge`（合同金额）/ `riskExposure`（剩余本金）/ `curOverdueAmount`（当前逾期金额） |
| `.guarantorCollaborationHistories` | 作为担保人情况列表 |
| `.guarantorAmountTotal` | 担保人合计（字段含义同 `leaseAmountTotal`） |
| `.cooperateHistoryDesc` | 合作历史说明 |

> 承租人 / 担保人模块内嵌的 `collaborationHistoryModel` **不**作本模块数据源。  
> **PDF 不输出：** 知识图谱、筛选主体、更新合作历史等页面交互；列表用入参已落库全量，不做前端筛选。

---

## 三、整模块与 block 门禁（校验）

本模块**始终输出**（即使两表皆空），按序组装 blocks：

| # | 规则 | 结果 |
| -: | ---- | ---- |
| 1 | `commonCollaborationHistoryModel` 缺失 / `null` | 仍输出两表空态（见 emptyText）；不输出说明 |
| 2 | 两表 `rows` 皆空（`null` / `[]`） | 两表均出；`emptyText` = `所有客户均无合作历史数据`；**不**出说明 |
| 3 | 仅一表为空 | 空表 `emptyText` = `暂无合作历史数据`；有数据表正常出；可出说明 |
| 4 | `cooperateHistoryDesc` | 仅当**至少一表有数据**时输出；有表无说明 → 值填 `—` |

---

## 四、展示与格式化（校验）

模块顶栏：「合作历史」。blocks 顺序固定，不可调换。每张表输出**完整列**（不拆表、不传 layout）；列数 > 8 时由 L2 自动叠行。

| 顺序 | blockKey | label | displayType | 条件 |
| :--: | -------- | ----- | ----------- | ---- |
| 1 | `leaseCollaborationHistoryList` | `承租人、关联方、担保人作为承租人情况` | `table` | 必出 |
| 2 | `guarantorCollaborationHistories` | `承租人、关联方、担保人作为担保人情况` | `table` | 必出 |
| 3 | `cooperateHistoryDesc` | `合作历史说明` | `longText` | 见 §三 #4 |

### 通用格式化

| 规则 | 说明 |
| ---- | ---- |
| 空值 | `null` / `""` / 缺失 → `—`（输出中不出现 `null` / 空串） |
| 金额 | 千分位 + 2 位小数（如 `10,000.00`） |
| 收益率（`irr` / `cmprhnsvIrr`） | 原样；已带 `%` 不再追加；纯数字可按业务补 `%`，不改精度 |
| 枚举 / 文案 | 接口中文原样，不做码值转换 |
| 列表顺序 | 按接口顺序，L1 **不重排** |
| `showIndex` | 两表均为 `true` |

### 4.3 合计行 `summary`（强校验）

两表均输出 `summary`；**仅**取对应合计对象三字段，**禁止**从 `rows` 求和，**禁止**用 rows 的 `corpusBalancePledge` 顶替 `riskExposure`。

| summary key（对应列） | 承租人取值 | 担保人取值 | 格式化 |
| --------------------- | ---------- | ---------- | ------ |
| `index`（序号列） | 固定 `合计` | 同左 | — |
| `contCashPledge` | `leaseAmountTotal.contCashPledge` | `guarantorAmountTotal.contCashPledge` | 金额；缺 → `—` |
| `corpusBalancePledge` | `leaseAmountTotal.riskExposure` | `guarantorAmountTotal.riskExposure` | 金额；缺 → `—` |
| `curOverdueAmount` | `leaseAmountTotal.curOverdueAmount` | `guarantorAmountTotal.curOverdueAmount` | 金额；缺 → `—` |

其余列在合计行填 `—`。

其它：不修改 / 不计算 / 不补充业务数据；输出不得含 HTML；必须带 `moduleIndex: 3`。
