# 实施方案 · 功能整合

> L1 · `moduleIndex: 6` · 上游：尽调全量入参 · 下游：`prjc_style_render`  
> 仅输出结构化 JSON（无 HTML）；完整报告须经 L0（`prjc_integrate_report`）调度。

**职责：** 从入参提取 `embodiment`（及同构报价 / 增信子对象），按小企业（`prjc-slb`）字段映射并标注 `displayType`。不做业务分析、不计算风险敞口、不做 HTML 渲染。页面 Tab（租金 / 保证金 / 其他收支）在 PDF 中按序全部展开。

---

## 一、模块标识

| 字段 | 值 |
| ---- | -- |
| `moduleIndex` | `6` |
| `moduleKey` | `implementation_plan` |
| `moduleName` | `实施方案` |

---

## 二、数据来源

| 路径 | 说明 |
| ---- | ---- |
| `embodiment` | 模块主对象 |
| `embodiment.riskExposure` | 预测风险敞口(元) |
| `embodiment.rate` | 预测风险敞口/设备原值(%) |
| `embodiment.lesseeAggregateRiskExposure` | 承租人累计风险敞口(元) |
| `embodiment.aggregateRiskExposure` | 承租人及关联方累计风险敞口(元) |
| `embodiment.advertisingInfoList[]` | 报价方案列表（投放 / 付款条件 / 各类计划） |
| `embodiment.advertisingInfoList[].paymentTermList` | 付款条件及笔数 |
| `embodiment.advertisingInfoList[].rentPlan` | 租金计划表（汇总 + 明细） |
| `embodiment.advertisingInfoList[].depositPlan` | 保证金计划 |
| `embodiment.advertisingInfoList[].otherPlan` | 其他收支计划 |
| `commonCreditEnhancementMeasure.creditEnhancementMeasureList[]` | 按 `quotName` 匹配的增信措施（**优先**） |
| `embodiment.creditEnhancementMeasureInfo` | 实施方案内嵌增信措施（次选） |
| `creditEnhancementMeasure` | 顶层增信措施（兜底） |

> 多报价按 `advertisingInfoList` 接口顺序逐条输出；每条以 `quotName` 作分组标题。  
> **PDF 不输出：** 保险规则 / 保险、单瓦融资额、支付方式 / 备注（环卫专属）；关联报价 / 取消关联 / 编辑 / 保存、知识图谱、付款条件选择等页面交互。

---

## 三、整模块与空态门禁（校验）

本模块**始终输出** `riskSummary`；报价与表块按空态规则处理：

| # | 条件 | 结果 |
| -: | ---- | ---- |
| 1 | `advertisingInfoList` 为 `null` / `[]` | 仍出风险敞口汇总（有值展示，无值 `—`）；**不**出报价子块；可追加 `empty` block，`emptyText: 暂无关联报价` |
| 2 | 单表为空 | 该表走对应 `emptyText`，其余块正常出 |
| 3 | 增信措施列表为空 | 仍出 `measureList`，`emptyText: 暂无增信措施` |
| 4 | 多报价 | 严格按 `advertisingInfoList` 顺序；每条报价子块（2～9）完整输出后再下一条 |

---

## 四、展示与格式化（校验）

模块顶栏：「实施方案」。blocks 顺序固定；多报价时对每个报价重复 2～9（`{i}` = 报价下标，从 0 起）。

| 顺序 | blockKey | label | displayType |
| :--: | -------- | ----- | ----------- |
| 1 | `riskSummary` | （无标题 / 可不传 label） | `group` |
| 2 | `quoteTitle_{i}` | `{quotName}` | `sectionHeading` |
| 3 | `loanInfo_{i}` | `投放信息` | `group` |
| 4 | `paymentTermList_{i}` | `付款条件及笔数` | `table` |
| 5 | `rentPlanSummary_{i}` | `租金计划表` | `group` |
| 6 | `rentPlanDetail_{i}` | （不传 label，紧接上块） | `table` |
| 7 | `depositPlan_{i}` | `保证金计划` | `table` |
| 8 | `otherPlan_{i}` | `其他收支计划` | `table` |
| 9 | `creditEnhancement_{i}` | `增信措施` | `measureList` |

### 通用格式化

| 规则 | 说明 |
| ---- | ---- |
| 空值 | `null` / `""` / 缺失 → `—` |
| 金额 | 千分位 + 2 位小数（如 `10,000.00`） |
| 比率 / 收益率 | 接口已为百分比文案则原样；纯数字不改精度（如 `10.8263`、`24.5000`） |
| 枚举 | 接口中文原样，不做码值转换 |
| 对象枚举 | 如 `guaranteeMethod` 为 `{ desc: "保证担保" }` 时取 `desc` |
| 列表顺序 | 按接口顺序，L1 **不重排** |
| 宽表 | 不拆 block；列数 > 8 时由 L2 叠行（含卡片内担保物表） |

其它：不修改 / 不计算 / 不补充业务数据；输出不得含 HTML；必须带 `moduleIndex: 6`。

### 4.1 风险敞口汇总（group · 4 字段）

数据源：`embodiment` 顶层。`columns: 4`；**不传 label**（顶栏指标行，无蓝色小节标题）。

| 列 label | key | displayType | 格式化 |
| -------- | --- | ----------- | ------ |
| 预测风险敞口(元) | `riskExposure` | `direct` | 金额 |
| 预测风险敞口/设备原值(%) | `rate` | `direct` | 原样；纯数字保留接口精度（如 `24.5000`） |
| 承租人累计风险敞口(元) | `lesseeAggregateRiskExposure` | `direct` | 金额 |
| 承租人及关联方累计风险敞口(元) | `aggregateRiskExposure` | `direct` | 金额 |

### 4.9 增信措施（measureList）

对齐页面卡片：每条措施一张卡（担保方式色标、客户身份行）；抵押/质押额外展开属性行 + 担保物明细表。  
`emptyText: 暂无增信措施`。**PDF 不输出：** 知识图谱入口、编辑/删除、担保人详情弹层。

**数据优先级（按 `quotName` 匹配当前报价）：**

1. `commonCreditEnhancementMeasure.creditEnhancementMeasureList` 中 `quotName` 与当前报价一致的项 → 其内层 `creditEnhancementMeasureList`
2. `embodiment.creditEnhancementMeasureInfo.creditEnhancementMeasureList`
3. `creditEnhancementMeasure.creditEnhancementMeasureList`（若带 `quotName` 则按报价过滤）

#### 4.9.1 卡片主字段（`items[]`）

| 字段 | key / 规则 | 格式化 |
| ---- | ---------- | ------ |
| 担保方式文案 | `guaranteeMethod` | 取对象 `desc`；已是字符串则原样 |
| 担保方式色调 | `guaranteeTone` | 见下表 |
| 客户名称 | `customerName` | 原样 |
| 关系标签 | `relationship` | 原样；空则不传（不渲染绿色关系 tag） |
| 证件类型 | `crdntlsType` | 原样 |
| 证件代码 | `documentCode` | 原样 |

**`guaranteeTone` 映射（按 `guaranteeMethod.code` / 文案）：**

| 担保方式 | code | `guaranteeTone` | 标签色（L2） |
| -------- | :--: | --------------- | ------------ |
| 保证担保 | 1 | `guarantee` | 橙 `#FF7D00` |
| 抵押担保 | 3 | `mortgage` | 蓝 `#3491FA` |
| 质押担保 | 5 | `pledge` | 浅橙 `#FF9A2E` |
| 其他 / 未知 | — | `default` | 灰 `#86909C` |

> 有 `desc` 无 `code` 时按文案包含「保证 / 抵押 / 质押」匹配；均无法匹配则 `default`。

#### 4.9.2 抵押 / 质押属性行（`attrs`）

仅当担保方式为 **抵押担保** 或 **质押担保** 时输出 `attrs`（保证担保不传）：

| 列 label | key | 格式化 |
| -------- | --- | ------ |
| 抵押物类别 | `collateralType` | 原样；空 → `—` |
| 抵质押物类型 | `mortgageAndPledgeType` | 原样；空 → `—` |
| 抵质押物分类 | `mortgageAndPledgeClass` | 原样；空 → `—` |

#### 4.9.3 担保物明细（`collateral`）

仅当 `collateralList` 非空时输出；结构复用 table Schema（L2 在卡片内渲染）。`collateralList` 为空 / null：**不传** `collateral`（保证担保天然无此块）。

| 列 label | key | 格式化 |
| -------- | --- | ------ |
| 担保物名称 | `assetsName` | 原样 |
| 所在地 | `locationVfbc` | 原样 |
| 车牌号/不动产面积 | `assetsNo1Vfbc` | 原样 |
| 机身号/不动产单元号 | `assetsNo` | 原样 |
| 租赁物唯一识别码/抵质押证书编号 | `assetsNo2Vfbc` | 原样 |
| 担保物估值(元) | `estimateValue` | 金额 |
| 币种 | `currtype` | 原样 |
| 第三方质押债务人 | `debtor` | 原样 |
| 是否第一顺位 | `isFirstOrder` | 原样 |
| 评估方式 | `assessMode` | 原样 |
| 优先受偿权数额 | `compensationNumber` | 金额（已是文案则原样） |
| 估值周期 | `valuationCycle` | 原样 |

- `collateral.label`: `担保物`
- `collateral.showIndex`: `true`
- **全部列**默认左对齐（不传 `align`，或统一 `align: "left"`）；表头与单元格对齐一致
- L2 用 `.report-measure-card__collateral .report-table th/td { text-align: left }` 兜底
