# 刚性负债分析 · 功能整合

> L1 · `moduleIndex: 12` · 上游：尽调全量入参 · 下游：`prjc_style_render`  
> 仅输出结构化 JSON（无 HTML）；完整报告须经 L0（`prjc_integrate_report`）调度。

**职责：** 从入参提取 `liabilityAnalysis`，按小企业（`prjc-slb`）映射借款情况（企业 / 个人）+ 对外担保 + 负债说明，并标注 `displayType`。不调征信/中登接口、不筛选主体、不做 HTML 渲染。PDF 按顺序全文展开（无 Tab / 折叠 / 筛选）；宽表由 L2 叠行，L1 不拆表。

---

## 一、模块标识

| 字段 | 值 |
| ---- | -- |
| `moduleIndex` | `12` |
| `moduleKey` | `liability_analysis` |
| `moduleName` | `刚性负债分析` |

---

## 二、数据来源

| 路径 | 说明 |
| ---- | ---- |
| `liabilityAnalysis` | 模块主对象 |
| `.loanSituation.companyLoanList[]` / `companyLoanTotal` | 企业借款明细 / 合计 |
| `.loanSituation.personLoanList[]` / `personLoanTotal` | 个人借款明细 / 合计 |
| `.externalGuaranteeSituationList[]` | 对外担保明细 |
| `.amountTotal` | 对外担保余额合计 |
| `.liabilityStatement` | 负债说明 |

**PDF 不输出：** `pkQueryRecord` / `queryStatusEnum`；`loanBalance`；`associateLiabilityInfo`；`personBorrowIndexList` / `companyBorrowIndexList`；`loanSituation.personBorrowDetailList`（个人主表用 `personLoanList` 汇总行）；`customerNo` / 各类主键；筛选 / 更新等页面操作。

## 三、整模块门禁（校验）

| # | 条件 | 结果 |
| -: | ---- | ---- |
| 1 | `liabilityAnalysis` 缺失 / `null` | **整模块不输出**（L0 跳过） |

通过后：

| 规则 | 说明 |
| ---- | ---- |
| 各表 `null` / `[]` | 仍出对应 `table`，走 `emptyText` |
| `liabilityStatement` 空 / null | 不出负债说明 block |
| `updateTime` 有值 | 出征信、中登数据更新时间 |

## 四、展示与格式化（校验）

模块顶栏：「刚性负债分析」。blocks 顺序固定。宽表完整列于**单个** table；叠行由 L2（`stackSpan` + 配对）；**不**按列数拆表。

| 顺序 | blockKey | label | displayType | 条件 |
| :--: | -------- | ----- | ----------- | ---- |
| 1 | `updateTime` | `征信、中登数据更新时间` | `direct` | 有值时 |
| 2 | `loanSituationTitle` | `借款情况` | `sectionHeading` | 必出 |
| 3 | `companyLoanList` | `企业借款` | `table` | 必出 |
| 4 | `personLoanList` | `个人借款` | `table` | 必出 |
| 5 | `externalGuaranteeSituationList` | `对外担保情况` | `table` | 必出 |
| 6 | `liabilityStatement` | `负债说明` | `longText` | 有值时 |

### 通用格式化

| 规则 | 说明 |
| ---- | ---- |
| 空值 | `null` / `""` / 仅空白 / 缺失 → `—` |
| 金额 | 千分位 + 2 位小数（number 或数字字符串均可） |
| 日期 / 枚举 / 文本 | 原样；`queryTime` 先 `trim` |
| `principalRole` | 非空元素用 `、` 连接；全空 → `—` |
| 五级分类 / 角色色标 | PDF **不做**彩色标签，仅中文文案 |

### 4.1 企业借款

**数据：** `loanSituation.companyLoanList`  
`showIndex: true` · `emptyText: 暂无企业借款数据`

| 列 label | key | 格式化 | 叠行 |
| -------- | --- | ------ | ---- |
| 借款主体 | `borrowingEntity` | 仅主体名称；日期走 `subKey` | `stackSpan` + `mergeSame`；`subKey: queryTime` |
| 主体角色 | `principalRole` | `、` 拼接；空 → `—` | `stackSpan` + `mergeSame` |
| 租赁借款余额合计(元) | `leaseLoanTotal` | 金额 | `stackSpan` + `mergeSame` |
| 非租赁借款余额合计(元) | `nonLeaseLoanTotal` | 金额 | `stackSpan` + `mergeSame` |
| 业务类型 | `businessType` | 原样 | 配对 |
| 机构编码 | `institutionalCode` | 原样 | 配对 |
| 授信机构 | `creditInstitutional` | 原样 | 配对 |
| 借款金额(元) | `loanAmount` | 金额 | 配对 |
| 余额(元) | `balance` | 金额 | 配对 |
| 起始日期 | `startDate` | 原样 | 配对 |
| 截止日期 | `deadline` | 原样 | 配对 |
| 担保方式 | `guaranteeMethod` | 原样 | 配对 |
| 抵押类型 | `mortgageType` | 原样 | 配对 |
| 五级分类 | `fiveLevel` | 原样（无色标） | 配对 |
| 当前逾期月份 | `curOverdueMonth` | 原样 | 配对 |
| 数据来源 | `querySource` | 原样 | 配对 |
| 是否与征信重复 | `repeat` | 原样；空 → `—` | 配对（**不得**单独拆表） |

**借款主体展示：**

- `borrowingEntity` 只填主体名称（供 `mergeSame` 比较）
- `queryTime` trim 非空时 L2 按 `subKey` 渲副行：`（征信查询日期: {queryTime}）`
- 同主体多行：每行仍写相同 `borrowingEntity` / `principalRole` / 租赁与非租赁合计；L2 `mergeSame`（`rowspan = 记录数 × 2`）
- 序号列**不合并**，每条明细各自编号

**不输出列：** `isWhite` / `loanOrigTypeName` / `customerNo` / 主键

**summary（强校验）：**

| summary key | 取值 |
| ----------- | ---- |
| `index` | `合计` |
| `leaseLoanTotal` | 按 `borrowingEntity` **去重取首行**的 `leaseLoanTotal` 求和后金额格式化 |
| `nonLeaseLoanTotal` | 同上，对 `nonLeaseLoanTotal` |
| `loanAmount` | `companyLoanTotal.loanAmount` 金额格式化 |
| `balance` | `companyLoanTotal.balance` 金额格式化 |
| 其余列 | `—` |

> `repeat == 是` 时业务侧合计会排除该行；PDF 以接口 `companyLoanTotal` 为准，**不**自行按 `repeat` 重算借款金额/余额合计。

### 4.2 个人借款

**数据：** `loanSituation.personLoanList`  
`showIndex: true` · `emptyText: 暂无个人借款数据`

| 列 label | key | 格式化 | 叠行 |
| -------- | --- | ------ | ---- |
| 借款主体 | `borrowingEntity` | 仅主体名称；日期走 `subKey` | `stackSpan` + `mergeSame`；`subKey: queryTime` |
| 业务大类 | `businessCategory` | 原样 | 配对 |
| 担保方式 | `guaranteeMethod` | 原样 | 配对 |
| 账户数量 | `accountNum` | 数字转字符串 | 配对 |
| 借款金额(元) | `loanAmount` | 金额 | 配对 |
| 余额(元) | `balance` | 金额 | 配对 |
| 累计逾期月数 | `overdueMonths` | 原样 | 配对 |
| 当前逾期账户数 | `overdueAccountNum` | 原样 | 配对 |
| 最长逾期月数 | `maxOverdueMonths` | 原样 | 配对 |
| 最大逾期金额(元) | `maxOverdueAmount` | 金额 | 配对 |
| 近一个月到期金额(元) | `balanceDue` | 金额 | 配对 |
| 近三个月被其他机构查询贷款审批及担保资格的次数 | `queryTimes` | 原样 | 配对 |
| 数据来源 | `querySource` | 原样 | 配对 |

**不输出：** `isBadAccount` / `maxCreditAmount` / `isWhite` / `principalRole` / `customerNo`

**summary（取 `personLoanTotal`）：**

| summary key | 取值 |
| ----------- | ---- |
| `index` | `合计` |
| `loanAmount` | `personLoanTotal.loanAmount` |
| `balance` | `personLoanTotal.balance` |
| `maxOverdueAmount` | `personLoanTotal.maxOverdueAmount`（有则填；优先有值则展示） |
| `balanceDue` | `personLoanTotal.balanceDue` |
| 其余列 | `—` |

### 4.3 对外担保情况

**数据：** `externalGuaranteeSituationList`  
`showIndex: true` · `emptyText: 暂无对外担保数据`

| 列 label | key | 格式化 | 叠行 |
| -------- | --- | ------ | ---- |
| 担保主体 | `borrowingEntity` | 仅主体名称；日期走 `subKey` | `stackSpan` + `mergeSame`；`subKey: queryTime` |
| 主体角色 | `principalRole` | `、` 拼接 | `stackSpan` + `mergeSame` |
| 被担保主体 | `guaranteedEntity` | 原样；空串 → `—` | 配对 |
| 业务类型 | `businessType` | 原样 | 配对 |
| 余额(元) | `balance` | 金额 | 配对 |
| 起始日期 | `startDate` | 原样 | 配对 |
| 截止日期 | `deadline` | 原样 | 配对 |
| 五级分类 | `fiveLevel` | 原样 | 配对 |
| 当前逾期月数 | `curOverdueMonth` | 原样 | 配对 |
| 是否存在对应借款 | `loanExists` | 原样 | 配对 |
| 数据来源 | `querySource` | 原样 | 配对 |

**不输出：** `paymentAmount` / `customerNo` / 主键

**summary：**

| summary key | 取值 |
| ----------- | ---- |
| `index` | `合计` |
| `balance` | `amountTotal` 金额格式化 |
| 其余列 | `—` |

其它：不修改 / 不补充业务数据；输出不得含 HTML；必须带 `moduleIndex: 12`。

**L2：** `direct` / `sectionHeading` / `table`（`summary` / `stackSpan` / `mergeSame` / `subKey`）/ `longText`；宽表适用叠行约定。
