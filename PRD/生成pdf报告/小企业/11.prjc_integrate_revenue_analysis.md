# 经营数据分析 · 功能整合

> L1 · `moduleIndex: 11` · 上游：尽调全量入参 · 下游：`prjc_style_render`  
> 仅输出结构化 JSON（无 HTML）；完整报告须经 L0（`prjc_integrate_report`）调度。

**职责：** 从入参提取 `revenueAnalysis`，按小企业（`prjc-slb`）映射主体 / 资产规模 / 产销 / 收入 / 还款能力，做分组·透视与 `displayType` 标注。不调税票/流水接口、不筛选主体、不做 HTML 渲染。PDF 按顺序全文展开（无 Tab / 筛选 / badge）；宽表由 L2 叠行。

## 三、整模块门禁（校验）

| # | 条件 | 结果 |
| -: | ---- | ---- |
| 1 | `revenueAnalysis` 缺失 / `null` | **整模块不输出**（L0 跳过） |

通过后：

| 规则 | 说明 |
| ---- | ---- |
| 各表 `null` / `[]` | 仍出对应 `table`，走 `emptyText` |
| 说明类 longText 空 | 不出该 block |
| `factoryType` | `0`→自有、`1`→租用、`2`→无厂房；无法识别 → 原样或 `—` |
| `paymentMethod[]` | 多用 `/` 拼接（如 `现金/银行承兑`） |
| 主体角色 | `customerRole[]` 保留数组；列 `cellType: roleTag` |
| 分组表 | 每组末插「合计」行；`mergeSame` 合并主体名称与角色 |
| 收入透视 | L1 按时间区间动态列；底部汇总 `_summary: true`，首列 `colspan=3` |
| 数值 | 原样透传（不追加 `%`）；空 → `—` |

### 4.7 营业收入分析（透视）

**数据：** `operatingIncomeAnalysis[]` + `operatingIncomeAnalysisTotal[]`  
`showIndex: false` · `emptyText: 暂无营业收入分析数据`

#### 列

| 列 label | key / 来源 | 说明 |
| -------- | ---------- | ---- |
| 主体名称 | `customerName` → 输出 `subjectName` | `mergeSame` |
| 主体角色 | `customerRole` | `mergeSame` + `roleTag` |
| 类型 | 固定文案 | `开票收入(万)` / `不开票收入(万)` |
| `{timeInterval}`… | 动态列 | 列头取 `timeInterval` 原文；按 `serialNumber` 升序去重 |

#### 明细行

1. 按 `serialNumber` 升序提取不重复 `timeInterval` 作动态列顺序  
2. 按 `customerNo` 分组（保持首次出现顺序）；每组 **2** 行：

| 类型（`type`） | 各动态列取值 |
| -------------- | ------------ |
| `开票收入(万)` | `invoicingRevenue` |
| `不开票收入(万)` | `nonInvoicingRevenue` |

3. 同主体两行 `subjectName` / `customerRole` 相同，L2 `mergeSame`（rowspan=2）  
4. 某主体某区间缺失 → `—`  
5. **不输出** `amountTotal` / `pkRevenueAnalysis` / `startYear` / `endYear`

#### 底部汇总（`operatingIncomeAnalysisTotal[]`）· 强校验

按相同 `timeInterval` 对齐；共 **3** 行（`_summary: true`；首列跨「主体名称 / 主体角色 / 类型」三列）：

| 顺序 | 汇总 label | 各动态列取值字段 |
| :--: | ---------- | ---------------- |
| 1 | `合计(万)` | `invoicingRevenue` |
| 2 | `关联交易(万)` | `relatedTransaction` |
| 3 | `剔除关联交易后合计(万)` | `excludeRelatedTransaction` |

- 匹配键：`operatingIncomeAnalysisTotal[].timeInterval` ≡ 动态列  
- 某区间合计缺失 → `—`  
- **禁止**用明细行自行加总替代后端 `operatingIncomeAnalysisTotal`

后续：`operatingIncomeDesc`（longText，有值时）；`verifiableRatio` ← `incomeAnalysis.ratio`（direct，有值时）。

### 4.8 营业收入核验（透视）· 强校验

**数据：** `operatingIncomeVerificationList[]` + `operatingIncomeVerificationFlowTotalList[]`  
`showIndex: false` · `emptyText: 暂无营业收入核验数据`  
> 页面标题可为「营业收入核查」；PDF label 统一 `营业收入核验`。

#### 列

| 列 label | key / 来源 | 说明 |
| -------- | ---------- | ---- |
| 主体名称 | `customerName` → `subjectName` | `stackSpan` + `mergeSame`（同主体 6 行） |
| 主体角色 | `customerRole` | `stackSpan` + `mergeSame` + `roleTag` |
| 类型 | 固定文案 | 见下表；`stackSpan` |
| `{timeInterval}`… | 动态月列 | 列头取原文；按 `serialNumber` 升序去重 |
| 合计 | L1 计算 | 该行各月展示值求和（保留 2 位） |
| 均值 | L1 计算 | 该行各月展示值求平均（保留 2 位）；无有效月值 → `—` |

#### 明细行（每组固定 6 行，顺序不可调换）

1. 按 `serialNumber` 升序提取不重复 `timeInterval`  
2. 按 `customerNo` 分组（保持首次出现顺序）：

| 顺序 | 类型（`type`） | 各月取值字段 | 备注 |
| :--: | -------------- | ------------ | ---- |
| 1 | `纳税申报收入(万)` | `taxableIncome` | |
| 2 | `银行流水(万)(剔除关联交易)` | `bankStatement` | **见下方高亮规则** |
| 3 | `银行承兑(万)(剔除关联交易)` | `bankAcceptance` | |
| 4 | `纳税申报采购(万)` | `taxDeclareIncome` | |
| 5 | `电费(万)` | `electricityFee` | |
| 6 | `工资总额(万)` | `wage` | |

#### 银行流水高亮规则（强校验 · 不可改）

| 规则 | 说明 |
| ---- | ---- |
| 展示值 | **始终**取 `bankStatement`（剔除关联交易后流水） |
| 高亮条件 | 当 `bankStatementFromJz` **有值**且与 `bankStatement` **不相等**时：该单元格标记 `cellType: highlight`（页面黄字） |
| 禁止替换 | **绝不**用 `bankStatementFromJz` 替换展示值 |
| 不成列 | `bankStatementFromJz` **不单独成列** |

其它：

- 某主体某月缺失 → `—`，不参与合计/均值  
- **不输出** `pkOperatingRevenue` / `totalFlow` / `relatedTransaction` / `balance` / `bankFlow` / `startYear` / `endYear`（`totalFlow` / `relatedTransaction` 仅用于底部汇总对象）

#### 底部汇总（`operatingIncomeVerificationFlowTotalList[]`）· 强校验

共 **3** 行（`_summary: true`）：

| 顺序 | 汇总 label | 各月取值字段 |
| :--: | ---------- | ------------ |
| 1 | `流水与承兑合计(万)(剔除关联交易)` | `totalFlow` |
| 2 | `纳税申报收入关联交易(万)` | `relatedTransaction` |
| 3 | `剔除关联交易后纳税申报收入合计(万)` | `excludeRelatedTransaction` |

- 匹配键：`operatingIncomeVerificationFlowTotalList[].timeInterval` ≡ 动态月列  
- 「合计」列：对该汇总行各月求和；「均值」列：填 `—`  
- **禁止**用明细行自行加总替代后端 `operatingIncomeVerificationFlowTotalList`

后续：`operatingIncomeVerifyDesc`（longText，有值时）。
