# 项目变更信息 · 功能整合

> L1 · `moduleIndex: 1` · 上游：尽调全量入参 · 下游：`prjc_style_render`  
> 仅输出结构化 JSON（无 HTML）；完整报告须经 L0（`prjc_integrate_report`）调度。

**职责：** 从入参提取 `projectChange`，按小企业（`prjc-slb`）字段映射并标注 `displayType`。不做业务分析、码值转换或 HTML 渲染。

---

## 一、模块标识

| 字段 | 值 |
| ---- | -- |
| `moduleIndex` | `1` |
| `moduleKey` | `project_change` |
| `moduleName` | `项目变更信息` |

---

## 二、数据来源

| 路径 | 说明 |
| ---- | ---- |
| `projectChange` | 模块主对象 |
| `projectChange.changeReason` | 审批变更原因 |
| `projectChange.changeType` | 审批变更类型（亦作整模块门禁） |

---

## 三、整模块门禁（校验）

按序判定；任一不通过 → **整模块不输出**（L0 跳过拼接），不中断其它模块：

| # | 条件 | 结果 |
| -: | ---- | ---- |
| 1 | `projectChange` 缺失 / `null` | 不输出 |
| 2 | `changeType`（`trim` 后）**不是** `审批变更` 且 **不是** `审批修改` | 不输出 |
| ↳ | 含：空串 / `null` / 缺失 / `初次评审` / 其它枚举 | 均不输出 |

> 仅 `审批变更`、`审批修改` 两种类型通过门禁。通过后门禁不再二次过滤字段有无。

---

## 四、展示与格式化（校验）

门禁通过后，固定输出 2 个 block（顺序不可调换）。模块顶栏标题为「项目变更信息」；体内**不**再套蓝色圆点 group；字段标签在上、内容在下。

| 顺序 | blockKey | label | displayType | 取值 | 格式化校验 |
| :--: | -------- | ----- | ----------- | ---- | ---------- |
| 1 | `changeReason` | `审批变更原因` | `longText` | `projectChange.changeReason` | `trim` 后原样；`null` / `""` / 缺失 / 仅空白 → `—`；不截断、不改写 |
| 2 | `changeType` | `审批变更类型` | `direct` | `projectChange.changeType` | `trim` 后原样；空 → `—`；**不做**码值转换，直接展示接口中文 |

其它：不修改 / 不计算 / 不补充业务数据；输出不得含 HTML 标签；必须带 `moduleIndex: 1`。

---

## 五、输出示例

```json
{
  "moduleIndex": 1,
  "moduleName": "项目变更信息",
  "moduleKey": "project_change",
  "blocks": [
    {
      "blockKey": "changeReason",
      "label": "审批变更原因",
      "displayType": "longText",

    },
    {
      "blockKey": "changeType",
      "label": "审批变更类型",
      "displayType": "direct",
      "value": "审批修改"
    }
  ]
}
```
