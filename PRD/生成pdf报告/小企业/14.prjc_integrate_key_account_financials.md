# 重点科目财务报表 · 功能整合

> L1 · `moduleIndex: 14` · 上游：尽调全量入参 · 下游：`prjc_style_render`  
> 仅输出结构化 JSON（无 HTML）；完整报告须经 L0（`prjc_integrate_report`）调度。

**职责：** 从入参提取 `financialStatementsOfKeyAccounts`，按小企业（`prjc-slb`）映射各主体资产负债表 + 利润表 + 模块级财务说明，并标注 `displayType`。仅做字段提取、透视展开、行级样式标注；不调税票 / 财报分析接口、不做 HTML 渲染。PDF 全部展开（无「财报分析」跳转、无上传主体财报等交互）。

---

## 一、模块标识

| 字段 | 值 |
| ---- | -- |
| `moduleIndex` | `14` |
| `moduleKey` | `key_account_financials` |
| `moduleName` | `重点科目财务报表` |

---

## 二、数据来源

| 路径 | 说明 |
| ---- | ---- |
| `financialStatementsOfKeyAccounts` | 模块主对象 |
| `.financialStatementsOfKeyAccountList[]` | 各主体财报表（保持入参顺序） |
| `.financialStatementsOfKeyAccountList[].sheetName` | 主体标题（如「承租人XXX重点科目财务报表」） |
| `.financialStatementsOfKeyAccountList[].fsDataSourceType` | 数据来源（展示为「数据来源：{值}」） |
| `.financialStatementsOfKeyAccountList[].balanceSheet[]` | 资产负债表按期明细 |
| `.financialStatementsOfKeyAccountList[].profitSheet[]` | 利润表按期明细 |
| `.balanceSheet[].period` / `.profitSheet[].period` | 期间列头，如 `202312` |
| `.balanceSheet[].dataType` / `.profitSheet[].dataType` | 单体 / 合并（列头红标） |
| `.financialNotes` | 财务说明（模块级，全部主体表之后） |

**PDF 不输出：** `creditCode` / `customerNo` / `periodType`（仅数据匹配）；`financialIndex[]`（重点指标模块另有表）；「财报分析」「上传主体财报」「税票授权财报引入」等页面交互。

---

## 三、整模块与 block 门禁（校验）

| # | 条件 | 结果 |
| -: | ---- | ---- |
| 1 | `financialStatementsOfKeyAccounts` 缺失 / `null` | **整模块不输出**（L0 跳过），不中断其它模块 |
| 2 | 某主体 `balanceSheet` / `profitSheet` 为空 | 仍输出对应表标题 + `emptyText` |
| 3 | `financialNotes` | 有值时输出；全部主体结束后追加 |

通过后按主体顺序组装：标题栏 → 资产负债表 → 利润表；两表期间列各自独立透视（可不一致）。

---

## 四、展示与格式化（校验）

模块顶栏：「重点科目财务报表」。blocks 按主体循环 + 末尾说明：

| 顺序 | blockKey | displayType | 说明 |
| :--: | -------- | ----------- | ---- |
| 每主体 | `subject_{customerNo}_header` | `fsSubjectHeader` | `sheetName` + `fsDataSourceType` |
| 每主体 | `subject_{customerNo}_balanceSheet` | `financialStatementTable` | 资产负债表 |
| 每主体 | `subject_{customerNo}_profitSheet` | `financialStatementTable` | 利润表 |
| 末尾 | `financialNotes` | `longText` | 有值时；label=`财务说明` |

### 通用格式化

| 规则 | 说明 |
| ---- | ---- |
| 空值 | `null` / `""` / 缺失 → `—` |
| 金额 | 千分位 + 2 位小数（含 `0.00`、负数） |
| 期间列 | 按数组顺序提取不重复 `period`；列头带 `dataType` |
| 列表顺序 | 按接口主体顺序，L1 **不重排** |

### 4.1 主体标题栏 · `fsSubjectHeader`

| 属性 | 来源 |
| ---- | ---- |
| `title` | `sheetName` |
| `dataSource` | `fsDataSourceType`（L2 展示前缀「数据来源：」） |

### 4.2 财务报表透视表 · `financialStatementTable`

| 属性 | 说明 |
| ---- | ---- |
| `label` | `资产负债表` / `利润表` |
| `unit` | 固定 `单位：元` |
| `periods[]` | `{ period, dataType }` |
| `rows[]` | `{ accountName, rowLevel, values: { [period]: string } }` |
| `emptyText` | `暂无数据` |

### 4.5 行级样式（`rowLevel`）

| rowLevel | 样式 |
| :------: | ---- |
| 1 | 背景 `#FFECE8`，字重 600（一级合计） |
| 2 | 背景 `#FFF7E8`，字重 600（二级小计） |
| 3 | 科目名左侧缩进；斑马纹可选（明细） |
| 列头 dataType | 红色小标签（如「单体」） |
| 金额列 | 右对齐 |

其它：不修改 / 不计算 / 不补充业务数据；输出不得含 HTML；必须带 `moduleIndex: 14`。
