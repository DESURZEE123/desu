# 租赁物信息 · 功能整合

> L1 · `moduleIndex: 7` · 上游：尽调全量入参 · 下游：`prjc_style_render`  
> 仅输出结构化 JSON（无 HTML）；完整报告须经 L0（`prjc_integrate_report`）调度。

**职责：** 从入参提取 `lshldModel`，按小企业（`prjc-slb`）与项目形态（直租 / 直转回 / 纯回租）分支映射，并标注 `displayType`。不做核心租赁物接口调用、不改写业务数据、不做 HTML 渲染。PDF **全部展开**明细详情（无折叠 / 导出 / 操作列）。

---

## 一、模块标识

| 字段 | 值 |
| ---- | -- |
| `moduleIndex` | `7` |
| `moduleKey` | `lease_property` |
| `moduleName` | `租赁物信息` |

---

## 二、数据来源

| 路径 | 说明 |
| ---- | ---- |
| `lshldModel` | 模块主对象 |
| `projectBaseInfo.leaseMethod` / `capitalUse` | 项目形态判定（§三） |
| `lshldModel.isInstallEquipment` / `installEquipmentDesc` | 监控设备（各形态） |
| `evalReportNo` / `netWorthTotal` / `pricingResult` / `convertRatio` / `realityConvertRatio` / `equipmentRatio` | 顶栏汇总（**仅纯回租**） |
| `lshldModel.lshldInfoList[]` | 租赁物明细（列集 / 详情按形态 A/B） |
| `lshldInfoList[].consumerName` / `isNew` / `deliveryAddress` | **直租 / 直转回** |
| `lshldInfoList[].zdNo` / `invoiceNo` / `invoiceDate` / `depreciationMonths` / `accumulatedDepreciation` | **纯回租** |
| `lshldModel.lshldPriceTotal` / `netWorthTotal` | 表合计行（各形态） |
| `lshldModel.supplierInfoList[]` | 供应商信息（**仅直租 / 直转回**） |
| `lshldModel.lshldOwnershipDesc` / `breakPriceDesc` | 底部说明 |

**PDF 不输出：** `pkRentThing` 等主键；`initialDetail` / `checkInfo` / `riskInfo`；「全部展开 / 收起 / 导出 / 操作」交互；纯回租下的 `supplierInfoList`；直租/直转回顶栏纯回租专属字段。

---

## 三、整模块门禁与形态判定（校验）

| # | 条件 | 结果 |
| -: | ---- | ---- |
| 1 | `lshldModel` 缺失 / `null` | **整模块不输出**（L0 跳过） |
| 2 | 通过后门禁按形态组装；`lshldInfoList` 为 `null` / `[]` | 仍出 table + `emptyText` |

### 项目形态判定（只读 `projectBaseInfo`）

| 形态 | 判定条件 |
| ---- | -------- |
| 直租 | `leaseMethod = 直租` |
| 直转回 | `leaseMethod = 回租` 且 `capitalUse ∈ {购置本次租赁物, 其他租赁物}` |
| 纯回租 | `leaseMethod = 回租` 且 `capitalUse = 补充流动资金` |

> 判定顺序：先直租；否则按资金用途分直转回 / 纯回租。L1 **只读**分支，不改写业务数据。

## 四、展示与格式化（校验）

模块顶栏：「租赁物信息」。blocks 顺序固定；形态决定字段集，**不得混用 A/B**。

| 顺序 | blockKey | label | displayType | 条件 |
| :--: | -------- | ----- | ----------- | ---- |
| 1 | `summary` | （不传） | `group` columns: 4 | 各形态 |
| 2 | `lshldInfoList` | `租赁物信息` | `table`（含行内 `detail`） | 各形态；列集按 A/B |
| 3 | `supplierInfoList` | `供应商信息` | `table` | **仅直租 / 直转回** |
| 4 | `lshldOwnershipDesc` | `租赁物权属状态说明` | `longText` | 有值时 |
| 5 | `breakPriceDesc` | `是否突破作价及说明` | `longText` | 有值时 |

### 通用格式化

| 规则 | 说明 |
| ---- | ---- |
| 空值 | `null` / `""` / 缺失 → `—` |
| 金额 | 千分位 + 2 位小数 |
| 比例 | 原样透传，**不**追加 `%` |
| `thingType` | 取对象 `.name` |
| 列表顺序 | 按接口顺序，L1 **不重排** |
| PDF 明细 | **全部展开**：每行必出对应形态 `detail`；无折叠交互 |
| 长文本空 | 不输出该 block |
| `showIndex` | 明细表 / 供应商表均为 `true` |

### 4.1 顶部汇总 `summary`

子字段均为 `direct`；**不传 group label**。

| 顺序 | label | 接口字段 | 格式化 | 展示条件 |
| :--: | ----- | -------- | ------ | -------- |
| 1 | 是否安装租赁物监控设备 | `isInstallEquipment` | 原样 | 各形态 |
| 2 | 监控设备情况说明 | `installEquipmentDesc` | 原样 | 各形态 |
| 3 | 评估报告号 | `evalReportNo` | 原样 | **仅纯回租** |
| 4 | 净值合计(元) | `netWorthTotal` | 金额 | **仅纯回租** |
| 5 | 定价结果(元) | `pricingResult` | 金额 | **仅纯回租** |
| 6 | 公司要求折价比例(%) | `convertRatio` | 原样 | **仅纯回租** |
| 7 | 实际折价比例(%) | `realityConvertRatio` | 原样 | **仅纯回租** |
| 8 | 通用设备占比(%) | `equipmentRatio` | 原样 | **仅纯回租** |

> 非纯回租：`children` 仅 1～2；纯回租：1～8 全量（空 → `—`）。

### 4.2 租赁物明细 `lshldInfoList`

**emptyText：** `暂无租赁物数据`。**不输出**「操作」列。宽表（汇总列 > 8）由 L2 叠行；详情栅格仍挂该条下方。

**合计行 `summary`（各形态相同，无 `detail`）：**

| key | 取值 | 说明 |
| --- | ---- | ---- |
| `index` | 固定 `合计` | — |
| `originalValue` | `lshldPriceTotal` | 金额；缺 → `—` |
| `netWorth` | `netWorthTotal` | 金额；缺 → `—`（**不受**顶栏纯回租条件限制） |

其余列合计行填 `—`。
