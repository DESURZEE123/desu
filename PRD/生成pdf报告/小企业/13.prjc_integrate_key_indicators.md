# 重点指标 · 功能整合

> L1 · `moduleIndex: 13` · 上游：尽调全量入参 · 下游：`prjc_style_render`  
> 仅输出结构化 JSON（无 HTML）；完整报告须经 L0（`prjc_integrate_report`）调度。

**职责：** 从入参提取 `keyIndicators`，按小企业（`prjc-slb`）映射顶部指标栅格 + 近 3 年财务指标表，并标注 `displayType`。不做指标计算、不调税票接口、不做 HTML 渲染。PDF 按页面顺序全文展开；系统每行 3 个指标，对齐 `columns: 3`。

---

## 一、模块标识

| 字段 | 值 |
| ---- | -- |
| `moduleIndex` | `13` |
| `moduleKey` | `key_indicators` |
| `moduleName` | `重点指标` |

---

## 二、数据来源

| 路径 | 说明 |
| ---- | ---- |
| `keyIndicators` | 模块主对象 |
| `.yoyRevenueGrowthRate` | 近一年收入同期增长率(%) |
| `.generalProvisionRatio` | 营授比(%)（字段名历史遗留，展示名以页面为准） |
| `.elementList[]` | 承租人 / 担保人抵押类负债占比动态列表 |
| `.elementList[].equivalentName` | 指标中文名（已含主体名称与单位） |
| `.elementList[].equivalentValue` | 指标值 |
| `.lesseeAndGuarantorsMortgageLiabilityRatio` | 承租人及担保人抵押类负债占比(%) |
| `.dailyAverageBalanceToIncomeRatio` | 日均余额收入比(%) |
| `.externalGuaranteeToIncomeRatio` | 对外担保收入比(%) |
| `.cashCoverageRatio` | 现金覆盖比(%) |
| `.financialIndicatorList[]` | 承租人近 3 年主要财务指标（按年份列展开） |
| `.financialIndicatorList[].year` | 年份键，如 `202312` |
| `.financialIndicatorList[].dataType` | 数据类型，如 `合并` / `单体` |
| `.haveData` | 财务指标表是否有数据；`false` 时财务表走空态 |
| `.fsDataSourceType` | 财报数据来源类型（仅数据匹配，**默认不输出**） |

**PDF 不输出：** 「税票数据引入」等页面操作；`netProfitMargin`（入参可有，页面 / 业务 PRD 不展示，L1 **不提取**）；使用入参已落库计算结果。

---

## 三、整模块门禁（校验）

| # | 条件 | 结果 |
| -: | ---- | ---- |
| 1 | `keyIndicators` 缺失 / `null` | **整模块不输出**（L0 跳过），不中断其它模块 |

通过后始终输出顶部 `keyMetrics` + 财务表（见 §四）；`elementList` 为 `null` / `[]` 时跳过动态项，其余固定指标仍出；`haveData === false` 或 `financialIndicatorList` 为 `null` / `[]` 时顶部仍出，财务表 `rows: []` + `emptyText`，**不省略** block。

---

## 四、展示与格式化（校验）

模块顶栏：「重点指标」。blocks 顺序固定。顶部指标**无**蓝色小节标题（不传 `label`）。

| 顺序 | blockKey | label | displayType | 条件 |
| :--: | -------- | ----- | ----------- | ---- |
| 1 | `keyMetrics` | （不传） | `group`（`columns: 3`） | 必出 |
| 2 | `financialIndicatorList` | `承租人近3年主要财务指标` | `table` | 必出 |

### 通用格式化

| 规则 | 说明 |
| ---- | ---- |
| 空值 | `null` / `""` / 缺失 → `—`（输出中不出现 `null` / 空串） |
| 数值 | 接口数字字符串**原样**（如 `0.0000`、`98.25`）；**不**强制补小数位，**不**追加 `%`（单位已在 label） |
| 枚举 / 名称 | `equivalentName`、`dataType` 原样，不做码值转换 |
| `fsDataSourceType` | 不输出 |

### 4.1 顶部重点指标 · `keyMetrics`

**children 组装顺序：**

| 顺序 | label | 接口字段 / 规则 | displayType | 格式化 |
| :--: | ----- | --------------- | ----------- | ------ |
| 1 | 近一年收入同期增长率(%) | `yoyRevenueGrowthRate` | `direct` | 原样；空 → `—` |
| 2 | 营授比(%) | `generalProvisionRatio` | `direct` | 同上 |
| 3… | `equivalentName` 原文 | `elementList[i].equivalentValue` | `direct` | 见动态项 |
| 后 1 | 承租人及担保人抵押类负债占比(%) | `lesseeAndGuarantorsMortgageLiabilityRatio` | `direct` | 原样；空 → `—` |
| 后 2 | 日均余额收入比(%) | `dailyAverageBalanceToIncomeRatio` | `direct` | 同上 |
| 后 3 | 对外担保收入比(%) | `externalGuaranteeToIncomeRatio` | `direct` | 同上 |
| 后 4 | 现金覆盖比(%) | `cashCoverageRatio` | `direct` | 同上 |

**动态项（`elementList`）：**

- 插入位置：固定在「营授比」之后、「承租人及担保人抵押类负债占比」之前
- `blockKey`：`element_{i}`（`i` 从 0 起）；有几条出几条
- `label`：**完整透传** `equivalentName`，不改写、不截断
- 列表空：不插动态 children → 增长率 → 营授比 → 承租人及担保人占比 → 日均 → 对外担保 → 现金覆盖

### 4.2 承租人近3年主要财务指标 · 列

`showIndex: false`；`emptyText: 暂无财务指标数据`。固定前两列 + 按 `financialIndicatorList` **年份升序**展开：

| 列顺序 | label | key | 说明 |
| :----: | ----- | --- | ---- |
| 1 | 评估项目 | `category` | 固定中文；`mergeSame: true`（L2 合并连续相同值） |
| 2 | 财务指标 | `indicator` | 固定中文 |
| 3… | `{year} {dataType}` | `y_{year}` | 如 `202312 合并`；`dataType` 空则仅 `year` |

- 年份列数量以入参为准（通常近 3 年，不强制截断）
- 同一 `year` 多条：以后出现的为准

### 4.3 固定行序（评估项目 × 财务指标）

按下行序展开；每行从各年份对象取对应字段写入 `y_{year}`。评估项目文案对齐页面（「运营能力」）。

| 顺序 | 评估项目（`category`） | 财务指标（`indicator`） | 接口字段 |
| :--: | ---------------------- | ----------------------- | -------- |
| 1 | 盈利能力 | 销售毛利率(%) | `grossProfitMargin` |
| 2 | 盈利能力 | ROA 资产净利率(%) | `returnOnAssets` |
| 3 | 盈利能力 | ROE 净资产收益率(%) | `returnOnEquity` |
| 4 | 运营能力 | 存货周转率 | `inventoryTurnover` |
| 5 | 运营能力 | 应收账款周转率 | `accountsReceivableTurnover` |
| 6 | 运营能力 | 总资产周转率 | `totalAssetTurnover` |
| 7 | 偿债能力 | 资产负债率(%) | `debtToAssetRatio` |
| 8 | 偿债能力 | 速动比率 | `quickRatio` |
| 9 | 偿债能力 | 流动比率 | `currentRatio` |
| 10 | 偿债能力 | 借款依存度(%) | `loanDependence` |
| 11 | 偿债能力 | 现金流动负债比率(%) | `cashFlowToCurrentLiabilitiesRatio` |
| 12 | 偿债能力 | 销售现金比率(%) | `cashSalesRatio` |
| 13 | 偿债能力 | 清算价值比率(%) | `liquidationValueRatio` |
| 14 | 发展能力 | 营业增长率(%) [财报数据] | `operatingRevenueGrowthRateFinancial` |
| 15 | 发展能力 | 资本积累率(%) | `capitalAccumulationRate` |
| 16 | 发展能力 | 总资产增长率(%) | `totalAssetGrowthRate` |

> 业务 PRD 另有「营业增长率(%)[发票数据]」；当前 schema 无对应字段时**不输出该行**。若后续入参加入 `operatingRevenueGrowthRateInvoice`，插在「营业增长率(%) [财报数据]」之前，归属发展能力。

**空表：** `haveData === false` 或 `financialIndicatorList` 为 `null` / 非数组 / 长度 0 → `rows: []`，走 `emptyText`。有数据时始终输出上表 16 行（含发票增长率时 17 行），缺年份字段填 `—`，**不因某年全空而删行**。`category` 列由 L2 按 `mergeSame` 合并；L1 仍按行重复写入。

其它：不计算 / 不改写指标；输出不得含 HTML；必须带 `moduleIndex: 13`。

**L2 协作：** `group`（`columns: 3`）+ `table`（`mergeSame`）；`keyMetrics` 不传 `label` → 无蓝色小节标题。
