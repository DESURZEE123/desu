# 增信措施 · 功能整合

> L1 · `moduleIndex: 10` · 上游：尽调全量入参 · 下游：`prjc_style_render`  
> 仅输出结构化 JSON（无 HTML）；完整报告须经 L0（`prjc_integrate_report`）调度。

**职责：** 从入参提取 `creditEnhancementMeasure`，按小企业（`prjc-slb`）映射担保措施卡片 + 担保人 / 担保企业详情，并标注 `displayType`。不调客户 / 司法涉诉接口、不做 HTML 渲染。PDF 按顺序全文展开（无「信息已完善」badge、无「管理增信措施」、无折叠 / Tab）。

---

## 一、模块标识

| 字段 | 值 |
| ---- | -- |
| `moduleIndex` | `10` |
| `moduleKey` | `credit_enhancement` |
| `moduleName` | `增信措施` |

---

## 二、数据来源

| 路径 | 说明 |
| ---- | ---- |
| `creditEnhancementMeasure` | 模块主对象 |
| `.creditEnhancementMeasureInfo.creditEnhancementMeasureList[]` | 担保措施列表（**不以报价过滤**） |
| `.guaranteePersonList[]` | 担保自然人详情 |
| `.guaranteeCompanyList[]` | 担保企业详情 |
| `.guaranteeCompanyList[].companyPublicInfo` | 担保企业公示信息（与承租人同构） |

与实施方案（moduleIndex 6）区别：实施方案按报价取摘要（`commonCreditEnhancementMeasure` → `embodiment` → 顶层，有 `quotName` 则过滤）；**本模块取顶层全量**，另含担保人 / 企业详情。卡片字段规则与实施方案摘要相同（§四.1）。

**PDF 不输出：** `pkCreditEnhancementMeasure` / `pkGuarantorInfo` / 各类主键；`customerType[]` / `guaCustomerNo`；`collaborationHistoryModel`（合作历史独立模块）；`loan` / `productionAndSaleSituation` / `assetSize` / 财报等截图外字段；页面交互控件。

## 三、整模块门禁（校验）

| # | 条件 | 结果 |
| -: | ---- | ---- |
| 1 | `creditEnhancementMeasure` 缺失 / `null` | **整模块不输出**（L0 跳过） |

通过后门禁：

| 规则 | 说明 |
| ---- | ---- |
| 担保措施列表 | 必出；空 → `emptyText: 暂无增信措施` |
| `guaranteePersonList` 空 | 不出「担保人信息」标题与自然人详情 |
| `guaranteeCompanyList` 空 | 不出担保企业详情 |
| 长文本空 | 不出该 `longText` block |
| 司法卡片 | `caseNum <= 0` 不展示；先高风险后普通 |

## 四、展示与格式化（校验）

模块顶栏：「增信措施」。blocks 顺序固定。

| 顺序 | blockKey | label | displayType | 条件 |
| :--: | -------- | ----- | ----------- | ---- |
| 1 | `creditEnhancementTitle` | `增信措施` | `sectionHeading` | 必出 |
| 2 | `creditEnhancementMeasureList` | `担保措施` | `measureList` | 必出 |
| 3 | `guaranteePersonTitle` | `担保人信息` | `sectionHeading` | 自然人列表非空 |
| 4+ | `guaranteePerson_{customerNo}` | `担保自然人 - {customerName}` | `guaranteePersonDetail` | 每人一组 |
| … | `guaranteeCompany_{customerNo}` | `担保企业 - {customerName}` | `guaranteeCompanyDetail` | 每企一组 |

> `guaranteePersonDetail` / `guaranteeCompanyDetail`：L2 扩展（蓝副标题 + childBlocks）；未实现前可用 `group`（`columns: 1`）降级，但 **L1 须按上表标注**。

### 通用规则

| 规则 | 说明 |
| ---- | ---- |
| 空值 | `null` / `""` / 缺失 → `—` |
| 金额 | 千分位 + 2 位小数 |
| `guaCustType` | `0`→企业；`1`→自然人（仅语义，**不单独成列**） |
| `guaranteeMethod` | 取对象 `desc`；已是字符串则原样 |
| `relationship` 空 | measureList 卡片不传该字段（不渲染绿 tag） |

### `guaranteeTone` 色标

| 担保方式 | code | tone | 标签色（L2） |
| -------- | :--: | ---- | ------------ |
| 保证担保 | 1 | `guarantee` | 橙 `#FF7D00` |
| 抵押担保 | 3 | `mortgage` | 蓝 `#3491FA` |
| 质押担保 | 5 | `pledge` | 浅橙 `#FF9A2E` |
| 其他 / 未知 | — | `default` | 灰 `#86909C` |

有 `desc` 无 `code` 时按文案含「保证 / 抵押 / 质押」匹配；均无法匹配 → `default`。L2：`report-measure-card__tag--{tone}`。

### 4.1 担保措施 · measureList

**emptyText：** `暂无增信措施`

#### 卡片主字段（`items[]`）

| 卡片字段 | 取值 | 说明 |
| -------- | ---- | ---- |
| `guaranteeMethod` | `guaranteeMethod.desc`（字符串则原样） | 标签文字 |
| `guaranteeTone` | 见上表 | 标签色 |
| `customerName` | `customerName` | |
| `relationship` | `relationship` | 空则不传 |
| `crdntlsType` | `crdntlsType` | |
| `documentCode` | `documentCode` | |

#### 抵押 / 质押 `attrs`（仅 tone = `mortgage` / `pledge`）

| 列 label | key |
| -------- | --- |
| 抵押物类别 | `collateralType` |
| 抵质押物类型 | `mortgageAndPledgeType` |
| 抵质押物分类 | `mortgageAndPledgeClass` |

空 → `—`。保证担保不传 `attrs`。

#### 担保物 `collateral`（仅 `collateralList` 非空）

`label: 担保物` · `showIndex: true` · 列全部左对齐（不传 `align` 或统一 `left`）

| 列 label | key | 格式化 |
| -------- | --- | ------ |
| 担保物名称 | `assetsName` | 原样 |
| 所在地 | `locationVfbc` | 原样 |
| 车牌号/不动产面积 | `assetsNo1Vfbc` | 原样 |
| 机身号/不动产单元号 | `assetsNo` | 原样 |
| 租赁物唯一识别码/抵质押证书编号 | `assetsNo2Vfbc` | 原样 |
| 担保物估值(元) | `estimateValue` | 金额 |
| 币种 | `currtype` | 原样 |
| 第三方质押债务人 | `debtor` | 原样 |
| 是否第一顺位 | `isFirstOrder` | 原样 |
| 评估方式 | `assessMode` | 原样 |
| 优先受偿权数额 | `compensationNumber` | 金额（已是文案则原样） |
| 估值周期 | `valuationCycle` | 原样 |

`collateralList` 空 / null：不传 `collateral`。

### 4.2 担保自然人 · childBlocks

| 顺序 | blockKey | label | displayType |
| :--: | -------- | ----- | ----------- |
| 1 | `baseInfo` | `基本信息` | `group`（columns: 4） |
| 2 | `judicialLitigationInfo` | `司法诉讼信息` | `litigationCards` |
| 3 | `judicialLitigationInfoDesc` | `司法诉讼信息说明` | `longText`（有值时） |

**基本信息字段：**

| 顺序 | label | 接口字段 | 说明 |
| :--: | ----- | -------- | ---- |
| 1 | 姓名 | `customerName` | |
| 2 | 证件类型 | `crdntlsType` | |
| 3 | 证件代码 | `documentCode` | |
| 4 | 与承租人关系 | `relationship` | |
| 5 | 与承租人关系说明 | `relationshipDesc` | |
| 6 | 名下资产、市值与抵押情况 | `assetDesc` | `fullWidth: true` |

**不输出：** `age` / `sex` / `maritalStatus` / `guaranteeContInfoList`。

### 4.3 担保企业 · childBlocks

| 顺序 | blockKey | label | displayType |
| :--: | -------- | ----- | ----------- |
| 1 | `baseInfo` | `基本信息` | `group`（columns: 4） |
| 2 | `shareholderList` | `股权结构` | `table` |
| 3 | `controllerIntroduction` | `实控人及股东情况介绍` | `longText`（有值时） |
| 4 | `judicialLitigationInfo` | `司法诉讼信息` | `litigationCards` |
| 5 | `judicialLitigationInfoDesc` | `司法诉讼信息说明` | `longText`（有值时） |

**基本信息**（`companyPublicInfo.baseInfo`）：

| 顺序 | label | 接口字段 | 说明 |
| :--: | ----- | -------- | ---- |
| 1 | 企业名称 | `customerName` | |
| 2 | 统一社会信用代码 | `crdntlsCode` | |
| 3 | 法定代表人 | `legalRepresentativeCustomerName` | |
| 4 | 实际控制人 | `actControlsName` | |
| 5 | 成立时间 | `estblshDate` | |
| 6 | 注册资本(万元) | `rgstrdCapital` | 千分位 |
| 7 | 行业小类 | `pkIndustrySortLittle.name` | |
| 8 | 从业人数 | `employeeNum` | |
| 9 | 注册地址 | `rgstrdAddress` | `fullWidth: true` |

**不输出：** 行业许可证、主营业务、公司沿革。

**股权结构：** `shareholderList[]` + `shareholderTotal` · `showIndex: true` · `emptyText: 暂无股权结构数据`

| 列 label | key |
| -------- | --- |
| 股东名称 | `shareholderName` |
| 出资额(万元) | `shareholderCapitalAmount`（千分位） |
| 占比(%) | `holdStockRatio` |

合计行取 `shareholderTotal`；序号列 `合计`。

**实控人及股东情况介绍：** `companyPublicInfo.controllerIntroduction`（自然人不出）。

### 4.4 司法诉讼 · litigationCards

规则同承租人基本信息：

| 属性 | 说明 |
| ---- | ---- |
| `updateTime` | `judicialLitigationInfo.updateTime` |
| `cards[]` | 先 `caseTypeHighRiskList`，再 `caseTypeCommonList`；过滤 `caseNum <= 0` |
| `cards[].tone` | 高风险 → `highRisk`；普通 → `common` |
| `emptyText` | `客户暂无司法诉讼数据` |

自然人：`guaranteePersonList[].judicialLitigationInfo`；企业：`companyPublicInfo.judicialLitigationInfo`。  
司法说明：`judicialLitigationInfo.judicialLitigationInfoDesc`。

其它：不修改 / 不补充业务数据；输出不得含 HTML；必须带 `moduleIndex: 10`。

**L2 依赖：** `measureList` / `sectionHeading` / `group` / `table` / `longText` / `litigationCards`；详情容器见上。
