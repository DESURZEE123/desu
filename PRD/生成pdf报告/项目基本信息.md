# 项目基本信息模块样式规范（PRJC_REPORT Skill）

## 模块定位

项目基本信息模块展示尽调项目核心基础信息，数据来源于接口 `projectBaseInfo` 对象（含闪光租 `filingStatusInfo` 子对象）。

AI 仅按字段类型匹配展示样式并输出 HTML 结构，**不做**数据整理、分析或计算。

---

## 一、样式规则

### 1. 基础键值对样式（文本 / 数值 / 枚举单值字段）

- **格式**：字段名：字段值
- **适用字段**：

| 中文展示名 | 接口字段 |
| ---------- | -------- |
| 客户名称 | `customerName` |
| 项目金额 | `projectAmount` |
| 项目类型 | `projectType` |
| 项目来源 | `projectSource` |
| 租赁方式 | `leaseMethod` |
| 资金用途 | `capitalUse` |
| 售后回租原因 | `leasebackReason` |
| 投保情况 | `insuranceSituation` |
| 是否投保 | `isInsure` |
| 是否一对一 | `isOnetoone` |
| 租赁类别 | `leaseCategry` |
| 部门名称 | `deptName` |
| 部门编码 | `deptCode` |

- **数值字段**：项目金额保留两位小数并添加千分位分隔符
- **枚举字段**：直接展示接口返回的中文枚举值，不做转换

### 2. 人员参照样式（参照类型字段）

- **格式**：字段名：姓名（工号）
- **适用字段**：

| 中文展示名 | 接口字段 |
| ---------- | -------- |
| 项目经理 | `managerName` / `managerWorkNo` |
| 项目协办人 | `custHelpName` / `custHelpNo` |

- 工号为空时仅展示姓名

### 3. 长文本样式（文本说明类字段）

- **格式**：字段名：换行后展示完整文本内容
- **适用字段**：

| 中文展示名 | 接口字段 |
| ---------- | -------- |
| 售后回租原因说明 | `leasebackExplain` |
| 租赁物保险 | `leaseInsurance` |

- 文本超过 200 字时自动换行，不截断

### 4. 子对象分组样式（对象类型字段）

- **格式**：以字段名为子标题，下方分组展示对象内各子字段（子字段按基础键值对样式展示）
- **适用字段**：环境与社会风险评估（`environmentAndSocialRisk`）
- **子字段包括**：

| 中文展示名 | 接口字段 |
| ---------- | -------- |
| 是否禁入业务 | `exclusionBusinessResult` |
| 是否政策限制 | `policyRestrictResult` |
| 是否取得经营许可 | `operateLicenseResult` |
| 是否违法违规 | `offenceResult` |
| 是否存在隐患风险 | `hiddenRiskResult` |
| 评估结果 | `assessResult` |

### 5. 列表表格样式（数组类型字段，闪光租特殊）

- **格式**：以字段名为标题，下方以表格形式展示数组中每个对象的字段
- **适用字段**：项目备案明细（`filingStatusDetailList`）
- **表格列**：

| 表头 | 接口字段 |
| ---- | -------- |
| 项目名称 | `projectName` |
| 备案容量 MW | `registeredCapacityMw` |
| 实际容量 MW | `actualCapacityMw` |
| 消纳模式 | `operationMode` |
| 屋顶企业 | `roofEnterprise` |
| 用电企业 | `powerConsumingEnterprise` |
| 自用电价元/度 | `selfConsumptionTariff` |
| 消纳比例 % | `consumptionRatio` |
| 项目地址 | `projectAddress` |
| 并网日期 | `gridConnectionDate` |
| 设备 | `equipment` |

- 数组为空时展示「暂无备案信息」

### 6. 实时计算数值样式（顶层计算字段，闪光租特殊）

- **格式**：字段名：数值 单位
- **适用字段**：自用电价（`selfUseElectricityPrice`）
- 保留四位小数，单位为「元/度」

### 7. 汇总数值样式（汇总对象，闪光租特殊）

- **格式**：在列表表格下方单独一行展示：`合计：备案容量 X MW，实际容量 Y MW`
- **适用字段**：
  - 备案容量汇总：`filingStatusTotal.registeredCapacityMw`
  - 实际容量汇总：`filingStatusTotal.actualCapacityMw`

## 二、尽调系统差异约束

| 规则范围 | 适用系统 | 说明 |
| -------- | -------- | ---- |
| 规则 1–4（通用字段） | 闪光租、小企业、厂商租赁、印包、环卫 | 所有尽调系统均适用 |
| 规则 5–7（闪光租特殊） | 仅闪光租 | **仅当** `projectType = 闪光租` 时展示，其他尽调系统不展示该模块 |
| 小企业特殊 | 仅小企业 | 对应老合同（`oldContInfoList`）仅小企业展示；当项目类型 = 老客租项目时可编辑 |

---

## 三、输出约束

1. AI 仅按上述样式规则将传入数据映射为展示结构，**不修改、不计算、不补充**任何数据
2. 字段名使用中文展示名称，接口英文字段名仅用于数据匹配，**不输出到 HTML**
3. 所有字段值为空时统一展示「—」，不输出 `null` 或空字符串
4. 输出为标准 HTML 片段，使用语义化标签（`div`、`p`、`table`、`thead`、`tbody`、`tr`、`td`、`ul`、`li` 等），**不包含** `html` / `head` / `body` 等完整文档标签
5. 样式通过内联 `style` 或 `class` 属性控制，不依赖外部 CSS 文件；表格需包含完整的 `thead` / `tbody` 结构
6. 列表表格样式（规则 5）输出为标准 `table` 标签，数组中每个对象对应一行 `tr`，字段名作为表头 `th`
